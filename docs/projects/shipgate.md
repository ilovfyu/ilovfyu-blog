## 项目定位

ShipGate 面向 AI 辅助开发的应用，定位为统一的安全层：把 AI 成本控制、Agent 熔断、支付防护和监控组织到一个 SDK 中。

## 安全层的关注范围

| 方向 | 项目目标 |
| --- | --- |
| AI 成本控制 | 关注应用调用 AI 服务产生的成本。 |
| Agent 熔断 | 为智能体执行提供可中断的保护边界。 |
| 支付防护 | 为涉及支付的应用操作提供保护。 |
| 监控 | 将运行情况与安全检查联系起来。 |

首屏以立体安全闸门说明定位：检查请求后，正常路径连接成本、智能体和支付策略，风险路径在入口前被拦截，不代表已交付的安全能力或保证。

## 构建状态

项目处于早期构建阶段，当前公开仓库主要提供项目定位。具体 API、安装方式、支持范围与验证结果将随实现补充。

查看 [GitHub 仓库](https://github.com/ilovfyu/ShipGate) 了解最新进展。
