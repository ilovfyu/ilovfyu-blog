## 项目定位

Tagline 聚焦 LLM 推理的性能分诊：以一条命令生成带分数的体检报告，并给出按收益排序的修复清单，让优化工作有明确的起点。

## 从诊断到优化顺序

| 环节 | 项目目标 |
| --- | --- |
| 性能分诊 | 梳理推理过程中的性能问题，形成可读的诊断结果。 |
| 体检报告 | 用带分数的报告帮助理解当前状态。 |
| 修复清单 | 按预期收益排列修复方向，帮助确定优化优先级。 |

首屏采用终端诊断界面：命令启动后扫描性能曲线、生成评分环，再逐行展开按收益排序的修复条目。曲线与条形仅用于解释流程，不是实际测量结果，也不代表固定的评分方法。

## 构建状态

项目处于早期构建阶段，当前公开仓库主要提供项目定位。具体 API、安装方式、支持范围与验证结果将随实现补充。
