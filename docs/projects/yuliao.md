# 愈语

> [!info] 项目状态
> 计划中。Obsidian 已建立独立项目目录，当前尚无可公开的设计文档。

## 当前记录

项目归类为 **C端 / AI 数字人陪伴**。愈语（YULIAO）是一款数字人实时视频聊天应用：轻触开启视频通话，数字人像你面前的朋友一样，看得见表情、听得懂语气、愿意陪你慢慢聊。核心体验围绕「数字人实时视频、自然语音交流、情绪陪伴、隐私安全、多端视频」展开。需求定义、系统边界、技术方案和验证记录将在形成后更新到本页。
