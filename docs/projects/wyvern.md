## 项目定位

Wyvern 是面向 **δ-mem 完整实现的算子与工具库**。以在线联想记忆的计算过程为主线，把输入投影、状态更新、记忆读出和注意力修正组织成可复用的实现单元，为模型接入、实现对照和后续优化提供基础。

## 从输入到记忆，再到生成

δ-mem 在冻结的全注意力骨干旁维护一个紧凑的联想记忆状态：新输入投影到记忆空间后，通过 δ 规则更新状态；生成时读出记忆，用于构造注意力计算的低秩修正。机制依据见 [δ-mem 论文](https://arxiv.org/abs/2605.12357) 与 [作者实现](https://github.com/declare-lab/delta-Mem)。

首屏动画以一张 **8 × 8 的示意状态矩阵** 展示这个过程：输入抵达、状态更新、记忆读出，最终回到注意力路径。图形用于说明计算关系，不代表性能测量或固定的状态维度。

## 实现范围

| 环节 | 库的职责 |
| --- | --- |
| 输入投影 | 组织输入到记忆空间的映射，以及写入所需的键、值与更新系数。 |
| δ 规则写入 | 围绕预测残差更新状态矩阵，明确状态初始化、更新顺序与序列边界。 |
| 记忆读出 | 从当前状态提取与查询有关的信息，衔接注意力的低秩修正路径。 |
| 算子接口 | 划分计算单元，明确张量形状、状态传递与组合方式。 |
| 验证工具 | 对照参考实现检查数值与梯度一致性，记录误差、耗时和显存使用。 |
