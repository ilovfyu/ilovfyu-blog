# 函数

## 学习目标

- 理解函数声明、函数表达式、箭头函数和方法的语义差异。
- 掌握参数、返回值、`this`、闭包与高阶函数。
- 能解释调用栈、尾调用限制和内存生命周期。
- 编写边界清晰、可组合且便于测试的函数。

## 1. 函数是值

函数可以赋给变量、放入对象、作为参数传递或作为结果返回，这是高阶编程的基础。

```js
function add(a, b) {
  return a + b;
}

const multiply = function (a, b) {
  return a * b;
};

const calculate = (operation, a, b) => operation(a, b);

console.log(calculate(add, 2, 3));
console.log(calculate(multiply, 2, 3));
```

函数声明在所在作用域初始化阶段可用；函数表达式只有执行到赋值语句后才能调用。为调试堆栈清晰，复杂函数表达式可使用具名形式。

## 2. 参数系统

JavaScript 按值传参。对象参数传递的是引用值的副本，因此函数可以修改同一个对象，但不能通过重新赋值参数替换调用方变量。

```js
function update(user, role = "reader") {
  user.role = role;
  user = { name: "other" }; // 只改变局部参数
}

const user = { name: "Ada" };
update(user);
console.log(user); // { name: "Ada", role: "reader" }
```

默认参数只在实参为 `undefined` 或缺省时生效，`null` 不会触发默认值。剩余参数是真数组，比传统的类数组 `arguments` 更适合现代代码。

```js
function createPoint({ x = 0, y = 0 } = {}) {
  return { x, y };
}

function average(first, ...rest) {
  const values = [first, ...rest];
  return values.reduce((sum, value) => sum + value, 0) / values.length;
}

console.log(createPoint({ x: 3 }));
console.log(average(2, 4, 6));
```

## 3. 箭头函数的边界

箭头函数语法紧凑，并从外层词法环境捕获 `this`、`arguments`、`super` 和 `new.target`。它不能作为构造函数，也没有 `prototype`。

```js
const team = {
  name: "Core",
  members: ["A", "B"],
  labels() {
    return this.members.map((member) => `${this.name}:${member}`);
  },
};

console.log(team.labels());
```

对象方法若写成箭头函数，`this` 不会指向该对象：

```js
const badCounter = {
  count: 0,
  increment: () => {
    // this 来自外层，不是 badCounter
  },
};
```

需要动态接收者、构造能力或 `arguments` 时使用普通函数；短回调通常优先箭头函数。

## 4. this 与调用方式

`this` 由调用方式决定，而不是由函数定义位置决定。常见规则是：

1. `obj.method()`：`this` 为点号前的对象。
2. `fn.call(value)`、`fn.apply(value)`：显式指定 `this`。
3. `new Fn()`：`this` 为新实例。
4. 独立普通函数调用：严格模式下为 `undefined`。
5. 箭头函数：沿词法作用域捕获，不参与上述绑定。

```js
function introduce(prefix, punctuation) {
  return `${prefix}${this.name}${punctuation}`;
}

const context = { name: "Lin" };
console.log(introduce.call(context, "Hi, ", "!"));
console.log(introduce.apply(context, ["Hello, ", "."]));

const bound = introduce.bind(context, "Welcome, ");
console.log(bound("!"));
```

`bind()` 返回新函数，不能再次通过 `call()` 改写其绑定的 `this`。频繁创建绑定函数也会影响事件监听器的移除，因为函数身份不同。

## 5. 闭包与词法作用域

函数会记住其定义时可访问的词法环境，即使外层函数已返回。这种组合称为闭包。

```js
function createCounter(initial = 0) {
  let value = initial;
  return {
    increment() {
      value += 1;
      return value;
    },
    current() {
      return value;
    },
  };
}

const counter = createCounter(10);
console.log(counter.increment(), counter.current());
```

闭包适合封装状态、创建配置化函数和维持异步上下文。只要闭包可达，它引用的外层数据通常也保持可达，因此不要无意捕获大型对象。

块级声明解决了经典循环闭包问题：

```js
const tasks = [];
for (let index = 0; index < 3; index += 1) {
  tasks.push(() => index);
}
console.log(tasks.map((task) => task())); // [0, 1, 2]
```

## 6. 递归与调用栈

递归应明确终止条件，并考虑输入规模。尾调用优化在 JavaScript 生态中的支持并不一致，生产代码不要依赖它避免栈溢出。

```js
function factorial(n) {
  if (!Number.isInteger(n) || n < 0) throw new RangeError("n 必须是非负整数");
  if (n <= 1) return 1;
  return n * factorial(n - 1);
}

console.log(factorial(5));
```

处理深层树或未知深度数据时，可以改用显式栈：

```js
function countNodes(root) {
  let count = 0;
  const stack = [root];
  while (stack.length > 0) {
    const node = stack.pop();
    count += 1;
    if (node.children) stack.push(...node.children);
  }
  return count;
}

console.log(countNodes({ children: [{}, { children: [{}] }] })); // 4
```

## 7. 高阶函数与组合

小型纯函数便于测试和复用。组合将数据处理拆为多个清晰步骤。

```js
const pipe = (...functions) => (input) =>
  functions.reduce((value, fn) => fn(value), input);

const normalize = (text) => text.trim().toLowerCase();
const slugify = (text) => text.replace(/\s+/g, "-");
const toSlug = pipe(normalize, slugify);

console.log(toSlug("  JavaScript Functions  ")); // javascript-functions
```

纯函数对相同输入给出相同输出，且不修改外部可观察状态。但 I/O、本地时间、随机数等天然包含副作用，应把它们集中在边界层，而不是假装所有代码都纯。

## 8. 缓存与函数属性

函数可拥有属性，但业务状态通常放在闭包或专用对象中更明确。记忆化适合输入稳定且计算昂贵的纯函数。

```js
function memoize(fn) {
  const cache = new Map();
  return (key) => {
    if (cache.has(key)) return cache.get(key);
    const value = fn(key);
    cache.set(key, value);
    return value;
  };
}

const square = memoize((number) => number ** 2);
console.log(square(12), square(12));
```

真实缓存还要考虑对象键、多个参数、容量上限、过期策略与错误结果是否缓存。

## 常见陷阱与最佳实践

1. 函数参数不要过多；相关参数可收拢为选项对象，并为缺省对象设置默认值。
2. 不要修改调用方传入的对象，除非 API 明确约定为原地操作。
3. 不要用箭头函数定义需要动态 `this` 的对象方法，也不要尝试用 `new` 调用箭头函数。
4. 回调被第三方长期保存时，注意闭包是否捕获 DOM 节点或大型缓存，并在适当时机注销。
5. `sort(compareFn)` 的比较函数应返回负数、零或正数，不应简单返回布尔值。
6. 保持返回类型稳定；同一函数不要一会儿返回对象、一会儿返回 `false`，可使用异常、`null` 或统一结果结构表达失败。
7. 优先让函数只做一件可命名的事，但不要为每一行机械拆分函数。

## 章节小结

函数是一等值，也是 JavaScript 抽象与组合的核心。参数与返回值定义数据边界，调用方式决定普通函数的 `this`，闭包则连接函数和词法环境。现代实践应优先使用默认参数、剩余参数和箭头回调，同时明确副作用、资源生命周期与递归深度。
