# 对象、类与面向对象编程

## 学习目标

- 理解对象属性、属性描述符及对象完整性控制。
- 掌握工厂函数、构造函数、原型链与 `class` 的关系。
- 能使用继承、组合和私有字段设计可维护的对象模型。
- 明确 JavaScript 面向对象中常见的共享状态、`this` 与封装陷阱。

## 1. 对象是动态的属性集合

JavaScript 对象由一组键值属性组成。属性键只能是字符串或 `Symbol`；数字键会被转换为字符串。对象适合表示有明确字段与行为的实体，而 `Map` 更适合频繁增删、键类型不限的字典数据。

```js
const user = {
  name: "Ada",
  age: 36,
  [Symbol.for("role")]: "admin",
  greet() {
    return `Hello, ${this.name}`;
  },
};

user.active = true;
console.log(user.greet());
console.log(Object.keys(user)); // 不包含 Symbol 键
console.log(Reflect.ownKeys(user)); // 包含字符串键与 Symbol 键
```

对象字面量支持计算属性名、属性简写和方法简写：

```js
const field = "score";
const score = 95;
const result = {
  [field]: score,
  score,
  print() {
    console.log(this.score);
  },
};

result.print();
```

## 2. 属性描述符

数据属性具有 `value`、`writable`、`enumerable`、`configurable` 四个特征。访问器属性用 `get` 和 `set` 代替 `value` 与 `writable`。

```js
const account = {};

Object.defineProperty(account, "id", {
  value: "A-001",
  writable: false,
  enumerable: true,
  configurable: false,
});

let balance = 0;
Object.defineProperty(account, "balance", {
  get() {
    return balance;
  },
  set(value) {
    if (!Number.isFinite(value) || value < 0) {
      throw new RangeError("balance 必须是非负有限数");
    }
    balance = value;
  },
  enumerable: true,
});

account.balance = 100;
console.log(account.balance, Object.getOwnPropertyDescriptor(account, "id"));
```

直接赋值创建的属性默认可写、可枚举、可配置；`Object.defineProperty()` 中未声明的布尔特征默认是 `false`。访问器适合校验或派生值，但不应隐藏昂贵计算或意外副作用。

## 3. 合并、解构与复制

`Object.assign()` 与对象展开执行浅复制，只复制自有可枚举属性。嵌套对象仍被共享，访问器通常会被读取为普通值。

```js
const defaults = { theme: "light", options: { compact: false } };
const config = { ...defaults, theme: "dark" };
config.options.compact = true;

console.log(defaults.options.compact); // true，嵌套对象被共享

const source = { name: "Lin", age: 28 };
const { name, age: years, city = "Shanghai" } = source;
console.log(name, years, city);
```

需要复制可结构化数据时可使用 `structuredClone()`，它支持循环引用、`Map`、`Set` 等，但不能克隆函数、DOM 节点和部分宿主对象。

```js
const original = { settings: { volume: 8 }, createdAt: new Date() };
const cloned = structuredClone(original);
cloned.settings.volume = 3;
console.log(original.settings.volume, cloned.createdAt instanceof Date);
```

## 4. 创建对象：从工厂到原型

工厂函数简单直观，但每次创建对象时通常会新建方法函数。构造函数配合原型可以共享行为。

```js
function createUser(name) {
  return {
    name,
    greet() {
      return `Hi, ${name}`;
    },
  };
}

function User(name) {
  this.name = name;
}

User.prototype.greet = function () {
  return `Hi, ${this.name}`;
};

const ada = new User("Ada");
console.log(ada.greet());
console.log(Object.getPrototypeOf(ada) === User.prototype); // true
```

`new User()` 大致会创建对象、连接到 `User.prototype`、以新对象调用函数，并在构造函数未显式返回对象时返回该对象。现代代码通常优先使用 `class` 表达同一套原型机制。

## 5. 原型链与属性查找

读取属性时，引擎先检查对象自身，再沿 `[[Prototype]]` 链向上查找，最终到 `null`。写入属性通常会在当前对象上创建或更新属性，而不会修改原型上的同名数据属性。

```js
const animal = { eats: true };
const rabbit = Object.create(animal);
rabbit.name = "Milo";

console.log(rabbit.eats); // 从原型读取
console.log(Object.hasOwn(rabbit, "eats")); // false
console.log("eats" in rabbit); // true

rabbit.eats = false;
console.log(rabbit.eats, animal.eats); // false true
```

判断自有属性应优先用 `Object.hasOwn(object, key)`，避免对象覆盖 `hasOwnProperty`，也适用于无原型对象。

## 6. 类、字段与私有状态

`class` 是基于原型机制的语法，类声明处于严格模式且不会像函数声明一样完整提升。实例方法位于原型，实例字段位于各实例自身。

```js
class Counter {
  #value = 0;
  static instances = 0;

  constructor(initial = 0) {
    this.#value = initial;
    Counter.instances += 1;
  }

  increment(step = 1) {
    this.#value += step;
    return this;
  }

  get value() {
    return this.#value;
  }

  static from(text) {
    return new Counter(Number(text));
  }
}

const counter = Counter.from("2").increment(3);
console.log(counter.value, Counter.instances);
```

`#value` 是语言级私有字段，只能在声明它的类体内访问。下划线前缀只是命名约定，并不提供真正私有性。

## 7. 继承与多态

`extends` 建立静态与实例两条原型链。派生类构造函数在访问 `this` 前必须调用 `super()`。覆写方法时可通过 `super.method()` 复用父类行为。

```js
class Shape {
  constructor(color) {
    this.color = color;
  }

  describe() {
    return `颜色：${this.color}`;
  }

  area() {
    throw new Error("子类必须实现 area()");
  }
}

class Rectangle extends Shape {
  constructor(width, height, color = "black") {
    super(color);
    this.width = width;
    this.height = height;
  }

  area() {
    return this.width * this.height;
  }

  describe() {
    return `${super.describe()}，面积：${this.area()}`;
  }
}

console.log(new Rectangle(3, 4, "blue").describe());
```

继承适合稳定的“是一个”关系。业务能力经常变化时，组合通常更灵活：将日志、缓存、验证等能力作为独立对象或函数注入，而不是建立很深的类层次。

## 8. 对象完整性

- `Object.preventExtensions()`：禁止增加自有属性。
- `Object.seal()`：在上述基础上禁止删除或重新配置属性。
- `Object.freeze()`：在上述基础上使现有数据属性不可写。

这些操作都是浅层的。

```js
const settings = Object.freeze({
  mode: "production",
  nested: { debug: false },
});

settings.nested.debug = true; // 内层对象未被冻结
console.log(settings.nested.debug);
```

## 常见陷阱与最佳实践

1. 不要在原型上放可变数组或对象，否则所有实例会共享状态；应在构造函数或实例字段中初始化。
2. 从实例中单独取出方法会丢失接收者：`const fn = obj.method; fn()` 中的 `this` 不再是 `obj`。事件回调可使用包装函数或在边界处绑定。
3. 箭头函数没有自己的 `this`，适合回调，不适合作为需要动态接收者的原型方法。
4. 不要依赖 `for...in` 只遍历自有属性；对象遍历优先使用 `Object.keys()`、`Object.values()` 或 `Object.entries()`。
5. 类继承不要只为复用几行代码而建立；优先保持扁平结构并通过组合复用能力。
6. 公共 API 返回内部可变对象时要考虑防御性复制，避免调用方破坏不变量。

## 章节小结

JavaScript 对象的核心是属性描述符与原型委托，`class` 提供了更清晰的构造、继承和私有字段语法，但没有改变底层模型。设计对象时，应区分自有状态与共享行为，谨慎处理浅复制、`this` 和可变共享数据，并在继承与组合之间选择更符合业务关系的方案。
