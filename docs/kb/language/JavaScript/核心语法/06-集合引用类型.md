# 集合引用类型

> 章节映射：《JavaScript 高级程序设计》第 4 版第 6 章，重点覆盖数组、Map、Set 与二进制数据。

## 学习目标

- 根据数据语义选择 Object、Array、Map、Set
- 掌握数组的查询、转换、排序与不可变更新
- 理解弱集合的用途和限制
- 了解 TypedArray、ArrayBuffer 等二进制集合的基本模型

## 1. 先按语义选择集合

JavaScript 常用集合各有适用场景：

| 类型 | 适用场景 | 键或元素特点 |
| --- | --- | --- |
| `Object` | 结构固定的记录 | 字符串或 Symbol 属性键 |
| `Array` | 有序列表 | 数字索引，可重复 |
| `Map` | 动态键值映射 | 任意类型键，按插入顺序迭代 |
| `Set` | 唯一值集合 | 值唯一，按插入顺序迭代 |
| `WeakMap` | 对象关联元数据 | 对象键，不可枚举，不阻止回收 |
| `WeakSet` | 弱引用对象成员标记 | 对象值，不可枚举 |

不要只因为熟悉对象就用对象解决全部集合问题。数据有固定字段时对象更直观；键动态增长、键不是字符串或需要可靠迭代时优先 `Map`。

## 2. Object：表达记录

对象字面量适合表示一个实体或配置。计算属性、展开语法和解构能简化读写。

```js
const field = "displayName";
const user = {
  id: 7,
  [field]: "Ada",
  role: "editor",
};

const { id, role = "viewer", ...publicProfile } = user;
const updated = { ...user, role: "admin" };

console.log(id, role, publicProfile, updated);
```

遍历自身可枚举字符串属性：

```js
const scores = { math: 95, language: 88 };
for (const [subject, score] of Object.entries(scores)) {
  console.log(`${subject}: ${score}`);
}
```

对象展开是浅复制。动态外部键写入普通对象时应关注 `__proto__` 等特殊键风险；字典场景可使用 `Map`，或在确有需要时使用 `Object.create(null)`。

## 3. Array：有序可重复列表

数组可通过字面量、`Array.from()` 和 `Array.of()` 创建。应避免创建稀疏数组，因为很多方法对“空槽”和显式 `undefined` 的处理不同。

```js
const range = Array.from({ length: 5 }, (_, index) => index + 1);
const values = Array.of(3, 7, 9);
console.log(range, values);
```

### 3.1 增删与查询

`push/pop` 操作尾部，`shift/unshift` 操作头部；频繁头部操作可能移动大量元素。`find` 返回元素，`findIndex` 返回位置，`some/every` 判断条件。

```js
const tasks = [
  { id: 1, done: false },
  { id: 2, done: true },
];

console.log(tasks.find((task) => task.id === 2));
console.log(tasks.some((task) => !task.done));
console.log(tasks.every((task) => task.done));
```

`includes` 能正确匹配 `NaN`，通常比 `indexOf(value) !== -1` 更能表达成员判断。

### 3.2 转换与聚合

`map` 一对一转换，`filter` 筛选，`flatMap` 转换后展开一层，`reduce` 聚合。不要为了“函数式”把简单循环写成难读的 `reduce`。

```js
const orders = [
  { id: 1, items: [{ price: 20 }, { price: 30 }] },
  { id: 2, items: [{ price: 15 }] },
];

const prices = orders.flatMap((order) => order.items.map((item) => item.price));
const total = prices.reduce((sum, price) => sum + price, 0);
console.log(prices, total); // [20, 30, 15] 65
```

### 3.3 修改型与复制型方法

`sort`、`reverse`、`splice`、`fill` 会修改原数组。现代环境提供 `toSorted`、`toReversed`、`toSpliced`、`with` 等复制型方法，使用前应核对目标环境。

```js
const numbers = [10, 2, 30];
const ascending = numbers.toSorted((a, b) => a - b);
console.log(numbers);   // [10, 2, 30]
console.log(ascending); // [2, 10, 30]

const replaced = numbers.with(1, 20);
console.log(replaced);  // [10, 20, 30]
```

默认排序按字符串比较，因此数值排序必须提供比较函数。

### 3.4 展开、解构与复制

```js
const first = [1, 2];
const second = [3, 4];
const merged = [...first, ...second];
const [head, ...rest] = merged;

console.log(head, rest);
```

展开只复制数组容器，元素若是对象仍共享引用。超大数组不要用 `Math.max(...items)`，参数展开可能超过引擎限制，应循环求值。

## 4. Map：真正的键值集合

`Map` 的键可以是对象、数字等任意值，提供 `size`，且迭代顺序明确。

```js
const alice = { id: 1 };
const accessCount = new Map([
  [alice, 3],
  ["anonymous", 10],
]);

accessCount.set(alice, (accessCount.get(alice) ?? 0) + 1);

for (const [key, count] of accessCount) {
  console.log(key, count);
}
```

对象键按身份比较，而不是按内容比较：

```js
const map = new Map();
map.set({ id: 1 }, "value");
console.log(map.get({ id: 1 })); // undefined，这是另一个对象
```

若业务键有稳定 ID，通常直接使用 ID 作为键更易序列化和调试。Map 转换为对象可用 `Object.fromEntries(map)`，前提是键适合作为对象属性。

## 5. Set：表达唯一性

`Set` 适合去重、成员判断和集合运算。成员比较类似严格相等，但 `NaN` 能与自身匹配，`-0` 与 `0` 视为相同。

```js
const tags = new Set(["js", "web", "js"]);
tags.add("core");
console.log(tags.has("js")); // true
console.log([...tags]);      // ["js", "web", "core"]
```

基础集合运算可清晰实现：

```js
function intersection(left, right) {
  return new Set([...left].filter((value) => right.has(value)));
}

const frontend = new Set(["js", "css", "html"]);
const required = new Set(["js", "sql"]);
console.log([...intersection(frontend, required)]); // ["js"]
```

部分现代运行时已提供 `Set.prototype.intersection` 等方法，但部署前应检查兼容性。

## 6. WeakMap 与 WeakSet

弱集合只接受对象（以及环境支持时的非注册 Symbol）作为键或值，且不可遍历。其主要价值是保存不会延长对象生命周期的关联信息。

```js
const privateData = new WeakMap();

class Session {
  constructor(token) {
    privateData.set(this, { token });
  }

  isAuthenticated() {
    return Boolean(privateData.get(this).token);
  }
}

const session = new Session("secret");
console.log(session.isAuthenticated());
```

现代类私有字段通常比 WeakMap 更直接；WeakMap 更适合在不修改对象的情况下附加跨模块元数据。

## 7. ArrayBuffer、TypedArray 与 DataView

二进制数据处理用于文件、网络协议、Canvas、WebGL 等场景。`ArrayBuffer` 是固定长度字节区，TypedArray 提供按特定数值类型访问的视图。

```js
const buffer = new ArrayBuffer(4);
const bytes = new Uint8Array(buffer);
bytes.set([0x48, 0x69, 0x21, 0x00]);

console.log(bytes); // Uint8Array [72, 105, 33, 0]
console.log(new TextDecoder().decode(bytes)); // "Hi!\0"
```

`DataView` 适合读取混合类型并显式指定字节序：

```js
const packet = new ArrayBuffer(6);
const view = new DataView(packet);
view.setUint16(0, 513, false); // 大端序
view.setUint32(2, 100_000, false);

console.log(view.getUint16(0, false));
console.log(view.getUint32(2, false));
```

TypedArray 的 `map` 等方法仍返回同类定长视图，其语义与普通数组并不完全相同。

## 常见陷阱与最佳实践

- **用对象存任意动态键**：需要任意键、频繁增删或可靠迭代时使用 `Map`。
- **数值数组直接 `sort()`**：传入 `(a, b) => a - b`。
- **误以为 `map` 会修改原数组**：它返回新数组；需要副作用时通常用循环或 `forEach`。
- **在 `map` 回调忘记返回值**：结果会是一组 `undefined`。
- **使用稀疏数组**：用 `Array.from` 或 `fill` 创建明确元素。
- **误以为 Set 能按对象内容去重**：对象仍按引用身份比较，应按 ID 或序列化键去重。
- **把 WeakMap 用于可枚举业务数据**：弱集合不能列出内容，也无法观察回收时机。
- **混淆字节与元素长度**：二进制处理中明确 `byteLength`、偏移、数值宽度和字节序。

## 章节小结

集合类型的选择应由数据语义决定：对象表达记录，数组表达顺序，Map 表达动态映射，Set 表达唯一成员，弱集合表达不影响生命周期的关联，TypedArray 系列处理二进制。理解修改型方法、引用身份和迭代顺序，可以避免大量隐蔽状态错误。
