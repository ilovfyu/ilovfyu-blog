# JavaScript 语言基础

> 章节映射：《JavaScript 高级程序设计》第 4 版第 3 章，侧重现代语法与可维护性。

## 学习目标

- 掌握声明、数据类型、转换、运算符和控制流
- 理解严格相等、短路求值与空值处理
- 能编写边界明确、意图清晰的函数
- 避免隐式转换、浮点数和旧式声明带来的问题

## 1. 语句、标识符与严格模式

JavaScript 区分大小写，标识符可包含字母、数字、`_`、`$`，但不能以数字开头。项目中应采用一致命名规则：变量与函数用 `camelCase`，类用 `PascalCase`，常量是否全大写取决于它是否真是跨模块不变量。

模块天然运行在严格模式。经典脚本可用 `"use strict"` 开启，但现代项目优先使用模块。

```js
"use strict";

const maxRetries = 3;
function createMessage(userName) {
  return `欢迎，${userName}`;
}

console.log(createMessage("Ada"), maxRetries);
```

分号自动插入并不等于可以忽略语句边界。项目应统一格式；`return` 后不要换行再写返回值。

## 2. const、let 与 var

默认使用 `const`，需要重新赋值时使用 `let`。两者都是块级作用域，并存在暂时性死区。`var` 具有函数作用域和声明提升，主要用于理解遗留代码。

```js
const settings = { theme: "light" };
settings.theme = "dark"; // 可以修改对象内容
// settings = {};         // 不可重新绑定

let remaining = 2;
remaining -= 1;
console.log(settings.theme, remaining);
```

`const` 保证绑定不变，不保证对象深度不可变。若业务要求不可变，应通过复制更新、封装或冻结策略实现。

## 3. 七种原始类型与对象

原始类型包括 `undefined`、`null`、`boolean`、`number`、`string`、`symbol`、`bigint`，除此以外都是对象。原始值按值使用，对象变量保存的是引用。

```js
const values = [undefined, null, true, 42, "hi", Symbol("id"), 10n, {}];
for (const value of values) {
  console.log(String(value), typeof value);
}
// 注意：typeof null 历史上返回 "object"
```

判断数组使用 `Array.isArray()`；判断 `null` 直接使用 `value === null`。不要用 `typeof` 细分所有对象类型。

## 4. Number、BigInt 与数值边界

JavaScript 的普通数字采用 IEEE 754 双精度浮点表示，整数只有在安全范围内才能精确表示。

```js
console.log(0.1 + 0.2 === 0.3); // false
console.log(Number.isSafeInteger(9_007_199_254_740_991)); // true

const cents = 10 + 20;
console.log(cents === 30); // 金额以最小货币单位存储更可靠

const huge = 9_007_199_254_740_993n;
console.log(huge + 1n);
```

`BigInt` 适合超大整数，但不能与 `Number` 直接混算，也不解决小数问题。高精度金额应根据业务使用整数或专门的十进制定点库。

`NaN` 表示无法得到有效数值，且不等于自身：

```js
const input = Number("not-a-number");
console.log(Number.isNaN(input)); // true
console.log(Number.isFinite(42)); // true
```

优先使用 `Number.isNaN` 与 `Number.isFinite`，避免全局版本先做隐式转换。

## 5. 字符串、模板字面量与 Symbol

字符串不可变。模板字面量适合插值和多行文本，但插值结果仍需根据 HTML、URL、SQL 等目标上下文正确转义。

```js
const product = "键盘";
const quantity = 2;
console.log(`${product} × ${quantity}`);

const publicId = Symbol("id");
const record = { [publicId]: 1001, id: "visible" };
console.log(record[publicId], record.id);
```

`Symbol` 常用于创建不易冲突的属性键和实现语言协议，不应把它当作安全的私有字段。

## 6. 显式转换优于猜测

`Boolean`、`Number`、`String` 可显式转换。假值只有 `false`、`0`、`-0`、`0n`、`""`、`null`、`undefined`、`NaN`；空数组和空对象都是真值。

```js
const rawCount = "12";
const count = Number(rawCount);

if (!Number.isInteger(count) || count < 0) {
  throw new TypeError("count 必须是非负整数");
}

console.log(count + 1); // 13
```

解析完整数值优先使用 `Number()`；需要从带单位文本开头提取整数时才使用 `Number.parseInt(text, 10)`。

## 7. 相等、短路与空值

默认使用严格相等 `===` 和 `!==`，避免宽松相等的复杂转换规则。仅在团队明确约定时，可用 `value == null` 同时判断 `null` 与 `undefined`。

```js
console.log(0 === false); // false
console.log("5" === 5);  // false

const config = { retries: 0, label: "" };
console.log(config.retries ?? 3); // 0
console.log(config.label || "默认标签"); // 默认标签
```

`??` 仅把 `null` 和 `undefined` 视为缺失；`||` 会把所有假值视为缺失。保存 `0`、`false`、空字符串时通常应选 `??`。

可选链应只用于“确实可选”的路径：

```js
const user = { profile: { city: "杭州" } };
console.log(user.profile?.city ?? "未知");
```

## 8. 控制流与迭代

控制流应优先清晰表达业务分支。数组遍历通常选择 `for...of`；对象可枚举键使用 `Object.keys/entries`；`for...in` 会遍历继承的可枚举属性，普通业务代码慎用。

```js
const orders = [120, 0, 88];
let total = 0;

for (const amount of orders) {
  if (amount < 0) continue;
  total += amount;
}

console.log(total); // 208
```

`switch` 使用严格匹配，适合有限离散值；每个分支应明确 `break`、`return` 或注释说明贯穿。

## 9. 函数是值

函数可赋给变量、作为参数传递或作为返回值。参数按值传递；传入对象时，复制的是引用这个值。

```js
function normalizeName(name = "") {
  return name.trim().toLocaleLowerCase("zh-CN");
}

function uniqueBy(items, getKey) {
  const seen = new Set();
  return items.filter((item) => {
    const key = getKey(item);
    if (seen.has(key)) return false;
    seen.add(key);
    return true;
  });
}

console.log(uniqueBy([{ id: 1 }, { id: 1 }, { id: 2 }], (item) => item.id));
```

函数应尽量接收明确输入并返回明确结果。参数过多时可用配置对象，但不要为了“灵活”接受多套模糊签名。

## 常见陷阱与最佳实践

- **默认使用 `var`**：新代码用 `const`，确需重新赋值才用 `let`。
- **依赖 `==` 隐式转换**：边界处显式转换，业务判断用严格相等。
- **用 `||` 设置所有默认值**：如果 `0`、`false`、`""` 有意义，使用 `??`。
- **直接比较浮点计算结果**：使用容差、整数最小单位或十进制库。
- **用 `typeof null` 判断对象**：先排除 `null`，数组用 `Array.isArray`。
- **滥用可选链掩盖错误**：必需依赖缺失时应尽早抛错，而不是一路返回 `undefined`。
- **忘记 `switch` 的贯穿行为**：显式终止每个分支。
- **信任外部输入类型**：URL、表单、JSON、存储内容都应在边界验证。

## 章节小结

可靠的 JavaScript 基础来自明确声明、理解类型边界、减少隐式转换以及选择与业务语义匹配的运算符。现代代码默认采用模块、`const`、严格相等、显式转换与清晰控制流。下一章将进一步解释这些变量在作用域中如何生存，以及对象如何被内存管理。
