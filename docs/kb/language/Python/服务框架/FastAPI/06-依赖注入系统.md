> 基线：FastAPI 0.141.1、Python 3.10+、Pydantic v2，类型声明统一使用 `Annotated`。

依赖注入（Dependency Injection，DI）把“如何取得某个值或资源”从路径操作中抽离。FastAPI 不需要容器注册表：任何可调用对象都可以是依赖，函数参数签名就是声明，返回值会被注入。

## 1. 依赖图如何执行

```python
from typing import Annotated

from fastapi import Depends, FastAPI, Header, HTTPException

app = FastAPI()


def read_token(x_token: Annotated[str | None, Header()] = None) -> str:
    if x_token != "demo-token":
        raise HTTPException(status_code=401, detail="Invalid token")
    return x_token


def read_tenant(
    token: Annotated[str, Depends(read_token)],
    x_tenant: Annotated[str, Header()],
) -> str:
    # read_tenant 的 subdependency 是 read_token。
    return x_tenant


@app.get("/items/{item_id}")
def read_item(
    item_id: int,
    tenant: Annotated[str, Depends(read_tenant)],
) -> dict[str, str | int]:
    return {"item_id": item_id, "tenant": tenant}
```

请求 `/items/1` 时，FastAPI 从路径操作向下构建有向无环依赖图：`read_item -> read_tenant -> read_token`。它递归分析每个签名，对路径、查询、请求头、Cookie、Body 等执行同一套提取、转换和校验，然后由叶子向根执行。依赖的参数与路径操作参数一样会进入 OpenAPI。

依赖函数既可同步也可异步；FastAPI 会等待 `async def`，并把普通 `def` 放进线程池。不要手动调用 `read_tenant()` 来“复用依赖”，否则不会发生注入。

## 2. 请求内缓存

同一个请求中，同一依赖节点默认只执行一次，结果供所有引用者复用：

```python
from typing import Annotated
from uuid import uuid4

from fastapi import Depends, FastAPI

app = FastAPI()


def request_id() -> str:
    return str(uuid4())


RequestId = Annotated[str, Depends(request_id)]


@app.get("/cache")
def cache_demo(first: RequestId, second: RequestId) -> dict[str, str]:
    return {"first": first, "second": second}  # 两者相同


@app.get("/no-cache")
def no_cache_demo(
    first: RequestId,
    second: Annotated[str, Depends(request_id, use_cache=False)],
) -> dict[str, str]:
    return {"first": first, "second": second}  # 通常不同
```

这是**单请求缓存**，不是跨请求缓存，也不是参数化结果缓存。数据库 Session 等请求级资源通常应保留默认缓存；随机数、即时读取等确需重复执行的操作才使用 `use_cache=False`。依赖产生副作用时，不应依赖“图中恰好只运行一次”来保证业务幂等。

## 3. 类依赖与可调用实例

类本身可调用（调用会构造实例），因此可直接交给 `Depends`：

```python
from typing import Annotated

from fastapi import Depends, FastAPI, Query

app = FastAPI()


class Page:
    def __init__(
        self,
        offset: Annotated[int, Query(ge=0)] = 0,
        limit: Annotated[int, Query(ge=1, le=100)] = 20,
    ) -> None:
        self.offset = offset
        self.limit = limit


@app.get("/items")
def list_items(page: Annotated[Page, Depends(Page)]) -> dict[str, int]:
    return {"offset": page.offset, "limit": page.limit}
```

带配置的可调用实例适合参数化策略：

```python
class FixedQueryChecker:
    def __init__(self, expected: str) -> None:
        self.expected = expected

    def __call__(self, q: str = "") -> bool:
        return self.expected in q


checker = FixedQueryChecker("fastapi")


@app.get("/check")
def check(ok: Annotated[bool, Depends(checker)]) -> dict[str, bool]:
    return {"ok": ok}
```

不要在全局依赖实例里保存请求可变状态；应用对象会被多个请求并发共享。

## 4. 路由装饰器、Router 与全局依赖

只需要执行校验、不需要返回值时，把依赖放在 `dependencies` 中，避免未使用形参：

```python
from fastapi import APIRouter, Depends, FastAPI, Header, HTTPException


def verify_key(x_api_key: str = Header()) -> None:
    if x_api_key != "secret":
        raise HTTPException(status_code=401, detail="Bad API key")


router = APIRouter(
    prefix="/admin",
    dependencies=[Depends(verify_key)],  # 本 Router 全部路径
)


@router.get("/status", dependencies=[Depends(lambda: None)])
def status() -> dict[str, bool]:
    return {"ok": True}


app = FastAPI(dependencies=[Depends(verify_key)])  # 整个应用
app.include_router(router)
```

三层作用域分别是路径操作、`APIRouter`、应用。它们仍进入依赖图、执行子依赖并可触发异常，只是结果不会注入形参。全局认证并不等于所有路由都适合相同策略，例如健康检查和 OAuth2 登录端点往往需公开；这时更适合把依赖放在受保护 Router，而非 `FastAPI(...)`。

## 5. `yield`：资源获取、清理与 `scope`

下面是可运行示例，展示默认请求作用域以及较早清理的函数作用域：

```python
from contextlib import AbstractContextManager
from typing import Annotated, Iterator

from fastapi import Depends, FastAPI
from fastapi.responses import StreamingResponse

app = FastAPI()


class Resource(AbstractContextManager["Resource"]):
    def __init__(self) -> None:
        self.closed = False

    def close(self) -> None:
        self.closed = True

    def __exit__(self, *args: object) -> None:
        self.close()


def get_resource() -> Iterator[Resource]:
    resource = Resource()
    try:
        yield resource
    finally:
        resource.close()


@app.get("/normal")
def normal(
    resource: Annotated[Resource, Depends(get_resource, scope="function")],
) -> dict[str, bool]:
    # scope="function"：路径函数返回后、响应发送前清理。
    return {"closed_in_handler": resource.closed}


@app.get("/stream")
def stream(
    resource: Annotated[Resource, Depends(get_resource, scope="request")],
) -> StreamingResponse:
    # scope="request"：响应发送完成后清理，流式迭代期间仍可使用。
    def rows() -> Iterator[bytes]:
        yield f"closed={resource.closed}\n".encode()

    return StreamingResponse(rows(), media_type="text/plain")
```

`yield` 前是获取阶段，`yield` 的值被注入，`finally` 是 teardown。FastAPI 内部以 context manager 方式确保成功、依赖异常和路径操作异常都能清理。

- `scope="function"`：路径操作执行完就清理，响应尚未发出。适合返回普通序列化结果后即可释放的资源。
- `scope="request"`：响应发送完才清理，适合 `StreamingResponse` 在发送期间仍需资源的场景。`yield` 依赖未指定时采用请求作用域。
- 作用域必须保持依赖图可正确退出：请求作用域的 `yield` 依赖不能依赖一个更早退出、却还需在自身 teardown 中使用的函数作用域资源。FastAPI 会拒绝不合法组合。
- teardown 中不要吞掉未知异常；需要回滚可在 `except`/`finally` 中执行，然后重新抛出。
- teardown 发生在所选阶段，不能替代应用停机时的全局资源关闭；连接池应由 lifespan 管理，单连接/Session 才由请求依赖管理。

## 6. 完整运行与测试

将任一完整代码保存为 `main.py` 后：

```bash
python -m venv .venv
source .venv/bin/activate
pip install "fastapi==0.141.1" "uvicorn[standard]" httpx pytest
uvicorn main:app --reload
```

依赖覆盖让测试不接触真实外部系统：

```python
from fastapi.testclient import TestClient

from main import app, read_token


def fake_token() -> str:
    return "test-token"


def test_item() -> None:
    app.dependency_overrides[read_token] = fake_token
    try:
        response = TestClient(app).get("/items/1", headers={"x-tenant": "acme"})
        assert response.status_code == 200
        assert response.json() == {"item_id": 1, "tenant": "acme"}
    finally:
        app.dependency_overrides.clear()
```

生产建议：依赖保持单一职责；I/O 依赖设置超时；不要把请求对象塞进全局单例；对认证失败、子依赖短路、缓存行为、teardown 和 override 清理分别测试。数据库 Session 的实际模式见 [SQL 数据库与事务](/kb/language/Python/服务框架/FastAPI/08-SQL-数据库与事务/)，应用级资源见 [异步并发后台任务与生命周期](/kb/language/Python/服务框架/FastAPI/09-异步并发后台任务与生命周期/)，配置依赖见 [大型应用配置与工程结构](/kb/language/Python/服务框架/FastAPI/10-大型应用配置与工程结构/)。
