> 基线：FastAPI 0.141.1、Python 3.10+、Pydantic v2、`Annotated`。

大型应用不等于堆叠抽象层。先按业务边界拆 Router、模型、依赖和配置，保持单向依赖；只有出现真实复用或复杂领域规则时再引入 service/repository。

## 1. 可运行的多文件结构

```text
app/
├── __init__.py
├── main.py
├── config.py
├── dependencies.py
├── routers/
│   ├── __init__.py
│   ├── items.py
│   └── users.py
├── static/
│   └── app.css
└── templates/
    └── home.html
.env.example
pyproject.toml
```

`app/config.py`：

```python
from functools import lru_cache
from typing import Literal

from pydantic import Field
from pydantic_settings import BaseSettings, SettingsConfigDict


class Settings(BaseSettings):
    app_name: str = "Example API"
    environment: Literal["local", "test", "staging", "production"] = "local"
    database_url: str = "sqlite:///./app.db"
    secret_key: str = Field(min_length=32)
    allowed_origins: list[str] = []

    model_config = SettingsConfigDict(
        env_file=".env",
        env_file_encoding="utf-8",
        env_prefix="APP_",
        extra="ignore",
    )


@lru_cache
def get_settings() -> Settings:
    # 每进程只解析一次；测试可 dependency override 并清 cache。
    return Settings()
```

Pydantic v2 已把 settings 拆到独立包 `pydantic-settings`。环境变量优先于 `.env`；`.env` 是开发便利，不是生产 secret manager。使用前缀后变量名例如 `APP_SECRET_KEY`、`APP_DATABASE_URL`。复杂列表可用 JSON：`APP_ALLOWED_ORIGINS='["https://example.com"]'`。

`app/dependencies.py`：

```python
from typing import Annotated

from fastapi import Depends, Header, HTTPException

from app.config import Settings, get_settings

SettingsDep = Annotated[Settings, Depends(get_settings)]


def require_api_key(
    settings: SettingsDep,
    x_api_key: Annotated[str | None, Header()] = None,
) -> None:
    if x_api_key != settings.secret_key:
        raise HTTPException(status_code=401, detail="Invalid API key")
```

`app/routers/items.py`：

```python
from typing import Annotated

from fastapi import APIRouter, Path
from pydantic import BaseModel, Field

from app.dependencies import SettingsDep

router = APIRouter(prefix="/items", tags=["items"])


class Item(BaseModel):
    id: int
    name: str = Field(min_length=1, max_length=100)


@router.get("/{item_id}", response_model=Item)
def read_item(
    item_id: Annotated[int, Path(ge=1)],
    settings: SettingsDep,
) -> Item:
    return Item(id=item_id, name=f"{settings.app_name} item")
```

`app/routers/users.py`：

```python
from fastapi import APIRouter

router = APIRouter(prefix="/users", tags=["users"])


@router.get("/me")
def read_me() -> dict[str, str]:
    return {"username": "demo"}
```

`app/main.py`：

```python
from contextlib import asynccontextmanager
from pathlib import Path
from typing import AsyncIterator

from fastapi import Depends, FastAPI, Request
from fastapi.responses import HTMLResponse
from fastapi.staticfiles import StaticFiles
from fastapi.templating import Jinja2Templates

from app.config import get_settings
from app.dependencies import require_api_key
from app.routers import items, users

BASE_DIR = Path(__file__).resolve().parent
templates = Jinja2Templates(directory=BASE_DIR / "templates")


@asynccontextmanager
async def lifespan(app: FastAPI) -> AsyncIterator[None]:
    # 在这里创建共享池；若初始化失败，让启动失败。
    yield
    # 在这里关闭共享池。


settings = get_settings()
app = FastAPI(title=settings.app_name, lifespan=lifespan)

app.mount(
    "/static",
    StaticFiles(directory=BASE_DIR / "static"),
    name="static",
)

app.include_router(items.router, prefix="/api/v1")
app.include_router(
    users.router,
    prefix="/api/v1",
    dependencies=[Depends(require_api_key)],
)


@app.get("/", response_class=HTMLResponse, include_in_schema=False)
def home(request: Request) -> HTMLResponse:
    return templates.TemplateResponse(
        request=request,
        name="home.html",
        context={"title": settings.app_name},
    )


@app.get("/health", tags=["operations"])
def health() -> dict[str, str]:
    return {"status": "ok"}
```

`app/templates/home.html`：

```html
<!doctype html>
&lt;html lang="zh-CN"&gt;

```

`.env.example`（只放占位符）：

```dotenv
APP_ENVIRONMENT=local
APP_SECRET_KEY=replace-with-at-least-32-random-characters
APP_DATABASE_URL=sqlite:///./app.db
APP_ALLOWED_ORIGINS=["http://localhost:3000"]
```

`pyproject.toml` 的最小依赖片段：

```toml
[project]
name = "example-api"
version = "0.1.0"
requires-python = ">=3.10"
dependencies = [
  "fastapi==0.141.1",
  "uvicorn[standard]",
  "pydantic-settings",
  "jinja2",
]
```

```bash

source .venv/bin/activate
pip install -e .
cp .env.example .env
uvicorn app.main:app --reload
```

## 2. `APIRouter` 与 `include_router`

`APIRouter` 是一组路径操作，不是独立应用。`include_router()` 在启动导入阶段把路由合入主应用，可以添加 `prefix`、`tags`、`dependencies`、`responses` 等元数据。同一个 Router 甚至可用不同前缀包含多次，但要避免 operation ID 冲突。

推荐：

- Router 按业务能力拆分，而不是机械按 HTTP method 拆分。
- `main.py` 只做 composition root：创建 app、中间件、lifespan、mount 和 include。
- Router 依赖 config/dependency/service；底层模块不要反向 import `app`，否则容易循环导入。
- 路由前缀放在 Router 或 `include_router` 一处清晰管理。最终路径是两者拼接。
- 导入 Router 模块时避免连接数据库、执行迁移等副作用；资源初始化放 lifespan。

## 3. 配置、环境与缓存陷阱

`@lru_cache` 保证当前进程复用同一 Settings，减少反复解析；多 worker 仍各有一份。环境变量在进程启动后变化不会自动刷新，这通常正是不可变配置所需行为。

测试覆盖配置：

```python
from fastapi.testclient import TestClient

from app.config import Settings, get_settings
from app.main import app


def test_custom_title() -> None:
    def test_settings() -> Settings:
        return Settings(
            app_name="Test API",
            environment="test",
            secret_key="x" * 32,
            _env_file=None,
        )

    app.dependency_overrides[get_settings] = test_settings
    try:
        with TestClient(app) as client:
            response = client.get("/api/v1/items/1")
        assert response.json()["name"] == "Test API item"
    finally:
        app.dependency_overrides.clear()
        get_settings.cache_clear()
```

注意示例 `main.py` 的 `settings = get_settings()` 在导入时用于 app 标题和模板页，这部分不会被依赖 override 替换；需要完全可测试的配置时，使用 app factory `create_app(settings)`，或只在 lifespan/app state 初始化。不要为了测试任意修改进程环境而忘记 `cache_clear()`。

生产中：开发、测试、预发、生产使用同一构建产物，以环境注入差异；启动时校验必需配置并快速失败；secret 不打印、不进入 OpenAPI、不提交 `.env`。若设置 CORS，明确列出 origin；带 credentials 时不能用通配符幻想“全部允许”。

## 4. 静态文件与模板

`StaticFiles` 是一个挂载的 ASGI 应用，路径内部独立于 API Router。`Jinja2Templates` 负责服务端模板渲染；模板默认自动转义 HTML，但把用户输入标为 `safe` 会绕过保护。生产中大量静态资源通常交给 CDN/反向代理，设置指纹文件名和缓存头；不要允许用户控制任意文件路径。

模板和静态目录用 `Path(__file__)` 定位，而不是依赖启动命令的当前工作目录。测试既要断言状态码，也要检查 content type、关键 HTML 与不存在文件的 404。

## 5. mount 子应用与 WSGI 边界

`mount` 把某个路径前缀交给另一个完整 ASGI 应用。子应用有自己的 OpenAPI、文档、中间件、异常处理和路由命名空间；这与 `include_router` 将路由合并进同一个应用不同。

```python
from fastapi import FastAPI

app = FastAPI(title="Main")
admin = FastAPI(title="Admin")


@admin.get("/status")
def admin_status() -> dict[str, bool]:
    return {"ok": True}


app.mount("/admin", admin)
```

此时子应用文档在 `/admin/docs`。主应用的 dependencies/middleware 传播语义与 Router 不同，不要假定认证自动覆盖子应用；应显式测试 root path、反向代理前缀和 lifespan。

旧 Flask/Django 等 WSGI 应用可通过 `a2wsgi.WSGIMiddleware`（或框架推荐适配器）挂载。WSGI 是同步请求/响应模型，不支持原生 ASGI WebSocket，流式、取消和 lifespan 语义也受适配层限制：

```python
from a2wsgi import WSGIMiddleware
from flask import Flask

legacy = Flask(__name__)


@legacy.get("/")
def legacy_home() -> str:
    return "legacy"


app.mount("/legacy", WSGIMiddleware(legacy))
```

适配适合渐进迁移，不会让 WSGI 代码变成异步。容量规划需考虑适配器线程数；身份、Session、错误格式与 tracing 跨边界通常要额外桥接。

## 6. 工程与发布建议

- 锁定依赖并在 CI 做安全更新；运行 lint、类型检查、单元和集成测试。
- OpenAPI 是契约，对 operation ID、错误模型和兼容性做测试；版本前缀不替代兼容策略。
- `/health` 区分存活与就绪。就绪检查关键依赖但设置短超时，不执行昂贵查询。
- 中间件顺序影响 CORS、异常、压缩与 tracing；统一结构化日志和 request ID，过滤敏感头。
- 应用在反向代理后部署时只信任明确代理来源，正确配置 forwarded headers 和 root path。
- 数据库迁移作为独立部署步骤，不在每个 worker 的 import/startup 中执行。
- 认证见 [安全认证与授权](/kb/language/Python/服务框架/FastAPI/07-安全认证与授权/)，Session 见 [SQL 数据库与事务](/kb/language/Python/服务框架/FastAPI/08-SQL-数据库与事务/)，资源初始化见 [异步并发后台任务与生命周期](/kb/language/Python/服务框架/FastAPI/09-异步并发后台任务与生命周期/)。
