> 基线：FastAPI 0.141.1、Python 3.10+、Pydantic v2、`Annotated`。本教程使用 PyJWT 和 pwdlib，不使用已停止维护的 Passlib 教程写法。

认证回答“你是谁”，授权回答“你能做什么”。OAuth2 Password Bearer 约定客户端用用户名/密码换取 bearer token；JWT 是 token 的一种自包含编码，不会自动加密载荷，也不会自动支持撤销。

## 1. Password flow 的适用边界

Password flow 是 FastAPI 为兼容和教学保留的 legacy flow，客户端会直接看到用户密码。根据当前 OAuth 安全最佳实践，新系统即使是第一方客户端也应优先采用 Authorization Code + PKCE；设备场景采用 Device Authorization Grant，机器身份通常采用 Client Credentials。第三方应用、浏览器 SSO、企业身份联合应交给成熟身份提供商，不要把本示例扩展成自制 OAuth2 授权服务器。

即使使用 JWT，也必须全程 HTTPS。Bearer token 被窃取后，持有者无需再次证明身份。

## 2. 完整可运行的 OAuth2、JWT 与 scopes

`main.py`：

```python
from datetime import datetime, timedelta, timezone
import os
from typing import Annotated

import jwt
from fastapi import Depends, FastAPI, HTTPException, Response, Security, status
from fastapi.responses import JSONResponse
from fastapi.security import OAuth2PasswordBearer, OAuth2PasswordRequestForm, SecurityScopes
from jwt.exceptions import InvalidTokenError
from pwdlib import PasswordHash
from pydantic import BaseModel, Field, ValidationError

SECRET_KEY = os.environ["SECRET_KEY"]
ALGORITHM = "HS256"
ACCESS_TOKEN_EXPIRE_MINUTES = 15

password_hash = PasswordHash.recommended()
DUMMY_HASH = password_hash.hash("dummy-password")


class User(BaseModel):
    username: str
    disabled: bool = False
    scopes: list[str] = Field(default_factory=list)


class UserInDB(User):
    hashed_password: str


class Token(BaseModel):
    access_token: str
    token_type: str
    scope: str


class TokenClaims(BaseModel):
    sub: str
    scope: str = ""


# 演示数据只存在内存。生产环境从数据库读取，绝不保存明文密码。
fake_users_db = {
    "alice": {
        "username": "alice",
        "disabled": False,
        "scopes": ["items:read", "items:write"],
        # 示例启动时生成，便于代码直接运行；真实哈希在注册/改密时生成并持久化。
        "hashed_password": password_hash.hash("secret"),
    }
}

oauth2_scheme = OAuth2PasswordBearer(
    tokenUrl="token",  # OpenAPI 中的相对 URL，不是 Python 函数地址
    scopes={
        "items:read": "读取物品",
        "items:write": "修改物品",
    },
)

app = FastAPI()


def get_user(username: str) -> UserInDB | None:
    record = fake_users_db.get(username)
    return UserInDB(**record) if record else None


def authenticate_user(username: str, password: str) -> UserInDB | None:
    user = get_user(username)
    # 对不存在的用户也验证一次固定哈希，降低用户名枚举的计时差异。
    if user is None:
        password_hash.verify(password, DUMMY_HASH)
        return None
    if not password_hash.verify(password, user.hashed_password):
        return None
    return user


def create_access_token(subject: str, scopes: list[str]) -> str:
    now = datetime.now(timezone.utc)
    payload = {
        "sub": subject,
        "scope": " ".join(scopes),
        "iat": now,
        "exp": now + timedelta(minutes=ACCESS_TOKEN_EXPIRE_MINUTES),
    }
    return jwt.encode(payload, SECRET_KEY, algorithm=ALGORITHM)


async def get_current_user(
    security_scopes: SecurityScopes,
    token: Annotated[str, Depends(oauth2_scheme)],
) -> User:
    authenticate_value = "Bearer"
    if security_scopes.scopes:
        authenticate_value = f'Bearer scope="{security_scopes.scope_str}"'

    credentials_error = HTTPException(
        status_code=status.HTTP_401_UNAUTHORIZED,
        detail="Could not validate credentials",
        headers={"WWW-Authenticate": authenticate_value},
    )
    try:
        payload = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])
        claims = TokenClaims.model_validate(payload)
        username = claims.sub
        token_scopes = claims.scope.split()
    except (InvalidTokenError, ValidationError):
        raise credentials_error

    user = get_user(username)
    if user is None:
        raise credentials_error

    for scope in security_scopes.scopes:
        if scope not in token_scopes:
            raise HTTPException(
                status_code=status.HTTP_403_FORBIDDEN,
                detail="Not enough permissions",
                headers={
                    "WWW-Authenticate": (
                        'Bearer error="insufficient_scope", '
                        f'scope="{security_scopes.scope_str}"'
                    )
                },
            )
    if user.disabled:
        raise HTTPException(status_code=403, detail="Inactive user")
    return user


@app.post("/token", response_model=Token)
def login(
    form: Annotated[OAuth2PasswordRequestForm, Depends()],
    response: Response,
):
    user = authenticate_user(form.username, form.password)
    if user is None:
        return JSONResponse(
            status_code=status.HTTP_400_BAD_REQUEST,
            content={"error": "invalid_grant"},
            headers={"Cache-Control": "no-store", "Pragma": "no-cache"},
        )

    # 本示例拒绝未知或用户不拥有的 scope，避免静默缩小授权范围。
    requested = set(form.scopes)
    if requested and not requested.issubset(set(user.scopes)):
        return JSONResponse(
            status_code=status.HTTP_400_BAD_REQUEST,
            content={"error": "invalid_scope"},
            headers={"Cache-Control": "no-store", "Pragma": "no-cache"},
        )
    granted = list(form.scopes) if requested else user.scopes
    scope = " ".join(granted)
    response.headers["Cache-Control"] = "no-store"
    response.headers["Pragma"] = "no-cache"
    return Token(
        access_token=create_access_token(user.username, granted),
        token_type="bearer",
        scope=scope,
    )


@app.get("/items")
async def read_items(
    user: Annotated[User, Security(get_current_user, scopes=["items:read"])],
) -> dict[str, str]:
    return {"owner": user.username}


@app.post("/items")
async def create_item(
    user: Annotated[User, Security(get_current_user, scopes=["items:write"])],
) -> dict[str, str]:
    return {"created_by": user.username}
```

运行：

```bash
python -m venv .venv
source .venv/bin/activate
pip install "fastapi==0.141.1" "uvicorn[standard]" "pyjwt>=2.8" "pwdlib[argon2]" python-multipart
export SECRET_KEY="$(openssl rand -hex 32)"
uvicorn main:app --reload

curl -X POST http://127.0.0.1:8000/token \
  -H 'Content-Type: application/x-www-form-urlencoded' \
  -d 'username=alice&password=secret&scope=items%3Aread'
```

`OAuth2PasswordRequestForm` 接收表单而非 JSON，因此需要 `python-multipart`。`Security` 是 `Depends` 的扩展：它将所需 scope 传给 `SecurityScopes`，并把授权需求写入 OpenAPI。登录端点使用普通 `def`，让同步且昂贵的 Argon2 验证进入 FastAPI 线程池；若端点必须是 `async def`，应通过 `await anyio.to_thread.run_sync(...)` 隔离密码验证，并限制登录并发与速率。

## 3. 401 与 403

- `401 Unauthorized` 实际表示“未认证”：缺少、过期、签名错误或格式错误的凭据。应带合适的 `WWW-Authenticate`。
- `403 Forbidden` 表示身份已确认，但账号禁用、角色或 scope 不足。通常不应把有效凭据误报为 401。
- 登录失败统一返回“用户名或密码错误”，避免账户枚举。
- 不把 JWT 解码错误、数据库细节或 scope 全量暴露给客户端；服务端日志可记录安全事件，但不得记录密码和完整 token。

## 4. HTTP Basic

Basic 每次请求都发送 Base64 编码的 `username:password`，Base64 **不是加密**。它适合 HTTPS 后简单内部工具、临时运维入口或与旧系统兼容，不适合复杂用户会话。

```python
import secrets
from typing import Annotated

from fastapi import Depends, FastAPI, HTTPException, status
from fastapi.security import HTTPBasic, HTTPBasicCredentials

app = FastAPI()
security = HTTPBasic()


def current_name(
    credentials: Annotated[HTTPBasicCredentials, Depends(security)],
) -> str:
    username_ok = secrets.compare_digest(
        credentials.username.encode(), b"admin"
    )
    password_ok = secrets.compare_digest(
        credentials.password.encode(), b"change-me"
    )
    if not (username_ok and password_ok):
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="Invalid credentials",
            headers={"WWW-Authenticate": "Basic"},
        )
    return credentials.username


@app.get("/basic")
def basic(name: Annotated[str, Depends(current_name)]) -> dict[str, str]:
    return {"username": name}
```

示例中的常量仅用于演示；生产中也应存密码哈希，而非可比较的明文。

## 5. 密码、JWT 与密钥安全

- 使用 pwdlib 推荐的 Argon2 参数；只存盐化哈希。验证后若 `password_hash.verify_and_update()` 返回新哈希，应升级持久化哈希参数。
- JWT 载荷仅 Base64URL 编码，任何持有者都能读；不要放密码、密钥、身份证号等敏感信息。
- `jwt.decode` 固定允许的 `algorithms`，不要根据 token 头部动态信任算法。
- 对称 HS256 密钥至少使用高熵随机值，经环境变量或 secret manager 注入，不能提交 Git。多服务场景可考虑非对称签名与 `kid` 轮换。
- access token 短期有效；需要长期登录时设计一次性、可轮换、可撤销的 refresh token。JWT 的 `exp` 不会提供主动撤销；高风险系统需版本号、denylist 或服务器会话。
- 校验 `exp`，跨系统还应校验 `iss`、`aud`、时钟偏差；使用 UTC。
- 浏览器若将 token 放 Cookie，要同时考虑 `HttpOnly`、`Secure`、`SameSite` 与 CSRF；放 `localStorage` 会扩大 XSS 后果。
- 登录接口做速率限制、审计和异常告警。认证数据库查询、密码哈希成本与 worker 容量都要压测。

## 6. 测试清单

使用 `TestClient` 覆盖：正确密码、错误密码、未知用户、过期 token、篡改签名、缺失 `sub`、scope 缺失、禁用用户、成功的 401/403 区分及 `WWW-Authenticate`。测试密钥必须与生产隔离；不要通过降低生产哈希参数来加速测试，可在测试应用中注入独立 hasher。
