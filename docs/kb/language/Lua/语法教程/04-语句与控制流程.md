## Block、空语句与赋值

block 是顺序执行的语句列表。`do ... end` 创建显式块，常用于缩小局部变量作用域。分号通常可省略，但以 `(` 开头的新语句可能与上一行函数调用产生语法歧义，此时应写 `;(...)`。

Lua 支持多重赋值，右侧先求值并调整数量，再执行写入：

```lua
local x, y = 10, 20
x, y = y, x

local a = {}
local i = 3
i, a[i] = i + 1, 99
assert(i == 4 and a[3] == 99)
```

变量多于值时补 nil；值多于变量时丢弃，最后表达式的多返回行为见下一章。

## 条件语句

```lua
local score = 87
if score >= 90 then
  print("A")
elseif score >= 80 then
  print("B")
else
  print("C")
end
```

条件只把 nil 和 false 视为假，不要求 boolean。

## while 与 repeat

```lua
local n = 3
while n > 0 do
  print(n)
  n = n - 1
end

repeat
  local line = io.read("l")
  if line then print(line) end
until line == nil or line == "quit"
```

`while` 先判断；`repeat ... until` 至少执行一次。repeat 的 block 作用域延续到 until 条件之后，因此条件能访问循环体中声明的 local。

## 数值 for

```lua
for i = 1, 10, 2 do
  print(i)
end
```

初值、上限、步长只在循环开始前求值一次。省略步长时为 1。Lua 5.5 的控制变量 `i` 是只读变量，不能在循环体中赋值；若需要可变副本，应 shadow：

```lua
for i = 1, 3 do
  local i = i
  i = i * 10
  print(i)
end
```

integer 参数按 integer 循环并处理溢出终止；任一参数不是 integer 时转为 float。不要在循环体修改外部上限并期待改变次数。

## 泛型 for

```lua
local colors = {red = "#f00", green = "#0f0"}
for key, value in pairs(colors) do
  print(key, value)
end

for index, value in ipairs({"a", "b", "c"}) do
  print(index, value)
end
```

泛型 for 由迭代器函数、状态、控制值和关闭值驱动。首个循环变量是只读控制变量。`pairs` 顺序未指定；`ipairs` 从 1 连续递增，到第一个 nil 停止。

## break、goto 与标签

`break` 结束最内层循环。`goto name` 跳到可见 `::name::`，但不能跳入某个局部变量的作用域：

```lua
for i = 1, 10 do
  if i % 2 == 0 then goto continue end
  print(i)
  ::continue::
end
```

Lua 没有专门的 continue，上述局部 goto 是常见替代，但应避免跨越复杂资源作用域。

## return

函数和 chunk 都能返回多个值。语法上 return 必须是 block 的最后一条非空语句；若需要在外层 block 中间返回，可使用：

```lua
do return "early" end
```

实践中普通 if 分支内的 return 已经位于其 block 末尾，通常无需该技巧。

## 综合示例

```lua
local function classify(values)
  local result = {}
  for index, value in ipairs(values) do
    local label
    if value < 0 then
      label = "negative"
    elseif value == 0 then
      label = "zero"
    else
      label = "positive"
    end
    result[index] = label
  end
  return result
end

for i, label in ipairs(classify({-2, 0, 5})) do
  print(i, label)
end
```

## 常见错误

- 把 `0` 当作循环结束的假值。
- 在 Lua 5.5 中给 for 控制变量赋值。
- 依赖 `pairs` 遍历顺序。
- 用 `ipairs` 遍历包含 nil 空洞的数组。
- 让 goto 跳入局部变量作用域；编译器会拒绝。
- 在遍历 table 时无计划地增删键，依赖未保证的访问行为。

## 练习

1. 用 while 和数值 for 分别计算 1 到 100 的和。
2. 用 repeat 写一个至少执行一次的输入验证循环。
3. 使用局部标签模拟 continue，打印 1–20 的奇数。
4. 解释 Lua 5.5 为什么把 for 控制变量设为只读。
