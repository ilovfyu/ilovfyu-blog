# Lua 5.5 语法教程

::: abstract 版本基线
本教程以 **Lua 5.5.0** 为基线。Lua 官方版本页显示 5.5.0 发布于 2025-12-22，是当前最新稳定版本。不同 `x.y` 版本之间可能存在语言、标准库、C API、ABI 和字节码不兼容；运行示例前请用 `lua -v` 确认版本。
:::

## 教程定位

本系列根据 [Lua 5.5 Reference Manual](https://www.lua.org/manual/5.5/) 重新组织为面向学习的中文教程。参考手册是语言的官方定义，本教程负责解释心智模型、执行语义、常见错误和实践方式，不替代官方手册。

Lua 是动态类型、自动内存管理、支持多返回值和协程的可嵌入脚本语言。其核心很小：表是唯一的数据结构机制，函数是一等值，元表提供可扩展语义，宿主可通过 C API 扩展语言。

## Lua 核心心智模型

1. 变量没有类型，值有类型。
2. `nil` 和 `false` 才是假；`0` 与空字符串都是真。
3. 表保存键值关系；把键赋为 `nil` 等于删除该键。
4. 表、函数、thread 和 full userdata 按引用传递，赋值不会深拷贝。
5. 函数可返回多个值，表达式所在位置决定结果如何调整。
6. 全局变量访问本质上是当前 `_ENV` 表的字段访问。
7. 元表不是继承语法，而是值在特定事件下的行为协议。
8. 协程是显式 yield 的协作式执行，不是操作系统线程。
9. GC 管内存可达性，不保证外部资源及时释放；资源应显式关闭。
10. Lua 版本间的预编译 chunk 和 C 扩展不可假定兼容。
