> 本章以 Lua 5.5.0 独立解释器为运行环境。发行版软件仓库可能仍提供 5.4，必须先检查版本。

## 本章目标

- 理解 Lua 作为库、独立解释器和编译器的三种形态。
- 运行脚本、表达式和交互式代码。
- 理解 chunk、源代码和二进制 chunk。
- 掌握标识符、关键字、注释、字符串和数字字面量。

## 安装与版本检查

Lua 官方以源码发布 5.5.0。在 Unix-like 系统中，解压后通常执行：

```bash
make
make test
```

构建结果包括：

| 文件 | 用途 |
|---|---|
| `lua` | 独立解释器，运行源码、脚本或 REPL |
| `luac` | 检查语法、列出指令、生成预编译 chunk |
| `liblua.a` | 宿主程序嵌入 Lua 使用的库 |

验证版本：

```bash
lua -v
lua -e 'print(_VERSION)'
```

期望包含 `Lua 5.5`。不要因命令名是 `lua` 就假定版本正确。

## 第一个程序

```lua
-- hello.lua
local name = arg[1] or "Lua"
print("Hello, " .. name .. "!")
```

运行：

```bash
lua hello.lua world
luac -p hello.lua
```

`arg[0]` 通常是脚本名，`arg[1]` 起是参数。`luac -p` 只解析检查，不执行脚本。

## Chunk

chunk 是 Lua 的编译单元，语法上就是一个 block。文件、字符串和标准输入都能提供 chunk。Lua 把 chunk 当作一个可变参数匿名函数的函数体，因此它能声明局部变量、读取参数并返回值。

`load()` 先编译字符串或 reader 提供的代码，成功时返回函数，失败时返回 `nil, message`；调用返回的函数才执行代码：

```lua
local fn, err = load("return 6 * 7", "answer", "t")
assert(fn, err)
print(fn())  -- 42
```

第三个参数 `"t"` 只允许文本 chunk。加载不可信输入时不要接受二进制 chunk；官方手册明确指出恶意构造的二进制 chunk 可能使解释器崩溃。

## 标识符与关键字

标识符由拉丁字母、数字和下划线组成，不能以数字开头。Lua 区分大小写。应避免自定义以下划线加大写字母开头的名字，例如 `_VERSION`。

Lua 5.5 关键字：

```text
and break do else elseif end false for function global goto if
in local nil not or repeat return then true until while
```

`global` 是 Lua 5.5 新关键字，旧代码若把它用作变量名，迁移时会产生语法错误。

## 注释

```lua
-- 单行注释

--[[
多行注释
]]

--[=[
可包含 ]] 的更高层长注释
]=]
```

长括号可以有任意数量的等号，结束符必须层级一致。调试时常用 `--[[ ... --]]` 注释代码，但若内部已有长注释，应使用更高层 `[=[...]=]`。

## 字符串字面量

Lua 字符串是不可变字节序列，不自带编码。短字符串支持转义：

```lua
local a = "line1\nline2"
local nul = "A\0B"
local hex = "\x41"
local utf8_text = "\u{4F60}\u{597D}"
local joined = "first\z
                second"  -- \z 吞掉后续空白
```

长字符串不处理转义，并统一换行形式：

```lua
local query = [=[
SELECT * FROM users
WHERE name = "Lua"
]=]
```

紧跟开始长括号的第一个换行不计入内容。

## 数字字面量

```lua
local decimal = 42       -- integer
local float = 42.0       -- float
local scientific = 3e2   -- float
local hex = 0xff         -- integer
local hexfloat = 0x1.fp3 -- float
```

带小数点或指数的 numeral 是 float。无小数点/指数的十六进制 numeral 总是 integer，溢出时按整数宽度回绕。标准构建通常使用 64 位 integer 和双精度 float，但嵌入式构建可调整，跨环境程序不应写死宽度假设。

## 常见错误

- 用 Lua 5.4 运行含 `global` 或具名 vararg table 的 5.5 代码。
- 把字符串当 Unicode 字符数组；`#s` 默认得到字节数。
- 认为长字符串会处理 `\n`；它保留反斜杠和字母本身。
- 对不可信输入使用 `load(code, name, "bt")` 或加载未知二进制 chunk。
- 用 `luac` 生成文件后跨 Lua 版本、平台或构建配置分发。

## 练习

1. 写脚本打印 `_VERSION`、脚本名和所有命令行参数。
2. 分别用短字符串、长字符串表示含引号和换行的 JSON 示例。
3. 用 `load(..., "t")` 计算一个固定算术表达式，并处理编译错误。
4. 解释为什么 `#"你好"` 通常不是 2。
