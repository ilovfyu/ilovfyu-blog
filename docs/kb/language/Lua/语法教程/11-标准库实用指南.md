## 标准库边界

Lua 标准库刻意精简，覆盖基础操作、协程、模块、字符串、UTF-8、表、数学、I/O、操作系统和调试。网络、JSON、数据库、加密等不在标准库内，需要宿主或第三方模块。

独立解释器通常加载全部标准库；嵌入 Lua 的宿主可只开放部分库。因此库代码不应假定 `io`、`os` 或 `debug` 必然存在。

## 基础函数

| 函数 | 用途与注意点 |
|---|---|
| `type(v)` | 返回基本类型名 |
| `tostring(v)` | 字符串表示，可触发 `__tostring` |
| `tonumber(v [, base])` | 转数值；失败返回 nil |
| `assert(v, ...)` | v 为假时抛错，否则返回全部参数 |
| `error(v [, level])` | 抛错误对象 |
| `pcall/xpcall` | 保护调用 |
| `select(index, ...)` | 访问 varargs；`select("#", ...)` 得数量 |
| `next/pairs/ipairs` | table 迭代 |
| `rawget/rawset/rawlen/rawequal` | 绕过元方法 |
| `load/loadfile/dofile` | 加载/执行 chunk |
| `print` | 调试输出，不适合格式化协议 |
| `warn` | 发警告，不中断执行 |

`dofile` 无保护地加载并执行文件；模块复用通常用 `require`，动态受控代码用 `loadfile` 并检查返回值。

## math

math 库包含三角、指数、取整、随机数和数值边界。重要 API：

```lua
print(math.type(1), math.type(1.0))
print(math.mininteger, math.maxinteger)
print(math.floor(-1.2), math.ceil(-1.2))

local x = math.tointeger(3.0)
assert(x == 3)
```

Lua 5.5 恢复/提供 `math.frexp` 和 `math.ldexp`。`math.random()` 使用伪随机生成器，不应用于密码、token 或安全 nonce。`math.randomseed()` 无参数时使用系统熵初始化并返回种子；测试应设置固定种子以复现。

## table

sequence 操作见 [表数组与迭代器](/kb/language/Lua/语法教程/06-表数组与迭代器/)。Lua 5.5 新增 `table.create(nseq [, nrec])` 预留 array/hash 容量。它是性能工具，只有基准显示大量动态扩容时才需要。

`table.sort` 原地修改且不稳定。`table.unpack` 展开数量受 Lua 栈空间约束，不适合一次展开巨大数组。

## io：简单与完整模型

简单模型用当前输入/输出文件：`io.input`、`io.output`、`io.read`、`io.write`。完整模型使用显式 file handle，更适合库：

```lua
local function copy(source_path, target_path)
  local source &lt;close&gt; = assert(io.open(source_path, "rb"))
  local target &lt;close&gt; = assert(io.open(target_path, "wb"))

  while true do
    local chunk = source:read(64 * 1024)
    if not chunk then break end
    assert(target:write(chunk))
  end
end
```

常用 read 格式：`"a"` 全部、`"l"` 行不含换行、`"L"` 行含换行、`"n"` 数字、整数 n 最多 n 字节。打开模式含 `r/w/a`、可选 `+` 和 `b`；文本/二进制差异依赖平台。

`io.lines(filename)` 在循环结束时自动关闭它打开的文件；`file:lines()` 不会自动关闭已有句柄。出错时许多 I/O 函数返回 `fail, message, code`，应检查而不是只看第一个值。

## os

| API | 说明 |
|---|---|
| `os.time([table])` | 日历时间；字段解释受本地时区影响 |
| `os.date([format [, time]])` | 格式化或返回日期表；`!` 前缀使用 UTC |
| `os.difftime(t2, t1)` | 时间差 |
| `os.clock()` | 程序 CPU 时间，不是墙钟时间 |
| `os.getenv(name)` | 环境变量 |
| `os.rename/remove` | 文件系统操作 |
| `os.execute(command)` | 调 shell/系统命令，注意注入 |
| `os.tmpname()` | 生成名称，存在竞态与平台风险 |

不要拼接不可信输入到 `os.execute` 或 `io.popen`。标准库没有参数数组形式的安全进程 API，安全调用应由宿主扩展提供。

## debug

debug 库可以检查栈、局部变量、upvalue、hook、registry 和 metatable。它能破坏普通封装和部分语言假设，主要用于调试器、分析器和可信工具：

```lua
local info = debug.getinfo(1, "nSl")
print(info.short_src, info.currentline)
```

`debug.sethook` 可按调用、返回、行或指令计数触发 hook，用于分析或限制运行步数，但 hook 自身会显著影响性能。不要向不可信代码暴露 debug 库。

## 时间与可移植性

Lua 标准库对操作系统设施保持较薄封装。文件路径、locale、时区、shell 状态码和二进制 I/O 在平台间可能不同。需要稳定协议时，显式定义编码、换行、时区、端序和错误约定。

## 常见错误

- 假设嵌入式 Lua 已加载全部标准库。
- 用 `print` 生成机器协议或持久化格式。
- 忽略 I/O 的第二、第三返回值。
- 把 `os.clock()` 当当前时间或真实耗时。
- 拼接用户输入给 `os.execute`。
- 使用 `math.random` 生成安全凭据。
- 在生产业务代码中依赖 debug 修改局部变量或 metatable。

## 练习

1. 实现二进制文件复制并可靠关闭两个文件。
2. 分别输出本地时间和 UTC 时间。
3. 固定随机种子，验证一组测试随机数可复现。
4. 列出最小嵌入环境中愿意向配置脚本开放的标准库函数。
