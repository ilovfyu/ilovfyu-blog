## 表是唯一内建数据结构

table 是关联数组，键可以是除 nil 和 NaN 外的任意 Lua 值，值可以是任意值。不存在的键读取为 nil，赋 nil 删除键。

```lua
local user = {
  name = "Ada",
  ["role"] = "admin",
  [1] = "first",
}

assert(user.name == user["name"])
user.role = nil
```

整数值和数值相等的 float 键被规范为同一个 integer 键，因此 `t[1]` 与 `t[1.0]` 是同一项。

## 构造器

```lua
local array = {10, 20, 30}                -- [1], [2], [3]
local record = {name = "Lua", version = 5.5}
local mixed = {[0] = "zero", "one", key = true}
```

列表字段按 1 起连续编号。最后一个列表字段若是多结果表达式，会展开全部结果；其他字段只取一个结果。

Lua 5.5 允许更深层的构造器嵌套，并新增预分配 API：

```lua
local values = table.create(1000)       -- 预留 sequence 空间
local map = table.create(0, 200)        -- 预留 record/hash 空间
```

`table.create(nseq, nrec)` 只优化容量，不改变长度，不自动填值。代码若需兼容 5.4，应使用 `{}` 或自行提供兼容库，而不是无条件调用它。

## 数组与边界

Lua 通常用从 1 开始、无 nil 空洞的 integer keys 表示 sequence。`#t` 返回边界，不是通用元素数量。对稀疏表：

```lua
local sparse = {[1] = "a", [3] = "c"}
```

其边界可能不等于最大键或键数量。若要可靠保存 nil，用显式 `n` 字段、sentinel，或重新设计数据表示。

## Table 标准操作

| API | 用途 | 关键点 |
|---|---|---|
| `table.insert(t, [pos,] value)` | 插入 sequence | 中间插入会搬移元素 |
| `table.remove(t, [pos])` | 删除并返回 | 默认删除最后项 |
| `table.move(a, f, e, t [, dest])` | 搬移区间 | 支持重叠和跨表 |
| `table.concat(t, sep, i, j)` | 高效拼接 | 元素需是字符串或数字 |
| `table.sort(t, comp)` | 原地排序 | comparator 必须严格一致 |
| `table.pack(...)` | 保存多参数 | 用字段 `n` 保留 nil 数量 |
| `table.unpack(t, i, j)` | 展开序列 | 大范围可能超出栈限制 |
| `table.create(nseq, nrec)` | 5.5 预分配 | 不增加逻辑元素 |

排序不稳定；comparator 必须形成严格弱序，不能随机变化或写成 `a <= b`。

## 遍历

`pairs(t)` 遍历所有键，但顺序未指定。遍历期间给不存在的字段赋值，其访问行为未定义；可以修改已有字段，若需结构变更，先收集键再处理。

`ipairs(t)` 产生 `1, t[1]`、`2, t[2]`，直到第一个缺失值。

```lua
local keys = {}
for key in pairs(user) do
  keys[#keys + 1] = key
end
table.sort(keys, function(a, b) return tostring(a) < tostring(b) end)
```

## 无状态迭代器

泛型 for 接收迭代器函数、不可变状态和初始控制值：

```lua
local function step(state, index)
  index = index + 1
  local value = state[index]
  if value ~= nil then return index, value end
end

local function values(t)
  return step, t, 0
end

for index, value in values({"a", "b"}) do
  print(index, value)
end
```

这种迭代器每轮不创建新闭包。需要复杂暂停状态时，可使用闭包或 [协程](/kb/language/Lua/语法教程/09-协程与协作式并发/)。

## 表作为集合与图

集合常用键存元素、值存 true：

```lua
local set = {lua = true, c = true}
if set.lua then print("present") end
set.lua = nil
```

图可把对象 table 直接当键。由于 table 按身份比较，这种键不会与内容相同的另一 table 混淆。

## 复制

Lua 没有内建深拷贝。浅拷贝：

```lua
local function shallow_copy(source)
  local target = {}
  for key, value in pairs(source) do target[key] = value end
  return target
end
```

深拷贝必须定义循环引用、共享引用、metatable、userdata 和 function 的策略；通用递归复制若没有 `seen` 表会在图结构上无限递归。

## 常见错误

- 用 `#t` 统计 map 或稀疏数组。
- 以为 `table.create(100)` 会创建 100 个元素。
- 依赖 `pairs` 顺序，或遍历时新增键。
- 用 `ipairs` 处理允许 nil 的序列。
- 写不满足严格顺序的 sort comparator。
- 赋值 table 后以为得到副本。

## 练习

1. 用 table 实现集合的 add/remove/contains。
2. 写稳定输出任意字符串键 map 的函数。
3. 实现带 `seen` 的深拷贝，并说明不复制 userdata 的策略。
4. 比较闭包迭代器与无状态迭代器保存状态的位置。
