## 字符串是字节序列

Lua string 不可变、可包含 `\0`、不知道编码。长度和下标默认按字节：

```lua
local text = "你好"
print(#text)          -- UTF-8 下通常 6
print(utf8.len(text)) -- 2
```

`string.sub`、`string.byte` 的位置也是字节偏移；对 UTF-8 任意切片可能截断字符。

## 常用 string API

| API | 用途 |
|---|---|
| `string.len(s)` / `#s` | 字节长度 |
| `string.sub(s, i, j)` | 按字节切片，负下标从末尾计 |
| `string.byte/char` | 字节值与字符串转换 |
| `string.lower/upper` | 受 locale 影响的大小写转换 |
| `string.rep(s, n, sep)` | 重复 |
| `string.reverse(s)` | 按字节反转 |
| `string.format` | 格式化 |
| `string.find/match` | 查找位置/捕获内容 |
| `string.gmatch` | 遍历匹配 |
| `string.gsub` | 替换并返回替换次数 |

字符串 metatable 使 `s:sub(1, 3)` 等价于 `string.sub(s, 1, 3)`。

## Lua Pattern 不是正则表达式

Lua pattern 是较小的模式语言，没有 alternation 等完整正则能力。常用字符类：

| 类 | 含义 |
|---|---|
| `.` | 任意字符 |
| `%a %d %s %w` | 字母、数字、空白、字母数字 |
| `%l %u %p %c %x %z` | 小写、大写、标点、控制、十六进制、零字节 |
| `[set]` / `[^set]` | 集合/补集 |
| `^` / `$` | 开头/结尾锚点 |

大写类通常表示补集，例如 `%D` 表示非数字。魔法字符 `^$()%.[]*+-?` 要按字面匹配时用 `%` 转义。

重复项：

| 后缀 | 语义 |
|---|---|
| `*` | 0 次或多次，贪婪 |
| `+` | 1 次或多次，贪婪 |
| `-` | 0 次或多次，非贪婪 |
| `?` | 0 或 1 次 |

## 捕获

```lua
local key, value = ("name=Lua"):match("^(%w+)=(%w+)$")
print(key, value)

for word in ("Lua 5.5 rocks"):gmatch("%w+") do
  print(word)
end
```

空捕获 `()` 返回当前位置。`%1` 等在模式中引用前面的字符串捕获。`%b()` 匹配平衡括号，`%f[set]` 是 frontier pattern。

## find、match 与 gsub

`find` 返回起止字节位置及捕获；`match` 只返回捕获，若无捕获返回整个匹配。`find(s, plain, init, true)` 可做无模式解释的纯文本搜索，处理用户输入时通常更安全。

`gsub` 的 replacement 可为字符串、table 或函数：

```lua
local result, count = ("a=1 b=2"):gsub("(%a)=(%d)", function(k, v)
  return k:upper() .. "=" .. tostring(tonumber(v) * 10)
end)
print(result, count)
```

函数/table replacement 返回 false/nil 时保留原匹配。

## UTF-8 库

| API | 用途 |
|---|---|
| `utf8.len(s, i, j, lax)` | 统计字符；非法序列返回 nil 和位置 |
| `utf8.codes(s, lax)` | 迭代字节位置和 code point |
| `utf8.codepoint(s, i, j, lax)` | 取 code points |
| `utf8.char(...)` | code points 编码为 UTF-8 |
| `utf8.offset(s, n, i)` | 查第 n 个字符的字节位置 |

Lua 5.5 的 `utf8.offset` 还返回目标字符的最终字节位置，便于安全切片：

```lua
local text = "A你好B"
local first, last = utf8.offset(text, 2)
print(text:sub(first, last)) -- 你
```

默认严格模式拒绝代理项等非 Unicode code point；lax 模式接受原始 UTF-8 规范扩展值。处理文本通常保持严格。

UTF-8 库不提供规范化、字素簇、语言相关排序或完整大小写转换。“字符”仍是 code point，不等于用户看到的一个 grapheme。

## 二进制 pack/unpack

`string.pack`/`unpack` 按格式字符串编码数值与定长数据，适合协议和文件格式：

```lua
local data = string.pack(">I2I4", 0x1234, 0x89abcdef)
local a, b, next_pos = string.unpack(">I2I4", data)
print(string.format("%x %x %d", a, b, next_pos))
```

必须明确大小端、字段宽度、对齐和输入长度。不要直接用本机原生格式设计跨平台持久化协议。

## 常见错误

- 把 Lua pattern 当 PCRE/JavaScript regex。
- 直接把用户输入拼入 pattern，未转义魔法字符。
- 用 `#`、sub、reverse 处理 Unicode 字符。
- 认为 utf8 库能处理字素簇和规范化。
- 对非法 UTF-8 忽略 `utf8.len` 的第二返回值。
- 二进制格式依赖本机大小端或 integer 配置。

## 练习

1. 用 pattern 解析简单 `key=value` 行。
2. 写函数转义 pattern 中所有魔法字符，或改用 plain find。
3. 用 `utf8.codes` 输出中文文本的字节位置与 code point。
4. 设计固定端序的二进制记录并 pack/unpack 验证。
