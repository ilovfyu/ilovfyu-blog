## 本章目标

- 掌握 Lua 的八种基本类型和引用语义。
- 区分 integer 与 float。
- 准确理解真值、相等、转换和运算优先级。
- 避免长度、浮点数、整数溢出和逻辑表达式陷阱。

## 八种基本类型

Lua 是动态类型语言：变量不带类型，值带类型。

| 类型 | 说明 |
|---|---|
| `nil` | 缺失值；表字段赋 nil 会删除键 |
| `boolean` | `true`、`false` |
| `number` | integer 与 float 两个子类型 |
| `string` | 不可变字节序列 |
| `function` | Lua 函数或 C 函数，一等值 |
| `userdata` | 宿主 C 数据，分 full/light userdata |
| `thread` | Lua 协程，不是 OS 线程 |
| `table` | 关联数组，唯一内建数据结构 |

```lua
for _, value in ipairs({true, 10, "lua", function() end, {}}) do
  print(type(value))
end
print(type(nil))
```

表、函数、thread 和 full userdata 是对象，赋值与传参复制引用，不复制对象：

```lua
local a = {count = 1}
local b = a
b.count = 2
assert(a.count == 2)
```

## 真值

只有 `false` 和 `nil` 为假；其他值全部为真，包括 `0`、`0.0` 和 `""`。

```lua
if 0 then print("0 is true") end
if "" then print("empty string is true") end
```

Lua 惯用默认值表达式：

```lua
local display = supplied_name or "anonymous"
```

但若 `false` 是有效输入，该写法会把它误当缺失。此时应显式判断 `nil`。

`and` 和 `or` 返回操作数，不强制返回 boolean：

```lua
print(nil or "fallback") -- fallback
print("ok" and 42)       -- 42
```

## 数字

```lua
print(math.type(3))    -- integer
print(math.type(3.0))  -- float
print(3 == 3.0)        -- true
```

标准 Lua 通常是 64 位有符号整数和双精度浮点数。整数运算溢出按二进制补码回绕。`/` 总做浮点除法，`//` 做向负无穷取整的 floor division：

```lua
print(7 / 2)    -- 3.5
print(7 // 2)   -- 3
print(-7 // 2)  -- -4
print(-7 % 2)   -- 1，满足 a % b == a - ((a // b) * b)
```

`math.tointeger(x)` 在值可精确表示为 integer 时返回整数，否则返回 nil。`tonumber(text, base)` 可按 2–36 进制解析整数文本。

## 运算符

| 类别 | 运算符 |
|---|---|
| 算术 | `+ - * / // % ^`，一元 `-` |
| 位运算 | `& | ~ << >>`，一元 `~` |
| 比较 | `== ~= < > <= >=` |
| 逻辑 | `and or not` |
| 拼接 | `..` |
| 长度 | `#` |

位运算会把可精确转成整数的操作数转为 integer，否则报错。移位用零填充；负移位量表示反方向，超出整数位数得到 0。

## 相等与顺序比较

不同类型通常不相等，但数值 integer/float 按数值比较。表、userdata 和 thread 默认按身份比较。字符串按当前字节序列比较。

`==` 与 `~=` 不做字符串到数字的自动转换：

```lua
print("1" == 1)          -- false
print(tonumber("1") == 1) -- true
```

顺序运算原生支持两个数字或两个字符串；其他值需元方法。NaN 与任何值比较都不相等，包括自身。

## 拼接与长度

`..` 拼接字符串或数字；大量循环拼接可能产生许多中间字符串，优先收集后 `table.concat()`。

`#s` 是字符串字节长度。对于没有 `__len` 的表，`#t` 返回边界：某个满足 `(border == 0 or t[border] ~= nil) and t[border + 1] == nil` 的整数。含空洞数组可能有多个边界，结果不应当作元素总数。

```lua
local dense = {10, 20, 30}
print(#dense) -- 3

local sparse = {[1] = 10, [3] = 30}
-- #sparse 的结果不适合作为业务计数
```

## 优先级速查

从低到高：

```text
or
and
< > <= >= ~= ==
|
~
&
<< >>
..
+ -
* / // %
一元 not # - ~
^
```

`..` 和 `^` 右结合，其他二元运算通常左结合。复杂表达式应加括号表达意图。

## 常见错误

- 把 `0` 或空字符串当假值。
- 用 `or` 给可能为 `false` 的配置设置默认值。
- 认为 `/` 会因两个 integer 而执行整数除法。
- 用 `#` 统计有空洞表的键数。
- 直接比较浮点计算结果是否精确相等。
- 以为赋值表会复制出独立副本。

## 练习

1. 写 `default(value, fallback)`，只在 value 为 nil 时返回 fallback。
2. 验证负数 floor division 和 remainder 的关系。
3. 写函数通过 `pairs` 统计任意表的键数量，并解释它与 `#` 的区别。
4. 说明 `1` 与 `1.0` 作为表键时为何指向同一项。
