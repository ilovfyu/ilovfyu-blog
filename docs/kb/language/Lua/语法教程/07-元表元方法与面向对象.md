## 元表模型

每个值都可以关联 metatable，它是描述值在特定事件下行为的普通 table。table 和 full userdata 每个对象可有独立 metatable；其他类型通常每种类型共享一张，只能通过 debug 库修改。

```lua
local mt = {}
local value = setmetatable({}, mt)
assert(getmetatable(value) == mt)
```

应在把 metatable 关联给对象前准备好元方法，特别是 `__gc`。

## `__index` 与 `__newindex`

读取缺失键时触发 `__index`。它可以是函数，也可以是另一个被继续索引的值：

```lua
local defaults = {timeout = 30, retries = 3}
local config = setmetatable({timeout = 10}, {__index = defaults})
print(config.timeout, config.retries) -- 10 3
```

给缺失键赋值时触发 `__newindex`；若需要真的写回原 table，必须使用 `rawset`，否则可能递归触发自身：

```lua
local function validated()
  return setmetatable({}, {
    __newindex = function(t, key, value)
      assert(type(key) == "string", "string key required")
      rawset(t, key, value)
    end,
  })
end
```

注意：已有键的普通读写不会触发这两个元方法。

## 运算元方法

常见元方法：

| 事件 | 元方法 |
|---|---|
| 算术 | `__add __sub __mul __div __idiv __mod __pow __unm` |
| 位运算 | `__band __bor __bxor __bnot __shl __shr` |
| 比较 | `__eq __lt __le` |
| 其他 | `__concat __len __call __tostring __pairs` |
| 生命周期 | `__close __gc __mode` |

二维向量：

```lua
local Vector = {}
Vector.__index = Vector

function Vector.new(x, y)
  return setmetatable({x = x, y = y}, Vector)
end

function Vector.__add(a, b)
  return Vector.new(a.x + b.x, a.y + b.y)
end

function Vector.__tostring(v)
  return ("Vector(%g, %g)"):format(v.x, v.y)
end

function Vector:length()
  return math.sqrt(self.x ^ 2 + self.y ^ 2)
end

local c = Vector.new(1, 2) + Vector.new(3, 4)
print(c, c:length())
```

Lua 查找元方法时使用 raw access，给 metatable 自己再套 metatable不能替代缺少的元方法。

## Raw 操作

`rawget`、`rawset`、`rawequal`、`rawlen` 绕过对应元方法，主要用于实现元方法内部逻辑、调试和框架底层。业务代码滥用 raw 操作会破坏对象不变量。

## 保护元表

metatable 中设置 `__metatable` 后，`getmetatable(obj)` 返回该值，`setmetatable` 拒绝修改：

```lua
Vector.__metatable = "Vector is protected"
```

这防止普通 Lua 代码意外修改，但 debug 库拥有更强能力，不是安全边界。

## 基于原型的对象模型

Lua 没有内建 class。常见模式是实例 metatable 的 `__index` 指向“类”表：

```lua
local Account = {}
Account.__index = Account

function Account.new(owner, balance)
  return setmetatable({owner = owner, balance = balance or 0}, Account)
end

function Account:withdraw(amount)
  assert(amount >= 0 and amount <= self.balance, "invalid amount")
  self.balance = self.balance - amount
end
```

继承可以让子原型的 `__index` 链到父原型，但深继承链会增加理解成本。组合、委托和显式函数通常更简单。

## 代理与只读视图

只读代理必须把数据存到另一个 table；若原 table 已有键，`__newindex` 不会触发：

```lua
local function readonly(source)
  return setmetatable({}, {
    __index = source,
    __newindex = function(_, key)
      error("cannot assign key " .. tostring(key), 2)
    end,
    __pairs = function() return pairs(source) end,
    __len = function() return #source end,
  })
end
```

这只是浅只读视图：source 中嵌套 table 仍可修改，持有 source 引用的代码也能改它。

## 常见错误

- 在 `__newindex` 中写 `t[key] = value` 导致递归。
- 以为 `__index` 会拦截已有字段。
- 把 metatable 当传统 class，并建立复杂继承层次。
- 认为 `__metatable` 能抵御 debug 库或恶意宿主。
- 写不一致的 `__eq`、`__lt`、`__le`，破坏容器和排序推理。
- 在关联对象后才添加 `__gc`，对象可能未被标记终结。
