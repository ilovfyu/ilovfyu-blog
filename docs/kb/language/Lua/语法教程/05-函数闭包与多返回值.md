## 函数是一等值

函数可以存入变量和表、作为参数传递、从函数返回：

```lua
local function apply(fn, value)
  return fn(value)
end

local square = function(x) return x * x end
print(apply(square, 6)) -- 36
```

`local function f()` 是适合递归的语法糖，大致等价于先声明 local f，再赋函数，函数体可引用自身。

## 参数与调用语法糖

参数不足补 nil，多余参数通常丢弃。调用只有一个字符串或表构造器参数时可省略括号：

```lua
print "hello"
local point = setmetatable({x = 1, y = 2}, {})
```

冒号定义和调用会隐式传 self：

```lua
local Account = {}

function Account:deposit(amount)
  self.balance = self.balance + amount
end

local account = {balance = 10, deposit = Account.deposit}
account:deposit(5) -- 等价 account.deposit(account, 5)
```

定义和调用端的冒号必须匹配意图；`.` 不会自动传 self。

## 多返回值与调整

Lua 函数可返回任意多个值：

```lua
local function divide(a, b)
  if b == 0 then return nil, "division by zero" end
  return a / b, nil
end

local value, err = divide(10, 2)
assert(value, err)
```

多结果表达式只有位于表达式列表末尾时才能展开为多个值；放在括号内强制调整为一个值：

```lua
local function values() return 1, 2, 3 end

local a, b, c = values()       -- 1, 2, 3
local x, y = values(), 99      -- 1, 99
local only = (values())        -- 1
print(values())                -- print 接收 1, 2, 3
print((values()))              -- print 只接收 1
```

表构造器最后一个列表字段也可接收多结果；其他位置只取一个值。

## 可变参数与 Lua 5.5 vararg table

Lua 5.5 的变长函数把额外参数放入 vararg table。匿名形式仍通过 `...` 访问：

```lua
local function sum(...)
  local args = table.pack(...)
  local total = 0
  for i = 1, args.n do
    total = total + (args[i] or 0)
  end
  return total
end
```

5.5 可在三个点后命名 vararg table；该名字是只读 local，表中 `n` 保留额外参数数量，包括尾部 nil：

```lua
local function describe(prefix, ...args)
  print(prefix, args.n)
  for i = 1, args.n do
    print(i, args[i])
  end
  return ...
end

describe("values", 10, nil, 30)
```

`args` 变量不能重新赋值，但 table 内容可修改；`...` 表达式按 `1..args.n` 返回当前表中值。为兼容 5.4，应继续使用匿名 `...` 加 `table.pack(...)`。

## 闭包

闭包由函数与其 upvalue 组成，常用于私有状态、回调和函数工厂：

```lua
local function memoize(fn)
  local cache = {}
  return function(key)
    if cache[key] == nil then
      cache[key] = fn(key)
    end
    return cache[key]
  end
end
```

若 nil 是合法结果，需要额外 sentinel 或存在性表，否则无法区分“未缓存”和“缓存结果为 nil”。

## Proper Tail Call

`return f(args)` 在没有额外运算时是尾调用，当前函数栈帧可被复用：

```lua
local function factorial(n, acc)
  acc = acc or 1
  if n == 0 then return acc end
  return factorial(n - 1, acc * n)
end
```

`return 1 + f()`、`return (f())` 或先调用再 return 都不是相同的尾调用形式。尾调用优化不等于所有递归都安全。

## 迭代器函数预览

函数的多返回值和闭包共同构成泛型 for 的基础：

```lua
local function range(last)
  local current = 0
  return function()
    current = current + 1
    if current <= last then return current end
  end
end

for value in range(3) do print(value) end
```

迭代器返回 nil 时循环结束，不能把 nil 当作普通迭代元素。

## 常见错误

- 忘记多返回值只有在列表末尾展开。
- 用 `{...}` 保存参数后用 `#` 取数量，丢失尾部 nil；应使用 vararg table 的 `n` 或 `table.pack`。
- 混用 `obj.method()` 与 `obj:method()`，造成 self 参数错位。
- 闭包缓存 nil 时无法区分未命中。
- 认为所有递归调用都会被尾调用优化。
- 用具名 `...args` 代码却声称兼容 Lua 5.4。

## 练习

1. 写函数返回最小值、最大值两个结果。
2. 验证函数调用在表达式列表不同位置的结果调整。
3. 用 Lua 5.5 具名 vararg table 实现能正确统计 nil 的日志函数。
4. 用闭包实现具有 `get`、`increment` 两个操作的私有计数器。
