## 8. 事实与证据

- [ ] 输出是否包含事实性主张？
- [ ] 事实来自模型参数、RAG、数据库还是工具？
- [ ] 哪个来源是权威源？
- [ ] 是否要求逐主张引用？
- [ ] 如何校验引用存在性和蕴含性？
- [ ] 数据多久更新？
- [ ] 冲突来源如何处理？
- [ ] 证据不足何时 abstain？

## 12. Prompt Injection

- [ ] 用户输入被视为不可信数据。
- [ ] RAG、网页、文件和工具结果被视为不可信数据。
- [ ] 系统不依赖纯提示词实现绝对防护。
- [ ] 数据和控制平面隔离。
- [ ] 工具最小权限。
- [ ] 输出和参数经过验证。
- [ ] 高风险动作人工批准。
- [ ] 有日志和红队计划。

详见 [Prompt Injection越权与数据泄露防护](/kb/ai/提示词工程/工程化与安全/03-Prompt-Injection越权与数据泄露防护/)。
