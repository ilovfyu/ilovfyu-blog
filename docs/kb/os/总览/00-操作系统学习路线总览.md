::: abstract 系列定位
本系列基于《Operating System Concepts》(Silberschatz, Galvin & Gagne, 9th Edition) 提炼核心知识，重构成"概念 → 算法/例题 → Linux 工程实践 → 常见误区"的学习体系。目标不是复述教材目录，而是把书里真正有用的内容——进程模型、调度算法、同步原语、死锁处理、内存/存储/IO 子系统、保护与安全——讲透，并能落到 Linux 上观察和验证。
:::

操作系统是连接硬件与应用的唯一桥梁：它把 CPU、内存、磁盘、网卡封装成"进程、地址空间、文件、套接字"这四类抽象。本系列的每一篇都在回答一个具体问题：操作系统用**什么机制**实现抽象，用**什么策略**优化性能，在 Linux 上**怎么看**、**怎么调**。

## 2. 三条主线

操作系统内容庞杂，但只需抓住三条主线：

**主线一：CPU 怎么被管理（并发与调度）**

- 进程 = 资源分配单位，线程 = CPU 调度单位（[进程概念与状态模型](/kb/os/进程线程/01-进程概念与状态模型/)、[线程概念与多线程模型](/kb/os/进程线程/04-线程概念与多线程模型/)）
- CPU 调度算法决定了"谁先跑"：FCFS / SJF / RR / Priority / MLFQ（[CPU调度算法详解](/kb/os/进程线程/05-CPU调度算法详解/)）
- 共享数据就必须同步：临界区、互斥锁、信号量、管程（[临界区问题与互斥实现](/kb/os/同步异步/01-临界区问题与互斥实现/) 至 [管程与条件变量](/kb/os/同步异步/03-管程与条件变量/)）
- 同步失控就死锁：四大必要条件、资源分配图、银行家算法（[死锁特征与必要条件](/kb/os/死锁/01-死锁特征与必要条件/) 至 [死锁避免与银行家算法](/kb/os/死锁/04-死锁避免与银行家算法/)）

**主线二：内存怎么被虚拟化（地址空间）**

- 逻辑地址 → 物理地址的映射：分页 + 页表 + TLB（[分页与页表结构](/kb/os/内存/02-分页与页表结构/)）
- 按需分页 + 页面置换 = 虚拟内存（[虚拟内存与按需分页](/kb/os/内存/04-虚拟内存与按需分页/)、[页面置换算法](/kb/os/内存/05-页面置换算法/)）
- 抖动是虚拟内存的"死亡螺旋"（[页面置换算法](/kb/os/内存/05-页面置换算法/)）

**主线三：数据怎么持久化（存储与 IO）**

- 磁盘调度 + RAID 决定底层存储速度（[磁盘结构与大容量存储](/kb/os/存储/01-磁盘结构与大容量存储/)、[磁盘调度算法与RAID](/kb/os/存储/02-磁盘调度算法与RAID/)）
- 文件系统 = 把块设备抽象成文件与目录（[文件系统接口与目录结构](/kb/os/存储/03-文件系统接口与目录结构/)、[文件系统实现](/kb/os/存储/04-文件系统实现/)）
- 数据安全靠日志与可靠性机制（[文件系统可靠性与日志](/kb/os/存储/06-文件系统可靠性与日志/)）
- IO 的一切围绕"减少 CPU 等待"：中断、DMA、缓冲、异步（[内核IO子系统与缓冲](/kb/os/IO/03-内核IO子系统与缓冲/)）

## 5. 学习方法

操作系统概念必须"看得到"，建议每篇三遍：

1. **概念轮**：读懂定义、状态机、机制（这一遍解决"是什么"）
2. **算法轮**：动手手算小规模例题——RR 的甘特图、SJF 的等待时间、银行家算法的安全序列、LRU/Clock 的缺页次数（这一遍解决"怎么算"，也是面试最容易考的点）
3. **观察轮**：在 Linux 上用 `ps`、`top`、`vmstat`、`strace`、`/proc` 看到第 1、2 轮学到的机制在真实系统里长什么样（这一遍解决"真的吗"）

::: tip 操作系统学的四个基本动作
抽象——把硬件封装成资源对象；复用——时间/空间复用共享硬件；隔离——保护进程互不干扰；调度——为竞争的资源分配顺序。所有主题都逃不出这四个动作。
:::

## 6. 能力检查

完成本系列后，应能回答：

- 进程和线程在资源、调度、开销上有什么本质区别？
- 从 `ps` 输出能读出进程的哪些状态？这些状态如何对应状态机？
- FCFS / SJF / RR / MLFQ 各适合什么场景？饥饿如何产生又如何解决？
- 信号量与互斥锁的区别？为什么说信号量计数可以是负数？
- 死锁四条件为什么"缺一不可"？银行家算法凭什么保证安全？
- 虚拟内存如何做到"内存比物理内存大"？缺页和置换有什么区别？
- LRU 为什么最优但不可实现？Clock 算法如何近似 LRU？
- 文件系统的 inode 和目录项分别存什么？硬链接和软链接有何不同？
- DMA 为什么能大幅减少中断次数？
- 访问矩阵的 ACL 与能力列表分别如何撤销权限？
- 拿到一台卡死的 Linux 机器，你按什么顺序排查？（参考 [性能分析方法论](/kb/os/问题排查/01-性能分析方法论/)）

```bash
strace -c ls /tmp
```
