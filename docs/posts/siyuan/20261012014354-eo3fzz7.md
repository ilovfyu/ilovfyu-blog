## 流程概览

这篇文章直接写在思源笔记中，通过本地同步脚本进入博客，再推送到 GitHub Pages。以后写文章，可以继续使用思源的编辑器，无需手工编写博客元信息。

## 1. 在思源里写作

打开当前笔记本，在「随笔」下面新建文档。标题就是博客文章标题，第一段正文会成为文章摘要。正文可以插入图片、列表、表格和代码块。

|文档位置|发布到哪里|
| -------------------| ------------|
|随笔 / 普通根文档|随笔|
|知识库|知识库|
|项目|项目|
|草稿|不发布|

## 2. 同步到本地预览

保持思源打开，双击博客项目里的「同步思源文章.command」，然后打开本地博客预览。也可以在终端执行：

```bash
npm run blog:sync
# 尚未启动预览时执行
npm run blog:preview
```

修改这段文字后再次同步，就能观察到文章内容更新。同步完成后，请确认正文、图片与链接显示正常。

## 3. 发布到网站

双击「发布博客.command」，或者执行：

```bash
npm run blog:publish
```

脚本会再次同步文章、构建网站、提交内容并推送 GitHub。随后 GitHub Actions 自动部署；等待部署完成后刷新网站即可。

- [博客网站](https://ilovfyu.github.io/ilovfyu-blog/)
- [代码仓库](https://github.com/ilovfyu/ilovfyu-blog)
- [部署进度](https://github.com/ilovfyu/ilovfyu-blog/actions)

## 写作提示

1. 文档不要直接修改同步生成的 Markdown 文件，后续内容更新在思源中完成。
2. 未完成的文章放在「草稿」目录，完成后移动到「随笔」。
3. 删除或移走已发布文章后，需要再执行发布，网站才会更新。
4. 发布脚本只提交文章与附件；修改博客代码后，先单独提交代码再发布文章。

> 这是一篇真实发布的流程演示。熟悉操作后，可以在思源中删除它，再执行发布撤下文章。

## 发布链路验证
