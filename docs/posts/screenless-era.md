# 当屏幕消失之后，我们还剩下什么？

> 当界面消失之后，人与技术还剩下什么？

我们习惯了把数字世界装进一块玻璃里。点击、滑动、刷新，像是在一扇小窗里生活。

但下一阶段的技术，也许不再需要被看见。它会变成环境，变成习惯，变成一个恰好在你需要时出现的动作。

真正重要的问题不是“界面会变成什么”，而是：**当工具越来越聪明，我们是否还知道自己想要什么？**

答案还没有出现。记录先开始。
