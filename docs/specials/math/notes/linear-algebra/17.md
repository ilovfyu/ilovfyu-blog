::: abstract 本章主线
张量运算并不神秘：先给每个轴赋予语义，再区分视图变换、逐元素运算与缩并。
`einsum` 则用索引字母统一表达转置、求和、矩阵乘法与批量运算。
:::

## 学习目标

- 理解 tensor 的 rank、shape、axis、stride 与 layout。
- 正确使用 reshape、transpose、squeeze 和 unsqueeze。
- 能逐轴判断 NumPy/PyTorch 广播是否合法。
- 区分 elementwise product、dot、outer product 与 matmul。
- 读写常见 `einsum` 表达式并推导输出 shape。
- 从张量缩并理解 batch、attention 与卷积的 im2col 视角。

## 1. shape 与布局约定

- 标量 shape 为 `()`。
- 向量 $x\in\mathbb{R}^{D}$，代码 shape 为 `(D,)`。
- 矩阵 $A\in\mathbb{R}^{M\times N}$，shape 为 `(M, N)`。
- batch-first 序列 $X$ 的 shape 为 `(B, T, D)`。
- 多头注意力内部采用 `(B, H, T, D_h)`。
- 图像默认采用 PyTorch 的 NCHW：$(B,C,H,W)$。
- 卷积核采用 $(C_{out},C_{in},K_h,K_w)$。
- 重复的大写字母表示维度大小，不是具体数值。

同一组数据可以有不同布局。

例如图像也可能采用 NHWC：$(B,H,W,C)$。

算法公式不依赖布局，但 transpose、性能和 API 参数依赖布局。

## 2. 张量、阶与轴

张量可先朴素地理解为多维数组。

- 0 阶张量：标量。
- 1 阶张量：向量。
- 2 阶张量：矩阵。
- 3 阶及以上：带更多语义轴的数组。

张量的“阶”是轴数量，不是矩阵的秩 rank。

对 $X$ shape `(B, T, D)`：

- axis 0 是 batch 轴。
- axis 1 是 token/time 轴。
- axis 2 是 feature/embedding 轴。

`axis=-1` 指最后一轴，因此常用于 feature 上的 softmax 或归一化。

### 2.1 沿轴归约

若 $X:(B,T,D)$：

- `X.sum(axis=0)` 得 `(T,D)`。
- `X.sum(axis=1)` 得 `(B,D)`。
- `X.sum(axis=-1)` 得 `(B,T)`。
- `keepdims=True` 保留被归约轴为大小 1。

保留大小为 1 的轴通常便于后续广播。

## 3. stride 与内存布局

shape 说明每轴长度，stride 说明沿某轴前进一步要跨过多少内存单元。

行主序矩阵 $A:(M,N)$ 的元素地址可抽象为

$$
\operatorname{addr}(A_{ij})=\operatorname{base}+(iN+j)s,
$$

其中 $s$ 是单元素字节数。

转置通常只改变 shape 和 stride，不复制数据。

因此转置后的数组可能 non-contiguous。

某些操作能处理任意 stride，另一些操作会要求 contiguous 并触发复制。

::: tip 语义与性能分开思考
transpose 首先是轴语义的置换；是否复制内存是具体库和后续算子的实现问题。
:::

## 4. reshape、transpose 与 view

### 4.1 reshape

reshape 改变轴的分组方式，但元素总数必须不变。

$$
\prod_i s_i=\prod_j t_j.
$$

例如 `(B,T,D)` 可 reshape 为 `(B*T,D)`。

但 reshape 本身不交换元素的逻辑顺序。

### 4.2 transpose / permute

transpose 交换轴。

若 $X:(B,T,D)$，则 `X.transpose(0, 1)` 得 `(T,B,D)`。

PyTorch 的 `permute(0, 2, 1)` 可得到 `(B,D,T)`。

NumPy 的 `X.transpose(0, 2, 1)` 含义相同。

### 4.3 squeeze / unsqueeze

`squeeze` 删除大小为 1 的轴。

`unsqueeze` 或 `expand_dims` 插入大小为 1 的轴。

例如 $x:(B,D)$：

- `x[:, None, :]` 得 `(B,1,D)`。
- `x[:, :, None]` 得 `(B,D,1)`。

两者广播语义完全不同。

### 4.4 flatten 不等于任意 reshape

将 `(B,T,D)` flatten 为 `(B,T*D)` 会把 token 与 feature 合并。

将其 reshape 为 `(B*T,D)` 则把 batch 与 token 合并。

元素数相同不代表语义相同。

## 5. 广播规则

NumPy 与 PyTorch 的基本规则是从末尾轴向前比较。

两个维度兼容，当且仅当：

- 两者相等；或
- 至少一个等于 1；或
- 某个张量缺少该轴，可视为该轴大小为 1。

输出轴大小取两者最大值。

### 5.1 合法示例

$$
(B,T,D)+(D)\to(B,T,D).
$$

$$
(B,T,1)+(1,1,D)\to(B,T,D).
$$

$$
(B,1,D)+(1,T,D)\to(B,T,D).
$$

### 5.2 非法示例

$$
(B,T,D)+(B,D)
$$

一般非法，因为从右侧比较得到 $T$ 与 $B$，通常既不相等也不为 1。

若意图给每个 batch 加一个 feature 向量，应将 `(B,D)` 改成 `(B,1,D)`。

### 5.3 广播的概念实现

广播通常不会真的复制数据，而是把大小为 1 的轴视为重复读取。

这可通过 stride 0 实现。

但广播后的运算输出仍可能很大。

例如 `(B,T,1)-(B,1,T)` 会产生 `(B,T,T)`，内存复杂度是 $O(BT^2)$。

## 6. 手算广播例题

给定

$$
X=\begin{bmatrix}1&2&3\\4&5&6\end{bmatrix},
\qquad b=\begin{bmatrix}10&20&30\end{bmatrix}.
$$

$X$ shape 为 `(2,3)`，$b$ shape 为 `(3,)`。

广播相加：

$$
X+b=
\begin{bmatrix}
11&22&33\\
14&25&36
\end{bmatrix}.
$$

若 $c=[10,20]$ shape 为 `(2,)`，则 `X + c` 非法。

要按行添加，应使用 $c[:,None]$：

$$
X+\begin{bmatrix}10\\20\end{bmatrix}
=\begin{bmatrix}11&12&13\\24&25&26\end{bmatrix}.
$$

## 7. elementwise、dot 与 matmul

### 7.1 逐元素运算

若 shape 可广播，则

$$
C_{ij}=A_{ij}B_{ij}
$$

对应 `A * B`，也称 Hadamard product。

它不对轴求和。

### 7.2 内积

对 $x,y\in\mathbb{R}^D$：

$$
x^\top y=\sum_{d=1}^D x_dy_d\in\mathbb{R}.
$$

### 7.3 外积

$$
xy^\top\in\mathbb{R}^{D\times D},
\qquad
(xy^\top)_{ij}=x_iy_j.
$$

### 7.4 矩阵乘法

若 $A:(M,K)$、$B:(K,N)$，则

$$
C=AB:(M,N),
\qquad
C_{mn}=\sum_{k=1}^K A_{mk}B_{kn}.
$$

矩阵乘法由“逐元素乘法 + 对共享轴求和”组成。

### 7.5 batched matmul

若 $A:(B,M,K)$、$B:(B,K,N)$，则

$$
A@B:(B,M,N).
$$

前导 batch 轴也可广播。

例如 `(1,M,K) @ (B,K,N) -> (B,M,N)`。

## 8. 爱因斯坦求和约定

经典记号中，重复索引表示求和，自由索引保留在输出中。

$$
C_{ij}=A_{ik}B_{kj}
$$

表示对 $k$ 求和。

代码 `einsum` 显式写输入和输出索引：

```text
ik,kj->ij
```

字母只代表轴标签，不要求使用特定字符。

### 8.1 阅读步骤

1. 给每个输入轴贴标签。
2. 检查同标签轴的大小是否兼容。
3. 出现在输出中的标签被保留。
4. 未出现在输出中的标签被求和消去。
5. 输出标签顺序决定输出轴顺序。

## 9. 常见 einsum 模式

### 9.1 转置

```python
np.einsum("ij->ji", A)
```

### 9.2 行求和

```python
np.einsum("ij->i", A)
```

### 9.3 内积

```python
np.einsum("i,i->", x, y)
```

### 9.4 外积

```python
np.einsum("i,j->ij", x, y)
```

### 9.5 矩阵乘法

```python
np.einsum("ik,kj->ij", A, B)
```

### 9.6 batch 矩阵乘法

```python
np.einsum("bik,bkj->bij", A, B)
```

### 9.7 batch 共享权重线性层

若 $X:(B,T,D)$、$W:(D,F)$：

```python
Y = np.einsum("btd,df->btf", X, W)
```

输出为 `(B,T,F)`。

### 9.8 对角线与迹

```python
diag = np.einsum("ii->i", A)
trace = np.einsum("ii->", A)
```

同一输入内重复标签表示取对角线，而不是普通广播。

## 10. NumPy 综合示例

```python
import numpy as np

rng = np.random.default_rng(0)
B, T, D, F = 2, 3, 4, 5
X = rng.normal(size=(B, T, D))
W = rng.normal(size=(D, F))
b = rng.normal(size=(F,))

Y_matmul = X @ W + b
Y_einsum = np.einsum("btd,df->btf", X, W) + b
np.testing.assert_allclose(Y_matmul, Y_einsum)

mean = X.mean(axis=-1, keepdims=True)
centered = X - mean
gram = np.einsum("btd,bte->bde", centered, centered)
print(Y_einsum.shape)  # (2, 3, 5)
print(gram.shape)      # (2, 4, 4)
```

## 11. 多头注意力的张量视角

输入

$$
X\in\mathbb{R}^{B\times T\times D},
\qquad D=H D_h.
$$

线性投影得到

$$
Q,K,V\in\mathbb{R}^{B\times T\times D}.
$$

reshape 并 transpose 后：

$$
Q,K,V\in\mathbb{R}^{B\times H\times T\times D_h}.
$$

注意力分数：

$$
S_{bhts}=\frac{1}{\sqrt{D_h}}
\sum_d Q_{bhtd}K_{bhsd}.
$$

einsum 写作：

```python
scores = np.einsum("bhtd,bhsd->bhts", Q, K) / np.sqrt(Dh)
```

这里 $t$ 是 query 位置，$s$ 是 key 位置。

softmax 沿最后的 key 轴 $s$：

$$
P=\operatorname{softmax}(S,\text{axis}=-1).
$$

加权求和：

$$
O_{bhtd}=\sum_s P_{bhts}V_{bhsd}.
$$

```python
O = np.einsum("bhts,bhsd->bhtd", P, V)
```

最后 transpose 回 `(B,T,H,Dh)`，再 reshape 为 `(B,T,D)`。

### 11.1 mask 广播

padding mask 可为 `(B,1,1,T)`。

它广播到 scores 的 `(B,H,T,T)`。

causal mask 可为 `(1,1,T,T)`。

两者组合时必须明确哪个轴对应 query、哪个轴对应 key。

## 12. PyTorch 注意力形状示例

```python
import math
import torch

B, T, H, Dh = 2, 4, 3, 5
Q = torch.randn(B, H, T, Dh)
K = torch.randn(B, H, T, Dh)
V = torch.randn(B, H, T, Dh)

scores = torch.einsum("bhtd,bhsd->bhts", Q, K) / math.sqrt(Dh)
causal = torch.triu(torch.ones(T, T, dtype=torch.bool), diagonal=1)
scores = scores.masked_fill(causal[None, None, :, :], float("-inf"))
weights = torch.softmax(scores, dim=-1)
out = torch.einsum("bhts,bhsd->bhtd", weights, V)

print(scores.shape)  # torch.Size([2, 3, 4, 4])
print(out.shape)     # torch.Size([2, 3, 4, 5])
```

## 13. 卷积的 im2col 视角

二维卷积输入：

$$
X:(B,C_{in},H,W).
$$

卷积核：

$$
K:(C_{out},C_{in},K_h,K_w).
$$

输出空间大小：

$$
H_{out}=\left\lfloor
\frac{H+2P_h-D_h(K_h-1)-1}{S_h}+1
\right\rfloor.
$$

$W_{out}$ 同理。

im2col 把每个局部窗口拉平成长度

$$
K=C_{in}K_hK_w
$$

的向量。

所有窗口组成

$$
X_{col}:(B,H_{out}W_{out},K).
$$

卷积核拉平为

$$
W_{col}:(K,C_{out}).
$$

于是卷积变为

$$
Y_{col}=X_{col}W_{col},
$$

shape 为 `(B, Hout*Wout, Cout)`。

再转置和 reshape 回 `(B,Cout,Hout,Wout)`。

### 13.1 einsum 表达局部缩并

若窗口张量为

$$
P:(B,H_o,W_o,C_i,K_h,K_w),
$$

核为

$$
K:(C_o,C_i,K_h,K_w),
$$

则

```python
Y = np.einsum("bhwcij,ocij->bohw", patches, kernel)
```

其本质仍是对输入通道和核空间三条轴求和。

## 14. 卷积手算例题

输入与核为

$$
X=\begin{bmatrix}
1&2&0\\
0&1&3\\
2&1&0
\end{bmatrix},
\qquad
K=\begin{bmatrix}1&0\\0&-1\end{bmatrix}.
$$

stride 1、无 padding，输出 shape 为 `(2,2)`。

左上窗口输出：

$$
1\cdot1+2\cdot0+0\cdot0+1\cdot(-1)=0.
$$

右上窗口输出：

$$
2\cdot1+0\cdot0+1\cdot0+3\cdot(-1)=-1.
$$

左下窗口输出：

$$
0\cdot1+1\cdot0+2\cdot0+1\cdot(-1)=-1.
$$

右下窗口输出：

$$
1\cdot1+3\cdot0+1\cdot0+0\cdot(-1)=1.
$$

故输出为

$$
Y=\begin{bmatrix}0&-1\\-1&1\end{bmatrix}.
$$

深度学习库通常实现的是 cross-correlation，不会先翻转核。

## 15. einsum 的性能边界

`einsum` 提升表达力，但不保证总是最快。

- 两矩阵乘法优先考虑 `@`，底层可直接调用高度优化的 GEMM。
- 多输入缩并的执行顺序会显著影响中间张量大小。
- NumPy 可使用 `optimize=True` 选择路径。
- PyTorch 后端可能对常见 pattern 做优化，但应以 profiling 为准。
- 清晰的 reshape + matmul 有时比复杂 einsum 更容易优化。

表达正确之后，再依据真实性能数据优化。

## 16. 常见误区

1. 把张量阶数与矩阵秩混为一谈。
2. 只验证元素总数，不验证 reshape 后各轴语义。
3. 认为 transpose 一定复制数据，或认为它永远不复制数据。
4. 从左向右判断广播，而不是从末轴向前判断。
5. 把 `*` 当成矩阵乘法。
6. 忘记 `axis=-1` 究竟是哪条语义轴。
7. 用 `squeeze()` 无参数删除所有单例轴，意外删掉 batch 轴。
8. 在 attention 中把 query 轴和 key 轴写反。
9. 忽略广播产生的巨大输出，例如完整两两距离矩阵。
10. 认为 im2col 必然节省内存；显式展开往往增加内存。
11. 将数学卷积与深度学习库的互相关实现混为一谈。
12. 写出正确 einsum 后便假定它一定是最快实现。

## 17. 自测题

### 题 1

`(8,1,32)` 与 `(1,16,1)` 相加，输出 shape 是什么？

::: answer 答案
`(8,16,32)`。三个轴分别由 `8/1`、`1/16`、`32/1` 广播得到。
:::

### 题 2

若 $X:(B,T,D)$，怎样计算每个 token 的 L2 范数并保留 feature 轴？

::: answer 答案
`np.sqrt((X * X).sum(axis=-1, keepdims=True))`，输出 `(B,T,1)`。
:::

### 题 3

解释 `einsum("btd,bsd->bts", Q, K)`。

::: answer 答案
对共同 feature 轴 `d` 求和，保留 batch、query 位置 `t` 和 key 位置 `s`，输出 `(B,T,S)`。
:::

### 题 4

将 `(B,T,H,Dh)` 变为 `(B,H,T,Dh)` 应使用 reshape 还是 transpose？

::: answer 答案
使用 transpose/permute，因为是在交换 token 轴和 head 轴，而不是重新分组连续元素。
:::

### 题 5

为什么 `(B,T,D) + (B,D)` 通常不合法？如何修复？

::: answer 答案
广播从右向左比较时，第二个张量的 `B` 会与第一个张量的 `T` 对齐。应将后者变为 `(B,1,D)`。
:::

### 题 6

im2col 后矩阵乘法的缩并轴是什么？

::: answer 答案
长度为 $C_{in}K_hK_w$ 的展平窗口轴；它同时包含输入通道与核的两个空间轴。
:::

## 18. 小结

- shape 是长度信息，axis 是语义，stride 是内存步长。
- reshape 重新分组轴，transpose 置换轴，两者不可互换。
- 广播从末轴比较，相等或某一方为 1 才兼容。
- matmul 是逐元素乘法后沿共享轴缩并。
- einsum 用标签明确“保留哪些轴、消去哪些轴”。
- attention 是 feature 缩并与 sequence 缩并的组合。
- 卷积可视为提取局部窗口后执行共享矩阵乘法。
- 正确性靠 shape 推理，性能结论靠 profiling。
