# 第 11 章 曲线积分与曲面积分

## 本章概览

**本章解决什么问题？**

前面几章我们学会了：
- 一元定积分 $\int_a^b f(x)\,dx$——对"直线段"上的函数积分（第 5 章）；
- 二重积分 $\iint_D f(x,y)\,d\sigma$、三重积分 $\iiint_\Omega f\,dV$——对"平面区域""空间区域"上的函数积分（第 10 章）。

但物理与几何中有大量问题需要对**曲线**和**曲面**积分：
- 一根弯曲的铁丝，密度各处不同，总质量是多少？（曲线上的积分）
- 一个弯曲的薄壳，面密度各处不同，总质量是多少？（曲面上的积分）
- 力场沿曲线推动质点做了多少功？（曲线上的积分，带方向）
- 流速场单位时间穿过一个曲面的流量是多少？（曲面上的积分，带方向）

这些正是本章的**曲线积分**与**曲面积分**。它们与重积分的本质区别在于：重积分是对"区域"（二维/三维体）积分，而曲线/曲面积分是对"低一维的对象"（线、面）积分。

**与前几章的联系**
- 第 5、6 章：定积分是曲线积分的原型；第 6 章学过的弧长微元 $ds$、曲面面积微元 $dS$ 正是本章"第一类"积分的微元。
- 第 8 章：空间曲面的方程、参数方程、切平面与法向量，是曲面积分计算的基础。
- 第 9 章：偏导数是计算 $dS$ 的根号因子以及格林、高斯公式被积函数的基础。
- 第 10 章：二重积分、三重积分是格林公式、高斯公式的"右端"。

**本章的两条主线与三大公式**
- 主线一：**第一类**（对弧长 $ds$、对面积 $dS$）——无方向，像"称重"；
- 主线二：**第二类**（对坐标 $dx,dy,dydz,dzdx,dxdy$）——有方向，像"做功、测流量"；
- 两类之间通过单位切向量/单位法向量互相转化；
- 三大公式：**格林公式**（平面）、**高斯公式**（空间）、**斯托克斯公式**（空间曲线）——都是"边界的积分 = 内部导数的积分"，是本章的计算利器。

## 知识点详解

### 一、第一类曲线积分（对弧长的曲线积分）

**定义.** 设 $L$ 是 $xOy$ 平面上的一条分段光滑曲线，$f(x,y)$ 是 $L$ 上有界的函数。将 $L$ 任意分成 $n$ 个小弧段，第 $i$ 段弧长为 $\Delta s_i$，在该段上任取一点 $(\xi_i,\eta_i)$，作和 $\sum_{i=1}^{n} f(\xi_i,\eta_i)\,\Delta s_i$。当各小段弧长的最大值 $\lambda \to 0$ 时，若该和式的极限存在且与分法、取点无关，则称此极限为 $f(x,y)$ 在曲线 $L$ 上**对弧长的曲线积分**，记作

$$\int_L f(x,y)\,ds = \lim_{\lambda \to 0}\sum_{i=1}^{n} f(\xi_i,\eta_i)\,\Delta s_i.$$

空间情形类似：$\int_\Gamma f(x,y,z)\,ds$，其中 $ds$ 为空间弧长微元。

**通俗讲解（几何与物理意义）**
- 把曲线想成一根"细铁丝"，$f(x,y)$ 是线密度（单位长度的质量），则 $\int_L f\,ds$ 就是铁丝的总质量；当 $f \equiv 1$ 时就是弧长 $\int_L ds$。
- 关键点：$ds$ 是**弧长微元，恒为正**。所以第一类曲线积分只与"曲线的形状和函数值"有关，**与曲线的方向无关**——从 A 走到 B 和从 B 走到 A，积分结果相同。
- 一维退化：当曲线取 $x$ 轴上的区间 $[a,b]$ 时，$ds = dx$，第一类曲线积分就退化为定积分 $\int_a^b f(x)\,dx$。所以第一类曲线积分是定积分在"弯曲的线"上的推广。

**性质**
1. 线性性：$\int_L [\alpha f + \beta g]\,ds = \alpha\int_L f\,ds + \beta\int_L g\,ds$；
2. 可加性：若 $L = L_1 + L_2$（首尾相接），则 $\int_L = \int_{L_1} + \int_{L_2}$；
3. 方向无关：$\int_{L^-} f\,ds = \int_L f\,ds$（$L^-$ 为反向曲线）——这是与第二类最本质的区别；
4. 对称性：若 $L$ 关于 $y$ 轴对称，且 $f$ 关于 $x$ 为奇函数（$f(-x,y) = -f(x,y)$），则 $\int_L f\,ds = 0$；若 $f$ 为偶函数，则 $\int_L f\,ds = 2\int_{L_{\text{右半}}} f\,ds$。对 $x$ 轴对称、原点对称有类似结论。

**计算方法（化为定积分，核心是写出 $ds$）**
- **参数方程**：$L:\ x = \varphi(t),\ y = \psi(t)$，$\alpha \le t \le \beta$，则

$$ds = \sqrt{[\varphi'(t)]^2 + [\psi'(t)]^2}\,dt, \qquad \int_L f(x,y)\,ds = \int_\alpha^\beta f(\varphi(t),\psi(t))\,\sqrt{\varphi'^2 + \psi'^2}\,dt.$$

- **直角坐标**：$L:\ y = \varphi(x)$，$a \le x \le b$，则

$$\int_L f(x,y)\,ds = \int_a^b f(x,\varphi(x))\,\sqrt{1 + [\varphi'(x)]^2}\,dx.$$

- **极坐标**：$L:\ r = r(\theta)$，$\alpha \le \theta \le \beta$，则

$$ds = \sqrt{r^2 + [r'(\theta)]^2}\,d\theta.$$

- **空间曲线**：$\Gamma:\ x = \varphi(t),\ y = \psi(t),\ z = \omega(t)$，则 $ds = \sqrt{\varphi'^2 + \psi'^2 + \omega'^2}\,dt$。

**注意**
- 公式要求曲线分段光滑（参数函数有连续导数，且 $(\varphi',\psi')$ 不同时为零）；分段光滑曲线应分段积分再相加。
- 因为 $ds$ 恒正，化为定积分时**按参数从起点到终点取值即可**，不必担心方向；这与第二类积分"上下限必须服从方向"完全不同。
- 解题技巧：先在 $L$ 上利用曲线方程简化被积函数（在曲线上成立的等式可以代入），再利用对称性和 $\int_L ds = $ 弧长等简化计算。

### 二、第二类曲线积分（对坐标的曲线积分）

**定义.** 设 $L$ 为有向分段光滑曲线，起点为 $A$、终点为 $B$，$P(x,y), Q(x,y)$ 在 $L$ 上有界。将 $L$ 从 $A$ 到 $B$ 分成 $n$ 小段，第 $i$ 段在 $x$、$y$ 方向的坐标增量分别为 $\Delta x_i,\ \Delta y_i$（可正可负），在该段上任取一点 $(\xi_i,\eta_i)$，作和

$$\sum_{i=1}^{n}\big[P(\xi_i,\eta_i)\,\Delta x_i + Q(\xi_i,\eta_i)\,\Delta y_i\big].$$

当最大小段弧长 $\lambda \to 0$ 时极限存在，则称该极限为 $P,Q$ 沿有向曲线 $L$ 的**对坐标的曲线积分**，记作

$$\int_L P(x,y)\,dx + Q(x,y)\,dy = \lim_{\lambda \to 0}\sum_{i=1}^{n}\big[P(\xi_i,\eta_i)\,\Delta x_i + Q(\xi_i,\eta_i)\,\Delta y_i\big].$$

空间情形：$\int_\Gamma P\,dx + Q\,dy + R\,dz$。向量形式：$\int_L \mathbf{F}\cdot d\mathbf{r}$，其中 $\mathbf{F} = (P,Q)$，$d\mathbf{r} = (dx,dy)$。

**通俗讲解（物理意义：变力做功）**
- 设力场 $\mathbf{F}(x,y) = (P(x,y), Q(x,y))$ 把质点沿曲线 $L$ 从 $A$ 拉到 $B$。在一小段位移 $d\mathbf{r} = (dx,dy)$ 上，功的微元为 $dW = \mathbf{F}\cdot d\mathbf{r} = P\,dx + Q\,dy$，总功

$$W = \int_L \mathbf{F}\cdot d\mathbf{r} = \int_L P\,dx + Q\,dy.$$

- 与第一类的区别：这里"测"的是**位移**（有方向的向量），而不是弧长。反向走，位移反向，功反号。
- 直观对比：第一类积分像"称重"（不分正反），第二类积分像"记账"（方向反了收支反号）。

**性质**
1. 线性性（对 $P,Q$ 均线性）；
2. **方向性**：$\int_{L^-} P\,dx + Q\,dy = -\int_L P\,dx + Q\,dy$（反向变号！）；
3. 可加性：$L = L_1 + L_2$ 时，$\int_L = \int_{L_1} + \int_{L_2}$；
4. 闭合曲线上的积分记作 $\oint_L P\,dx + Q\,dy$。

**计算方法（化为定积分，方向体现在上下限）**
- 有向曲线 $L:\ x = \varphi(t),\ y = \psi(t)$，起点对应 $t = \alpha$、终点对应 $t = \beta$，则

$$\int_L P\,dx + Q\,dy = \int_\alpha^\beta \big[P(\varphi(t),\psi(t))\,\varphi'(t) + Q(\varphi(t),\psi(t))\,\psi'(t)\big]dt.$$

- 特殊情形 $L:\ y = \varphi(x)$，$x$ 从 $a$ 到 $b$（起点对应 $a$，终点对应 $b$）：

$$\int_L P\,dx + Q\,dy = \int_a^b \big[P(x,\varphi(x)) + Q(x,\varphi(x))\,\varphi'(x)\big]dx.$$

- 空间情形：$\int_\Gamma P\,dx + Q\,dy + R\,dz = \int_\alpha^\beta \big[P\varphi' + Q\psi' + R\omega'\big]dt$。

**注意**：第二类积分化为定积分时，**下限一定是起点对应的参数，上限一定是终点对应的参数**（不能机械地"小数在下、大数在上"）；方向反了，上下限互换，结果变号。

#### 两类曲线积分的关系

设 $L$ 上每一点处、沿积分方向的单位切向量为 $\mathbf{e}_t = (\cos\alpha, \cos\beta)$（$\alpha,\beta$ 是该切向量与 $x$ 轴、$y$ 轴正向的夹角），则

$$\int_L P\,dx + Q\,dy = \int_L (P\cos\alpha + Q\cos\beta)\,ds.$$

物理意义：做功 = 力在切线方向的分量对弧长的积分。注意 $\cos\alpha,\cos\beta$ 必须按**积分方向**取（反向则二者变号，与第二类积分的反向变号吻合）。记忆口诀：**第二类 = 第一类（被积函数换成"向量场点乘单位切向量"）**。

### 三、格林公式及其应用；平面曲线积分与路径无关

**格林公式.** 设闭区域 $D$ 由分段光滑的简单闭曲线 $L$ 围成，函数 $P(x,y), Q(x,y)$ 在 $D$ 上具有一阶连续偏导数，$L$ 取**正向**（即沿 $L$ 前进时区域 $D$ 恒在左手侧，外边界为逆时针方向），则

$$\oint_L P\,dx + Q\,dy = \iint_D \left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right)dx\,dy.$$

**通俗讲解**
- 左边是"沿区域边界转一圈的曲线积分"，右边是"内部 $\dfrac{\partial Q}{\partial x} - \dfrac{\partial P}{\partial y}$ 的二重积分"。可以把 $\dfrac{\partial Q}{\partial x} - \dfrac{\partial P}{\partial y}$ 理解为平面场的"旋转强度"（旋度的 $z$ 分量），格林公式说：**边界上的环量 = 内部旋转强度的总和**。
- 记忆：$\oint_L P\,dx+Q\,dy$ 对应 $\iint_D \Big(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\Big)$，即"$Q$ 对 $x$ 的偏导 减 $P$ 对 $y$ 的偏导"。

**应用**
1. 计算闭曲线上的曲线积分：化为二重积分（常配合极坐标）；
2. 反向使用：当二重积分难算而边界积分好算时，用格林公式把二重积分化为曲线积分；
3. 求面积：取 $P = -y,\ Q = x$ 得 $S_D = \dfrac12\oint_L x\,dy - y\,dx$；
4. 判断与计算与路径无关的曲线积分（见下）。

**注意（使用条件，逐条检查）**
1. $L$ 是分段光滑的**简单闭曲线**（不自交）；开曲线想用格林公式须先"补线"成闭曲线，再减去补线上的积分；
2. $P,Q$ 在 $D$（含边界）上具有**一阶连续偏导数**；
3. **方向**：取正向（外边界逆时针、内边界顺时针）；取反则结果变号；
4. **复连通区域**：若 $D$ 内有"洞"（如奇点被挖去），格林公式须对每个边界分量分别使用，或采用"挖洞法"。

**平面曲线积分与路径无关的条件.** 设 $G$ 是**单连通**开区域，$P,Q$ 在 $G$ 内有一阶连续偏导数，则以下四条**等价**：

1. 对 $G$ 内任意闭曲线 $L$，$\oint_L P\,dx + Q\,dy = 0$；
2. $\int_L P\,dx + Q\,dy$ 在 $G$ 内**与路径无关**（只取决于起点与终点）；
3. 存在函数 $u(x,y)$，使 $du = P\,dx + Q\,dy$（即 $P\,dx+Q\,dy$ 是某个二元函数的全微分），且

$$u(x,y) = \int_{(x_0,y_0)}^{(x,y)} P\,dx + Q\,dy;$$

4. $\dfrac{\partial P}{\partial y} = \dfrac{\partial Q}{\partial x}$ 在 $G$ 内恒成立。

**求原函数 $u$ 的方法**：折线法——$u = \int_{x_0}^{x} P(x,y_0)\,dx + \int_{y_0}^{y} Q(x,y)\,dy$（从 $(x_0,y_0)$ 先水平后竖直积分）；或分组凑微分。

**注意（考研经典陷阱）**："$\dfrac{\partial P}{\partial y} = \dfrac{\partial Q}{\partial x}$"必须结合"**区域单连通**"一起使用。例如 $P = \dfrac{-y}{x^2+y^2},\ Q = \dfrac{x}{x^2+y^2}$ 在"去掉原点的平面"上满足 $\dfrac{\partial P}{\partial y} = \dfrac{\partial Q}{\partial x}$，但沿单位圆逆时针一周

$$\oint_L P\,dx+Q\,dy = \int_0^{2\pi} \big[\sin^2 t + \cos^2 t\big]dt = 2\pi \neq 0.$$

原因：原点被挖掉，区域有洞，不是单连通的。处理办法：**挖洞法**——用充分小的圆绕开奇点，把小圆边界取相反方向，转化为小圆上的积分。

### 四、第一类曲面积分（对面积的曲面积分）

**定义.** 设曲面 $\Sigma$ 是光滑的（或分片光滑），$f(x,y,z)$ 在 $\Sigma$ 上有界。将 $\Sigma$ 任意分成 $n$ 小块 $\Delta S_i$，每小块上任取一点 $(\xi_i,\eta_i,\zeta_i)$，作和 $\sum_{i=1}^{n} f(\xi_i,\eta_i,\zeta_i)\,\Delta S_i$。当各小块直径的最大值 $\lambda \to 0$ 时极限存在，则称该极限为 $f$ 在 $\Sigma$ 上**对面积的曲面积分**，记作

$$\iint_\Sigma f(x,y,z)\,dS = \lim_{\lambda \to 0}\sum_{i=1}^{n} f(\xi_i,\eta_i,\zeta_i)\,\Delta S_i.$$

**通俗讲解（物理意义）**
- 把曲面想成"曲面薄壳"，$f$ 是面密度（单位面积的质量），则 $\iint_\Sigma f\,dS$ 是薄壳的总质量；当 $f \equiv 1$ 时就是曲面面积。
- $dS$ 是面积微元，恒为正，所以第一类曲面积分**与曲面的侧无关**（不分里外、上下）。
- 它是二重积分的"弯曲版"：二重积分积在平面区域上（微元 $d\sigma = dx\,dy$），曲面积分积在曲面上（微元 $dS$）。

**性质**：线性、可加性、与侧无关；对称性（$\Sigma$ 关于某坐标面对称，且 $f$ 为相应变量的奇函数时积分为 0）。

**计算方法（化为二重积分，核心是写出 $dS$）**
- 若 $\Sigma:\ z = z(x,y)$，$(x,y) \in D$（$D$ 是 $\Sigma$ 在 $xOy$ 平面上的投影区域），则

$$dS = \sqrt{1 + z_x^2 + z_y^2}\,dx\,dy, \qquad \iint_\Sigma f(x,y,z)\,dS = \iint_D f\big(x,y,z(x,y)\big)\,\sqrt{1+z_x^2+z_y^2}\,dx\,dy.$$

- 若曲面方程形如 $x = x(y,z)$ 或 $y = y(x,z)$，则分别投影到 $yOz$、$xOz$ 平面：

$$dS = \sqrt{1+x_y^2+x_z^2}\,dy\,dz, \qquad dS = \sqrt{1+y_x^2+y_z^2}\,dx\,dz.$$

**注意**
- 根号因子 $\sqrt{1+z_x^2+z_y^2}$ 是"曲面微元与平面微元"的面积换算系数，**第一类曲面积分一定要乘它**，这是它与二重积分、与第二类曲面积分的最大区别之一。
- 投影区域 $D$ 是曲面在坐标平面上的投影，注意取全；对"多值"曲面（如球面、整圈锥面）要分片（上半片、下半片）分别投影再相加。
- 常用对称性：如 $\Sigma$ 关于 $xOy$ 面对称、$f$ 关于 $z$ 为奇函数，则积分为 0。

### 五、第二类曲面积分（对坐标的曲面积分）

**定义.** 设 $\Sigma$ 是取定**侧**（如外侧、上侧）的光滑有向曲面，$\mathbf{F} = (P,Q,R)$ 在 $\Sigma$ 上有界。将 $\Sigma$ 分成 $n$ 小块 $\Delta S_i$，把第 $i$ 小块投影到 $yOz$、$zOx$、$xOy$ 平面，得到**有向**投影面积（按所取侧的法向量方向与相应坐标轴正向的夹角决定正负），分别记为 $\Delta S_i^{yz},\ \Delta S_i^{zx},\ \Delta S_i^{xy}$，取点 $(\xi_i,\eta_i,\zeta_i)$ 作和

$$\sum_{i=1}^{n}\big[P\,\Delta S_i^{yz} + Q\,\Delta S_i^{zx} + R\,\Delta S_i^{xy}\big].$$

当 $\lambda \to 0$ 时极限存在，称为 $\mathbf{F}$ 沿有向曲面 $\Sigma$ 的**对坐标的曲面积分**：

$$\iint_\Sigma P\,dy\,dz + Q\,dz\,dx + R\,dx\,dy.$$

**通俗讲解（物理意义：流量/通量）**
- 设 $\mathbf{F} = (P,Q,R)$ 是流速场，则 $\iint_\Sigma \mathbf{F}\cdot \mathbf{n}\,dS$ 是单位时间穿过曲面 $\Sigma$ 的流体总量（**通量**），其中 $\mathbf{n}$ 是所取侧的单位法向量。
- 因为"穿过"有方向之分（从这侧穿到那侧），所以第二类曲面积分**与曲面的侧有关**：换侧（如外侧换内侧）结果变号。
- 记号说明：$dy\,dz,\ dz\,dx,\ dx\,dy$ 是有向面积微元在三个坐标平面上的投影分量。

**计算方法（投影法，符号是灵魂）**
- 以 $\iint_\Sigma R(x,y,z)\,dx\,dy$ 为例：若 $\Sigma:\ z = z(x,y)$，$(x,y) \in D$，则

$$\iint_\Sigma R\,dx\,dy = \pm \iint_D R\big(x,y,z(x,y)\big)\,dx\,dy,$$

其中当 $\Sigma$ 取**上侧**（法向量与 $z$ 轴正向夹角为锐角）时取"$+$"，取**下侧**（夹角为钝角）时取"$-$"。
- 同理：$\iint_\Sigma P\,dy\,dz$ 投影到 $yOz$ 平面，按法向量与 $x$ 轴正向的夹角定符号（法向朝前为正）；$\iint_\Sigma Q\,dz\,dx$ 投影到 $xOz$ 平面，按法向量与 $y$ 轴正向的夹角定符号（法向朝右为正）。

**注意**
1. **方向**：换侧整体变号；封闭曲面习惯取外侧；
2. 三个积分**逐项独立投影、逐项判断符号**，不要想当然统一符号——这是最容易丢分的地方；
3. 投影法**不乘**根号因子 $\sqrt{1+z_x^2+z_y^2}$（与第一类相反），符号另外处理；
4. 若曲面某部分投影时"重叠或退化"（如竖直柱面投影成一条线），应改投到其他坐标平面或分片处理。

#### 两类曲面积分的关系

设 $\Sigma$ 取定一侧，该侧的单位法向量为 $\mathbf{n} = (\cos\alpha, \cos\beta, \cos\gamma)$（$\alpha,\beta,\gamma$ 为法向量与三坐标轴正向的夹角），则

$$\iint_\Sigma P\,dy\,dz + Q\,dz\,dx + R\,dx\,dy = \iint_\Sigma (P\cos\alpha + Q\cos\beta + R\cos\gamma)\,dS = \iint_\Sigma \mathbf{F}\cdot \mathbf{n}\,dS.$$

记忆口诀：**第二类曲面积分 = 第一类曲面积分（被积函数换成"向量场点乘单位法向量"）**。$\cos\alpha,\cos\beta,\cos\gamma$ 必须按所取的侧确定（换侧则三者变号）。

### 六、高斯公式与散度（了解）

**高斯公式.** 设空间闭区域 $\Omega$ 由分片光滑的闭曲面 $\Sigma$ 围成，$P,Q,R$ 在 $\Omega$ 上具有一阶连续偏导数，$\Sigma$ 取**外侧**，则

$$\iiint_\Omega \left(\frac{\partial P}{\partial x} + \frac{\partial Q}{\partial y} + \frac{\partial R}{\partial z}\right)dV = \iint_\Sigma P\,dy\,dz + Q\,dz\,dx + R\,dx\,dy.$$

**散度.** 向量场 $\mathbf{A} = (P,Q,R)$ 的散度为

$$\mathrm{div}\,\mathbf{A} = \nabla\cdot\mathbf{A} = \frac{\partial P}{\partial x} + \frac{\partial Q}{\partial y} + \frac{\partial R}{\partial z}.$$

散度刻画"单位体积的通量"，即源的强度：$\mathrm{div}\,\mathbf{A} > 0$ 为源（流体向外涌出），$\mathrm{div}\,\mathbf{A} < 0$ 为汇（向内吸收），$\mathrm{div}\,\mathbf{A} = 0$ 为无源场。高斯公式即：**穿过闭曲面外侧的通量 = 内部散度的三重积分**——它是格林公式从平面到空间的推广（把"二维区域的边界"推广为"三维区域的边界"）。

**使用注意**
1. $\Sigma$ 必须是**封闭**曲面且取**外侧**（方向反了整体差一个负号）；
2. $P,Q,R$ 在 $\Omega$（含边界）上具有一阶连续偏导数；
3. 求**非封闭**曲面的通量时用**补面法**：补一块简单曲面（常为平面）使成闭曲面，用高斯公式后再减去补面上的通量；
4. 场在 $\Omega$ 内有奇点时用**挖洞法**（挖去以奇点为中心的小球/小椭球，内表面取内侧），与格林公式的处理完全类似。

**一个直观的小例子**：求向量场 $\mathbf{F} = (x,y,z)$ 穿过球面 $x^2+y^2+z^2 = R^2$（外侧）的通量。
- 用高斯公式：$\mathrm{div}\,\mathbf{F} = 1+1+1 = 3$，通量 $= 3 \cdot \dfrac{4}{3}\pi R^3 = 4\pi R^3$；
- 直接算：外侧单位法向量 $\mathbf{n} = \dfrac{(x,y,z)}{R}$，$\mathbf{F}\cdot\mathbf{n} = \dfrac{x^2+y^2+z^2}{R} = R$，通量 $= R \cdot 4\pi R^2 = 4\pi R^3$。

两种方法结果一致，互相印证；这个例子同时展示了高斯公式的威力与"第二类曲面积分"的方向性约定。

### 七、斯托克斯公式与旋度（了解）

**斯托克斯公式.** 设 $\Gamma$ 是分段光滑的空间有向闭曲线，$\Sigma$ 是以 $\Gamma$ 为边界的分片光滑有向曲面，$\Gamma$ 的方向与 $\Sigma$ 的侧满足**右手法则**（右手四指沿 $\Gamma$ 的走向弯曲，拇指指向 $\Sigma$ 的法向），$P,Q,R$ 在含 $\Sigma$ 的空间区域内有一阶连续偏导数，则

$$\oint_\Gamma P\,dx + Q\,dy + R\,dz = \iint_\Sigma \left(\frac{\partial R}{\partial y} - \frac{\partial Q}{\partial z}\right)dy\,dz + \left(\frac{\partial P}{\partial z} - \frac{\partial R}{\partial x}\right)dz\,dx + \left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right)dx\,dy.$$

行列式记忆形式（按第一行展开即得上式）：

$$\oint_\Gamma P\,dx+Q\,dy+R\,dz = \iint_\Sigma \begin{vmatrix} dy\,dz & dz\,dx & dx\,dy \\ \dfrac{\partial}{\partial x} & \dfrac{\partial}{\partial y} & \dfrac{\partial}{\partial z} \\ P & Q & R \end{vmatrix}.$$

**旋度.** 向量场 $\mathbf{A} = (P,Q,R)$ 的旋度为

$$\mathrm{rot}\,\mathbf{A} = \nabla\times\mathbf{A} = \begin{vmatrix} \mathbf{i} & \mathbf{j} & \mathbf{k} \\ \dfrac{\partial}{\partial x} & \dfrac{\partial}{\partial y} & \dfrac{\partial}{\partial z} \\ P & Q & R \end{vmatrix} = \left(\frac{\partial R}{\partial y} - \frac{\partial Q}{\partial z},\ \frac{\partial P}{\partial z} - \frac{\partial R}{\partial x},\ \frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right).$$

旋度刻画场的"旋转强度"（涡旋性）：某点旋度的方向是旋转轴方向，模长正比于旋转角速度。斯托克斯公式即：**空间闭曲线的环量 = 旋度在张成的曲面上的通量**，它是格林公式从平面到空间的推广（格林公式恰为旋度只有 $z$ 分量时的平面特例）。

**注意**
1. $\Gamma$ 与 $\Sigma$ 的定向必须满足右手法则，这是最易错点；
2. 实际计算常取 $\Sigma$ 为以 $\Gamma$ 为边界的**平面区域**（如 $\Gamma$ 所在的平面片），此时旋度的法向分量较易计算；
3. 空间曲线积分与路径无关的条件（了解）：在（任意闭曲线可缩成一点的）空间单连通区域内，$\oint_\Gamma P\,dx+Q\,dy+R\,dz = 0$ 对任意闭曲线 $\Gamma$ 成立 $\iff$ 积分与路径无关 $\iff$ 存在势函数 $u$ 使 $P\,dx+Q\,dy+R\,dz = du$ $\iff$ $\mathrm{rot}\,\mathbf{A} = \mathbf{0}$；
4. 本部分为数学一内容，大纲多作"了解"要求，复习以会用公式、方向不错为主。

## 典型例题

### 例题 1（第一类曲线积分：代入曲线方程与弧长公式）

**题目**：计算 $\oint_L (x^2+y^2)\,ds$，其中 $L$ 为圆周 $x^2+y^2 = a^2$。

**解题步骤**：
1. 在曲线 $L$ 上，$x^2+y^2 = a^2$ 是常数，先代入被积函数：

$$\oint_L (x^2+y^2)\,ds = a^2 \oint_L ds.$$

2. $\oint_L ds$ 就是整条曲线的弧长，即圆周长 $2\pi a$。
3. 所以原式 $= a^2 \cdot 2\pi a = 2\pi a^3$。

**思路点拨**：第一类曲线积分的两个常用技巧——①在曲线上成立的等式（曲线方程）可直接代入被积函数化简；②$\int_L ds = $ 弧长。本题若用参数法（$x = a\cos t,\ y = a\sin t,\ ds = a\,dt$）结果相同，可自行验证。若把被积函数换成 $x^3$（关于 $x$ 为奇函数，而 $L$ 关于 $y$ 轴对称），由对称性直接得 0。

### 例题 2（第二类曲线积分：参数化 + 全微分验证）

**题目**：计算 $\int_L y\,dx + x\,dy$，其中 $L$ 是曲线 $y = \sqrt{x}$ 上从点 $A(1,1)$ 到点 $B(4,2)$ 的弧段。

**解题步骤（方法一：参数化）**：
1. 令 $x = t^2,\ y = t$，则 $t$ 从 1 到 2（起点 $(1,1)$ 对应 $t=1$，终点 $(4,2)$ 对应 $t=2$），且 $dx = 2t\,dt,\ dy = dt$。
2. 代入得

$$\int_L y\,dx + x\,dy = \int_1^2 \big[t\cdot 2t + t^2\big]dt = \int_1^2 3t^2\,dt = t^3\Big|_1^2 = 8 - 1 = 7.$$

**解题步骤（方法二：全微分）**：
3. 注意到 $y\,dx + x\,dy = d(xy)$ 是 $xy$ 的全微分，故积分与路径无关，只取决于端点：

$$\int_L y\,dx + x\,dy = xy\Big|_{(1,1)}^{(4,2)} = 4\cdot 2 - 1\cdot 1 = 7.$$

**思路点拨**：①第二类积分化为定积分时，**上下限由起点、终点决定**（此处 $t: 1 \to 2$），方向不能乱换；②看到 $y\,dx + x\,dy$ 这类"凑得出来的"形式，先想全微分（路径无关），往往一步出答案；两种方法互相验证，结果一致。

### 例题 3（格林公式：闭曲线积分化二重积分）

**题目**：计算 $\oint_L (x^2+y)\,dx + (y^2-x)\,dy$，其中 $L$ 为圆周 $x^2+y^2 = a^2$，取逆时针方向。

**解题步骤**：
1. 令 $P = x^2+y$，$Q = y^2-x$，则 $\dfrac{\partial P}{\partial y} = 1$，$\dfrac{\partial Q}{\partial x} = -1$。
2. $P,Q$ 在全平面有一阶连续偏导数，$L$ 是分段光滑简单闭曲线且取正向（逆时针），满足格林公式条件：

$$\oint_L P\,dx + Q\,dy = \iint_D \left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right)dx\,dy = \iint_D (-1 - 1)\,dx\,dy,$$

其中 $D:\ x^2+y^2 \le a^2$。
3. $\displaystyle \iint_D (-2)\,dx\,dy = -2 \cdot \pi a^2 = -2\pi a^2$，故原式 $= -2\pi a^2$。

**思路点拨**：①看到**闭曲线**上的第二类曲线积分，第一反应是用格林公式化为二重积分（本题一步到位）；②用格林公式前逐条检查条件：闭曲线、正向、偏导连续；③若 $L$ 取顺时针，结果变为 $+2\pi a^2$——方向决定符号。若题目给的是开曲线，可先"补线"成闭曲线再用格林公式，最后减去补线上的积分。

### 例题 4（第一类曲面积分：$dS$ 的根号因子与极坐标）

**题目**：计算 $\iint_\Sigma (x^2+y^2)\,dS$，其中 $\Sigma$ 为锥面 $z = \sqrt{x^2+y^2}$ 被平面 $z=1$ 截下的部分（$0 \le z \le 1$）。

**解题步骤**：
1. 写出 $dS$。由 $z = \sqrt{x^2+y^2}$ 得 $z_x = \dfrac{x}{\sqrt{x^2+y^2}}$，$z_y = \dfrac{y}{\sqrt{x^2+y^2}}$，于是

$$dS = \sqrt{1+z_x^2+z_y^2}\,dx\,dy = \sqrt{1 + \frac{x^2+y^2}{x^2+y^2}}\,dx\,dy = \sqrt{2}\,dx\,dy.$$

2. 确定投影区域：$0 \le z \le 1$ 即 $0 \le \sqrt{x^2+y^2} \le 1$，故 $D:\ x^2+y^2 \le 1$。
3. 化为二重积分并用极坐标：

$$\iint_\Sigma (x^2+y^2)\,dS = \iint_D (x^2+y^2)\,\sqrt{2}\,dx\,dy = \sqrt{2}\int_0^{2\pi}\!\int_0^1 r^2 \cdot r\,dr\,d\theta = \sqrt{2} \cdot 2\pi \cdot \frac{1}{4} = \frac{\sqrt{2}\,\pi}{2}.$$

**思路点拨**：①第一类曲面积分的关键步骤是"算 $dS$ 的根号因子"——本题锥面斜率为 1，恰好得 $dS = \sqrt{2}\,dx\,dy$（即锥面面积是投影面积 $D$ 的 $\sqrt{2}$ 倍，可用"扇形展开"直观理解）；②然后化为投影区域上的二重积分，用极坐标计算；③检验：令被积函数为 1，则 $\iint_\Sigma dS = \sqrt{2} \cdot \pi \cdot 1^2 = \sqrt{2}\,\pi$，正是圆锥的侧面积（底面半径 1、母线长 $\sqrt{2}$，侧面积 $\pi R l = \pi \cdot 1 \cdot \sqrt{2}$），可用来核对计算过程。

## 常见错误与易混淆点

1. **两类曲线积分的方向性混用**：第一类对弧长积分与方向无关，第二类对坐标积分反向变号。做题前先分清"称重型"（第一类）还是"做功型"（第二类）。曲面积分同理：对面积（第一类）与侧无关，对坐标（第二类）换侧变号。
2. **第二类曲线积分化定积分时上下限写反**：下限 = 起点对应的参数，上限 = 终点对应的参数；不要机械地"小数在下、大数在上"。
3. **格林公式方向错**：$L$ 必须取正向（外边界逆时针、内边界顺时针），取反了结果差一个负号。判断口诀：沿 $L$ 前进，区域在左手边即为正向。
4. **用格林/高斯公式前不查条件**：$P,Q,R$ 须一阶连续偏导、区域单连通（或闭曲面内无奇点）；有奇点要用挖洞法，不能硬套公式。
5. **第二类曲面积分投影法的符号**：$\iint_\Sigma R\,dx\,dy$ 取上侧为正、下侧为负；$dy\,dz$、$dz\,dx$ 分别按与 $x$、$y$ 轴正向的夹角判断——**三个积分符号各判各的**，不要统一取正号。
6. **第一类曲面积分漏掉根号因子**：$dS = \sqrt{1+z_x^2+z_y^2}\,dx\,dy$，把曲面积分错写成普通二重积分是常见失分点；而第二类曲面积分投影时**不乘**根号因子、符号另算——两类恰好相反，极易混淆。
7. **两类曲面积分混用**：第二类 = 第一类点乘单位法向量，$dy\,dz = \cos\alpha\,dS$ 等关系要会用（常用来把第二类化为第一类，或由法向量算两类关系）。
8. **斯托克斯公式定向错**：$\Gamma$ 的方向与 $\Sigma$ 的侧必须满足右手法则，方向反了等式两边全错。
9. **漏块**：球面、整圈锥面等多值曲面要分片投影（上下半球分别算）；闭曲线经过奇点（如 $\dfrac{-y}{x^2+y^2}dx + \dfrac{x}{x^2+y^2}dy$ 绕原点一周）时，不能直接断言"路径无关"。
10. **对称性误用**：第一类积分用对称性要求曲线/曲面本身对称，且被积函数是相应变量的**奇函数**；用之前先代入曲线（曲面）方程化简，再判断奇偶。

## 复习与考研提示

- **考试范围**：本章（曲线积分、曲面积分、格林/高斯/斯托克斯公式）为考研**数学一**的内容；数学二、数学三的大纲不包含本部分（数二不考向量场与曲线曲面积分，数三不考三重积分及曲线曲面积分）。具体以当年《全国硕士研究生招生考试数学考试大纲》为准。
- **高频考点**：① 第一类曲线/曲面积分的直接计算（参数化或投影 + 根号因子）；② 第二类曲线积分与格林公式（含"补线"、挖洞法）；③ 曲线积分与路径无关及全微分求原函数；④ 高斯公式求通量（含"补面法"）；⑤ 斯托克斯公式求环量（数学一，偶出小题）。
- **"三看"口诀**：看到**闭曲线**想格林公式（平面）或斯托克斯（空间）；看到**闭曲面通量**想高斯公式；看到**开曲线/开曲面**，要么参数化/投影直接算，要么补线/补面凑成闭的再用公式。
- **路径无关四条件**要能互相推导：$\oint = 0 \iff$ 与路径无关 $\iff$ 存在原函数 $\iff \partial P/\partial y = \partial Q/\partial x$（单连通区域内）。求原函数常用折线法或凑微分。
- **方向与符号是本章的生命线**：第二类积分的方向、曲面的"侧"决定符号，审题时先把方向、侧、正向圈出来，再动笔。
- **与前后章联动**：格林公式把曲线积分变二重积分（第 10 章），高斯公式把曲面积分变三重积分（第 10 章），斯托克斯公式联系空间曲线与曲面；配合第 8 章的曲面方程、法向量和第 9 章的偏导数，形成"多元积分"完整闭环。
- **建议练习量**：五类基本计算（两类曲线积分、两类曲面积分、三大公式）各做 2~3 题，重点练"补面法""挖洞法"和含方向符号的题；考前把三大公式及各自的使用条件默写一遍。
