## 为什么要按这个顺序学

高等数学是一条**逻辑递进**的主线，每一章都建立在前一章的基础之上：

```
函数 → 极限 → 连续 ──→ 导数 / 微分 ──→ 中值定理（导数应用）
                              │
                              └──→ 不定积分 → 定积分 → 定积分应用
```

- **极限是地基**：导数、积分、级数本质都是"某种极限"。
- **导数是核心工具**：中值定理、洛必达法则、泰勒公式、单调性、极值、凹凸性全都建立在导数之上。
- **积分是导数的逆运算**：先学不定积分（找原函数），再学定积分（面积、牛顿-莱布尼茨公式），最后学定积分的应用（微元法）。
- **微分方程**是一元微积分的综合应用，建议学完上册后学习。
- **多元部分**（空间几何 → 多元微分 → 重积分 → 曲线曲面积分）是同一套思想在更高维度的推广，逐层递进。
- **无穷级数**是极限与泰勒公式的延伸，可放在最后。

## 学习路线建议

### 路线 A：期末速成（2~4 周）
1. 先通读 [-函数与极限](/specials/math/notes/calculus/01/)，重点练**求极限**（等价无穷小 + 洛必达）。
2. 接着 [-导数与微分](/specials/math/notes/calculus/02/) 与 [-微分中值定理与导数的应用](/specials/math/notes/calculus/03/)，掌握求导与中值定理题型。
3. 积分部分：[-不定积分](/specials/math/notes/calculus/04/) → [-定积分](/specials/math/notes/calculus/05/) → [-定积分的应用](/specials/math/notes/calculus/06/)，重点是不定积分的换元与分部。
4. 视考试范围补充 [-微分方程](/specials/math/notes/calculus/07/) 或多元部分。
5. 考前刷 [附录-常用公式与结论速查](/specials/math/notes/calculus/13/)。

### 路线 B：考研系统复习（建议顺序）
- **基础阶段**：按上述主线逐章精读，每章完成"知识点详解 + 典型例题"。
- **强化阶段**：重点攻克三大难点——中值定理证明（[-微分中值定理与导数的应用](/specials/math/notes/calculus/03/)）、多元积分（[-重积分](/specials/math/notes/calculus/10/)、[-曲线积分与曲面积分](/specials/math/notes/calculus/11/)）、级数（[-无穷级数](/specials/math/notes/calculus/12/)）。
- **冲刺阶段**：以 [附录-常用公式与结论速查](/specials/math/notes/calculus/13/) 为准绳做查漏补缺。

## 学习方法提示

1. **公式要"会推导"而不是"死记"**：如求导公式 → 积分公式是逆运算；泰勒展开 → 幂级数是推广。
2. **每章笔记的结构统一**：本章概览 → 知识点详解（定义/定理/公式 + 通俗讲解 + 注意）→ 典型例题 → 常见错误 → 复习与考研提示，适合按章自测。
3. **善用双链**：做题卡壳时，顺着 [附录-常用公式与结论速查](/specials/math/notes/calculus/13/) 定位公式，再回到对应章节看讲解。
4. **数学一定要动手**：每章至少独立重做 2~4 道典型例题，再看"常见错误"部分对照自己的易错点。
