# 附录 常用公式与结论速查

> 本页汇总高等数学常用公式与结论，供期末与考研复习快速查阅。未特别注明时，$C$ 为任意常数，条件默认在使公式有意义的范围内成立。

## 1. 基本初等函数求导公式

| 函数 | 导数 |
| :--- | :--- |
| $C$（常数） | $0$ |
| $x^\mu$ | $\mu x^{\mu-1}$ |
| $\sin x$ | $\cos x$ |
| $\cos x$ | $-\sin x$ |
| $\tan x$ | $\sec^2 x$ |
| $\cot x$ | $-\csc^2 x$ |
| $\sec x$ | $\sec x \tan x$ |
| $\csc x$ | $-\csc x \cot x$ |
| $a^x$ | $a^x \ln a$ |
| $e^x$ | $e^x$ |
| $\log_a x$ | $\dfrac{1}{x \ln a}$ |
| $\ln x$ | $\dfrac{1}{x}$ |
| $\arcsin x$ | $\dfrac{1}{\sqrt{1-x^2}}$ |
| $\arccos x$ | $-\dfrac{1}{\sqrt{1-x^2}}$ |
| $\arctan x$ | $\dfrac{1}{1+x^2}$ |
| $\operatorname{arccot} x$ | $-\dfrac{1}{1+x^2}$ |
| $\sinh x$ | $\cosh x$ |
| $\cosh x$ | $\sinh x$ |

**求导法则：**
- 四则运算：$(u \pm v)' = u' \pm v'$，$(uv)' = u'v + uv'$，$\left(\dfrac{u}{v}\right)' = \dfrac{u'v - uv'}{v^2}$。
- 复合函数（链式法则）：$[f(g(x))]' = f'(g(x)) \cdot g'(x)$。
- 反函数：若 $y = f(x)$ 的反函数为 $x = \varphi(y)$，则 $\varphi'(y) = \dfrac{1}{f'(x)}$。
- 对数求导法：幂指函数 $y = u(x)^{v(x)}$ 及多因子乘除式，先取对数再求导。

**积分线性性质：** $\int [\alpha f(x) + \beta g(x)]\,dx = \alpha\int f(x)\,dx + \beta\int g(x)\,dx$。

## 3. 等价无穷小替换（$x \to 0$ 时）

| 等价关系 | 等价关系 |
| :--- | :--- |
| $\sin x \sim x$ | $\tan x \sim x$ |
| $\arcsin x \sim x$ | $\arctan x \sim x$ |
| $1 - \cos x \sim \dfrac{x^2}{2}$ | $e^x - 1 \sim x$ |
| $a^x - 1 \sim x \ln a$ | $\ln(1+x) \sim x$ |
| $(1+x)^\alpha - 1 \sim \alpha x$ | $x - \sin x \sim \dfrac{x^3}{6}$ |
| $\tan x - x \sim \dfrac{x^3}{3}$ | $\arcsin x - x \sim \dfrac{x^3}{6}$ |

**使用要点：**
- 更一般地，当 $u(x) \to 0$ 时，$\sin u \sim u$、$\ln(1+u) \sim u$、$e^u - 1 \sim u$、$(1+u)^\alpha - 1 \sim \alpha u$ 等均成立。
- 等价无穷小只能**整体替换乘积或商中的因子**，加减法中不可随意替换（除非替换后能证明极限存在）。

## 4. 两个重要极限

**第一重要极限：**
$$
\lim_{x \to 0}\frac{\sin x}{x} = 1
$$
常见变形：
- $\lim_{x \to 0}\dfrac{\tan x}{x} = 1$，$\lim_{x \to 0}\dfrac{\arcsin x}{x} = 1$，$\lim_{x \to 0}\dfrac{\arctan x}{x} = 1$
- $\lim_{x \to 0}\dfrac{1 - \cos x}{x^2} = \dfrac{1}{2}$
- 一般形式：$\lim \dfrac{\sin u(x)}{u(x)} = 1$（当 $u(x) \to 0$ 时）

**第二重要极限：**
$$
\lim_{x \to \infty}\left(1 + \frac{1}{x}\right)^x = e
$$
常见变形：
- $\lim_{x \to 0}(1+x)^{\frac{1}{x}} = e$，$\lim_{x \to 0}(1+\sin x)^{\frac{1}{x}} = e$
- 一般形式：$\lim (1+u)^{\frac{1}{u}} = e$（当 $u \to 0$ 时）
- $1^{\infty}$ 型通用做法：$\lim (1+u)^v = e^{\lim uv}$（$u \to 0$ 时）

## 5. 常用函数的麦克劳林展开式

| 函数 | 展开式（含通项） | 收敛域 |
| :--- | :--- | :--- |
| $e^x$ | $\displaystyle\sum_{n=0}^{\infty}\frac{x^n}{n!} = 1 + x + \frac{x^2}{2!} + \cdots$ | $\mathbb{R}$ |
| $\sin x$ | $\displaystyle\sum_{n=0}^{\infty}(-1)^n\frac{x^{2n+1}}{(2n+1)!} = x - \frac{x^3}{3!} + \frac{x^5}{5!} - \cdots$ | $\mathbb{R}$ |
| $\cos x$ | $\displaystyle\sum_{n=0}^{\infty}(-1)^n\frac{x^{2n}}{(2n)!} = 1 - \frac{x^2}{2!} + \frac{x^4}{4!} - \cdots$ | $\mathbb{R}$ |
| $\ln(1+x)$ | $\displaystyle\sum_{n=1}^{\infty}(-1)^{n-1}\frac{x^n}{n} = x - \frac{x^2}{2} + \frac{x^3}{3} - \cdots$ | $-1 < x \le 1$ |
| $\dfrac{1}{1-x}$ | $\displaystyle\sum_{n=0}^{\infty}x^n = 1 + x + x^2 + \cdots$ | $\vert x\vert < 1$ |
| $\dfrac{1}{1+x}$ | $\displaystyle\sum_{n=0}^{\infty}(-1)^n x^n = 1 - x + x^2 - \cdots$ | $\vert x\vert < 1$ |
| $(1+x)^\alpha$ | $\displaystyle 1 + \alpha x + \frac{\alpha(\alpha-1)}{2!}x^2 + \cdots$ | $\vert x\vert < 1$（端点视 $\alpha$ 而定） |
| $\arctan x$ | $\displaystyle\sum_{n=0}^{\infty}(-1)^n\frac{x^{2n+1}}{2n+1} = x - \frac{x^3}{3} + \frac{x^5}{5} - \cdots$ | $\vert x\vert \le 1$ |
| $\arcsin x$ | $x + \dfrac{x^3}{6} + \dfrac{3x^5}{40} + \cdots$ | $\vert x\vert \le 1$ |
| $\tan x$ | $x + \dfrac{x^3}{3} + \dfrac{2x^5}{15} + \cdots$ | $\vert x\vert < \dfrac{\pi}{2}$ |

**记忆技巧：** $e^x$ 全为正号，$\sin x$ 只含奇次幂且正负交替，$\cos x$ 只含偶次幂且正负交替，$\ln(1+x)$ 各项符号正负交替且系数为 $\dfrac{1}{n}$。

## 6. 微分中值定理与洛必达法则

| 定理 | 条件 | 结论 |
| :--- | :--- | :--- |
| 罗尔定理 | $f$ 在 $[a,b]$ 连续，$(a,b)$ 内可导，$f(a) = f(b)$ | 存在 $\xi \in (a,b)$，使 $f'(\xi) = 0$ |
| 拉格朗日中值定理 | $f$ 在 $[a,b]$ 连续，$(a,b)$ 内可导 | 存在 $\xi \in (a,b)$，使 $f(b) - f(a) = f'(\xi)(b-a)$ |
| 柯西中值定理 | $f, g$ 在 $[a,b]$ 连续、$(a,b)$ 内可导且 $g'(x) \ne 0$ | 存在 $\xi \in (a,b)$，使 $\dfrac{f(b)-f(a)}{g(b)-g(a)} = \dfrac{f'(\xi)}{g'(\xi)}$ |

**泰勒中值定理：** 若 $f$ 在含 $x_0$ 的区间内有 $n+1$ 阶导数，则
$$
f(x) = f(x_0) + f'(x_0)(x-x_0) + \cdots + \frac{f^{(n)}(x_0)}{n!}(x-x_0)^n + R_n(x)
$$
- 拉格朗日余项：$R_n(x) = \dfrac{f^{(n+1)}(\xi)}{(n+1)!}(x-x_0)^{n+1}$（$\xi$ 介于 $x$ 与 $x_0$ 之间）
- 皮亚诺余项：$R_n(x) = o\big((x-x_0)^n\big)$（用于求极限）

**洛必达法则：** 若 $\lim \dfrac{f(x)}{g(x)}$ 为 $\dfrac{0}{0}$ 或 $\dfrac{\infty}{\infty}$ 型，且 $f'(x)$、$g'(x)$ 存在、$g'(x) \ne 0$，$\lim \dfrac{f'(x)}{g'(x)}$ 存在（或为无穷大），则
$$
\lim \frac{f(x)}{g(x)} = \lim \frac{f'(x)}{g'(x)}
$$
- 可连续多次使用；若求导后极限不存在（非无穷），**不能**断言原极限不存在。
- 其他未定式转化：$0 \cdot \infty$ 化为 $\dfrac{0}{0}$ 或 $\dfrac{\infty}{\infty}$ 型；$\infty - \infty$ 先通分或有理化；$1^{\infty}$、$0^{0}$、$\infty^{0}$ 先取对数：$\lim v \ln u$。

## 7. 常见函数的 n 阶导数与莱布尼茨公式

| 函数 | $n$ 阶导数 |
| :--- | :--- |
| $e^x$ | $e^x$ |
| $a^x$ | $a^x (\ln a)^n$ |
| $\sin x$ | $\sin\left(x + \dfrac{n\pi}{2}\right)$ |
| $\cos x$ | $\cos\left(x + \dfrac{n\pi}{2}\right)$ |
| $\ln x$ | $\dfrac{(-1)^{n-1}(n-1)!}{x^n}$ |
| $\ln(1+x)$ | $\dfrac{(-1)^{n-1}(n-1)!}{(1+x)^n}$ |
| $\dfrac{1}{x}$ | $\dfrac{(-1)^n n!}{x^{n+1}}$ |
| $\dfrac{1}{x+a}$ | $\dfrac{(-1)^n n!}{(x+a)^{n+1}}$ |
| $x^\mu$ | $\mu(\mu-1)\cdots(\mu-n+1)\,x^{\mu-n}$ |

**莱布尼茨公式：**
$$
(uv)^{(n)} = \sum_{k=0}^{n} C_n^k\, u^{(k)}\, v^{(n-k)}
$$
适用情形：两个因子中有一个是低次多项式（其高阶导数为 0）或三角函数、指数函数。

## 8. 积分常用技巧速记

- **第一类换元（凑微分）：** $\int f[\varphi(x)]\,\varphi'(x)\,dx = \int f(u)\,du$，如 $\int f(\ln x)\dfrac{dx}{x} = \int f(u)\,du$。
- **第二类换元（三角代换）：**

| 被积函数含 | 令 | 目的 |
| :--- | :--- | :--- |
| $\sqrt{a^2 - x^2}$ | $x = a\sin t$ | 化为 $a\cos t$ |
| $\sqrt{a^2 + x^2}$ | $x = a\tan t$ | 化为 $a\sec t$ |
| $\sqrt{x^2 - a^2}$ | $x = a\sec t$ | 化为 $a\tan t$ |

- **分部积分：** $\int u\,dv = uv - \int v\,du$。选择 $u$ 的次序口诀：**反对幂指三**（反三角函数、对数、幂函数、指数、三角函数，排在前面的作 $u$）。
- **对称区间奇偶性：** $f$ 为奇函数 ⇒ $\displaystyle\int_{-a}^{a} f(x)\,dx = 0$；$f$ 为偶函数 ⇒ $\displaystyle\int_{-a}^{a} f(x)\,dx = 2\int_0^a f(x)\,dx$。
- **华里士公式（点火公式）：**
$$
\int_0^{\frac{\pi}{2}}\sin^n x\,dx = \int_0^{\frac{\pi}{2}}\cos^n x\,dx = 
\begin{cases}
\dfrac{(n-1)!!}{n!!}\cdot\dfrac{\pi}{2}, & n \text{ 为偶数} \\[6pt]
\dfrac{(n-1)!!}{n!!}, & n \text{ 为奇数}
\end{cases}
$$
- **区间再现：** $\displaystyle\int_0^{\pi} x\,f(\sin x)\,dx = \frac{\pi}{2}\int_0^{\pi} f(\sin x)\,dx$。
- **周期函数：** $f$ 以 $T$ 为周期 ⇒ $\displaystyle\int_a^{a+T} f(x)\,dx = \int_0^T f(x)\,dx$。
- **常用结论：** $\displaystyle\int_0^{+\infty} e^{-x^2}\,dx = \frac{\sqrt{\pi}}{2}$；$\displaystyle\int_{-a}^{a}\sqrt{a^2-x^2}\,dx = \frac{\pi a^2}{2}$。

## 9. 常见平面图形面积、旋转体体积与弧长

**平面图形面积：**
- 直角坐标：$A = \displaystyle\int_a^b \big\vert f(x) - g(x)\big\vert\,dx$（上曲线减下曲线）
- 极坐标（$r = r(\theta)$，$\alpha \le \theta \le \beta$）：$A = \dfrac{1}{2}\displaystyle\int_\alpha^\beta r^2(\theta)\,d\theta$

**旋转体体积：**
- 绕 $x$ 轴：$V = \pi\displaystyle\int_a^b [f(x)]^2\,dx$
- 绕 $y$ 轴（薄壳法，$f(x) \ge 0$，$0 \le a < b$）：$V = 2\pi\displaystyle\int_a^b x\,f(x)\,dx$

**弧长：**
- 直角坐标：$s = \displaystyle\int_a^b \sqrt{1 + [f'(x)]^2}\,dx$
- 参数方程 $x = \varphi(t),\ y = \psi(t)$：$s = \displaystyle\int_\alpha^\beta \sqrt{[\varphi'(t)]^2 + [\psi'(t)]^2}\,dt$
- 极坐标：$s = \displaystyle\int_\alpha^\beta \sqrt{r^2(\theta) + [r'(\theta)]^2}\,d\theta$

**旋转体侧面积**（曲线绕 $x$ 轴，$f(x) \ge 0$）：$S = 2\pi\displaystyle\int_a^b f(x)\sqrt{1 + [f'(x)]^2}\,dx$。

## 10. 微分方程类型与解法速查

| 类型 | 标准形式 | 解法要点 |
| :--- | :--- | :--- |
| 可分离变量 | $y' = f(x)\,g(y)$ | 分离变量：$\displaystyle\int\frac{dy}{g(y)} = \int f(x)\,dx + C$ |
| 齐次方程 | $y' = \varphi\left(\dfrac{y}{x}\right)$ | 令 $u = \dfrac{y}{x}$，化为可分离变量 |
| 一阶线性 | $y' + P(x)y = Q(x)$ | $y = e^{-\int P\,dx}\left[\displaystyle\int Q\,e^{\int P\,dx}\,dx + C\right]$ |
| 伯努利方程 | $y' + P(x)y = Q(x)y^n$ | 令 $z = y^{1-n}$，化为一阶线性方程 |
| 全微分方程 | $P\,dx + Q\,dy = 0$，且 $\dfrac{\partial P}{\partial y} = \dfrac{\partial Q}{\partial x}$ | 求原函数 $u(x,y)$ 使 $du = P\,dx + Q\,dy$，通解 $u = C$ |
| 可降阶（Ⅰ） | $y'' = f(x)$ | 连续积分两次 |
| 可降阶（Ⅱ） | $y'' = f(x, y')$ | 令 $p = y'$，得 $p' = f(x, p)$ |
| 可降阶（Ⅲ） | $y'' = f(y, y')$ | 令 $p = y'$，则 $y'' = p\dfrac{dp}{dy}$ |
| 二阶常系数齐次 | $y'' + py' + qy = 0$ | 特征方程 $r^2 + pr + q = 0$，见下 |
| 二阶常系数非齐次 | $y'' + py' + qy = f(x)$ | 齐次通解 $+$ 特解（待定系数法） |

**特征根与齐次通解：**
- 两不等实根 $r_1 \ne r_2$：$y = C_1 e^{r_1 x} + C_2 e^{r_2 x}$
- 二重实根 $r_1 = r_2 = r$：$y = (C_1 + C_2 x)\,e^{rx}$
- 共轭复根 $r_{1,2} = \alpha \pm i\beta$：$y = e^{\alpha x}\big(C_1\cos\beta x + C_2\sin\beta x\big)$

**非齐次特解**（$f(x) = e^{\lambda x} P_m(x)$，$P_m$ 为 $m$ 次多项式）：设 $y^* = x^k e^{\lambda x} Q_m(x)$，其中 $k$ 为 $\lambda$ 作为特征根的重数（$0, 1, 2$），$Q_m$ 为待定 $m$ 次多项式。

## 11. 级数审敛法速查

**正项级数** $\displaystyle\sum_{n=1}^{\infty}u_n$（$u_n \ge 0$）：

| 方法 | 条件 | 结论 |
| :--- | :--- | :--- |
| 比较审敛 | $u_n \le v_n$ | $\sum v_n$ 收敛 ⇒ $\sum u_n$ 收敛；$\sum u_n$ 发散 ⇒ $\sum v_n$ 发散 |
| 极限比较 | $\displaystyle\lim_{n\to\infty}\frac{u_n}{v_n} = l \ (0 < l < +\infty)$ | 两级数同敛散 |
| 比值审敛（达朗贝尔） | $\displaystyle\lim_{n\to\infty}\frac{u_{n+1}}{u_n} = \rho$ | $\rho < 1$ 收敛；$\rho > 1$ 发散；$\rho = 1$ 失效 |
| 根值审敛（柯西） | $\displaystyle\lim_{n\to\infty}\sqrt[n]{u_n} = \rho$ | 同上 |
| 积分审敛 | $u_n = f(n)$，$f(x)$ 单调递减非负 | $\displaystyle\int_1^{+\infty}f(x)\,dx$ 与 $\sum u_n$ 同敛散 |

**常用基准级数：** $p$-级数 $\displaystyle\sum\frac{1}{n^p}$：$p > 1$ 收敛，$p \le 1$ 发散；等比级数 $\displaystyle\sum aq^{n-1}$：$\vert q\vert < 1$ 收敛。

**交错级数（莱布尼茨审敛法）：** 若 $u_n \ge u_{n+1}$ 且 $\lim\limits_{n\to\infty}u_n = 0$（单调递减趋于 0），则 $\displaystyle\sum_{n=1}^{\infty}(-1)^{n-1}u_n$ 收敛，且余项 $\vert R_n\vert \le u_{n+1}$。

**绝对收敛与条件收敛：** $\sum\vert u_n\vert$ 收敛 ⇒ $\sum u_n$ 绝对收敛；$\sum u_n$ 收敛但 $\sum\vert u_n\vert$ 发散 ⇒ 条件收敛。绝对收敛级数可任意重排。

**幂级数** $\displaystyle\sum_{n=0}^{\infty}a_n x^n$：
- 收敛半径：$R = \lim\limits_{n\to\infty}\left\vert\dfrac{a_n}{a_{n+1}}\right\vert$（若极限存在），或 $R = \dfrac{1}{\lim\limits_{n\to\infty}\sqrt[n]{\vert a_n\vert}}$。
- 收敛域：$\vert x\vert < R$ 内绝对收敛，$\vert x\vert > R$ 发散，端点 $x = \pm R$ 需单独代入判别。
- **阿贝尔定理：** 在收敛区间内幂级数可逐项求导、逐项积分，收敛半径不变（端点处可能改变）。

## 12. 常用特殊值

**特殊角三角函数值：**

| $\theta$ | $\sin\theta$ | $\cos\theta$ | $\tan\theta$ |
| :--- | :--- | :--- | :--- |
| $0$ | $0$ | $1$ | $0$ |
| $\dfrac{\pi}{6}$ | $\dfrac{1}{2}$ | $\dfrac{\sqrt{3}}{2}$ | $\dfrac{\sqrt{3}}{3}$ |
| $\dfrac{\pi}{4}$ | $\dfrac{\sqrt{2}}{2}$ | $\dfrac{\sqrt{2}}{2}$ | $1$ |
| $\dfrac{\pi}{3}$ | $\dfrac{\sqrt{3}}{2}$ | $\dfrac{1}{2}$ | $\sqrt{3}$ |
| $\dfrac{\pi}{2}$ | $1$ | $0$ | 不存在 |

**常见极限值：**
- $\lim\limits_{x \to 0}\dfrac{\sin x}{x} = 1$；$\lim\limits_{x \to \infty}\left(1+\dfrac{1}{x}\right)^x = e$；$\lim\limits_{x \to 0}(1+x)^{\frac{1}{x}} = e$
- $\lim\limits_{x \to \infty}\dfrac{\sin x}{x} = 0$（有界量与无穷小之积）
- $\lim\limits_{x \to 0}\dfrac{\ln(1+x)}{x} = 1$；$\lim\limits_{x \to 0}\dfrac{e^x - 1}{x} = 1$；$\lim\limits_{x \to 0}\dfrac{a^x - 1}{x} = \ln a$
- $\lim\limits_{x \to 0^+} x \ln x = 0$；$\lim\limits_{x \to 0^+} x^x = 1$
- $\lim\limits_{n \to \infty}\sqrt[n]{n} = 1$；$\lim\limits_{n \to \infty}\sqrt[n]{a} = 1$（$a > 0$）
- $\lim\limits_{n \to \infty}\dfrac{n^k}{a^n} = 0$（$a > 1$，指数增长快于幂函数）；$\lim\limits_{n \to \infty}\dfrac{\ln n}{n^a} = 0$（$a > 0$）；$\lim\limits_{n \to \infty}\dfrac{a^n}{n!} = 0$

**常用常数：** $e \approx 2.7183$，$\pi \approx 3.1416$，$\ln 2 \approx 0.6931$，$\ln 10 \approx 2.3026$，$\sqrt{2} \approx 1.4142$，$\sqrt{3} \approx 1.7321$。
