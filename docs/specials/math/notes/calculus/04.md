# 第 4 章 不定积分

## 本章概览

上一章（第 3 章）我们建立了导数与微分体系，解决了"已知运动规律求瞬时速度"这类问题。本章反过来研究它的逆运算：已知导数（如瞬时速度）$f(x)$，求原来的函数（如位移规律）$F(x)$。这种逆运算就是**不定积分**（indefinite integral），被积出来的函数 $F(x)$ 称为**原函数**。

本章解决的核心问题是：

1. 什么样的函数存在原函数？原函数有什么结构？（原函数存在定理、原函数之间相差常数）
2. 如何求出原函数？（基本积分表、凑微分法、换元法、分部积分法、部分分式法）
3. 逆运算有哪些性质（线性性、与求导互逆），以及计算中的注意事项。

与前几章的联系：

- 以第 2、3 章的求导法则为"底本"——每一条积分公式都可以由一条求导公式"倒过来"得到；
- 不定积分是第 5 章定积分计算（牛顿—莱布尼茨公式）的基石；
- 第 7 章微分方程的求解，本质上就是"求原函数"。

简言之：**微分是"问路"，积分是"找路"**——已知一个函数的"变化率"，把函数本身找回来。

## 知识点详解

### 4.1 原函数与不定积分的概念

**定义（原函数）**：设函数 $f(x)$ 定义在区间 $I$ 上。若存在函数 $F(x)$，使得对区间 $I$ 内任意一点 $x$，都有

$$F'(x) = f(x),$$

则称 $F(x)$ 为 $f(x)$ 在区间 $I$ 上的一个**原函数**（antiderivative）。

**定理（原函数存在定理）**：如果 $f(x)$ 在区间 $I$ 上连续，那么 $f(x)$ 在区间 $I$ 上一定存在原函数。

**定理（原函数的结构）**：若 $F(x)$ 是 $f(x)$ 在区间 $I$ 上的一个原函数，则 $F(x) + C$（$C$ 为任意常数）都是 $f(x)$ 的原函数；反之，$f(x)$ 的任意两个原函数之间只相差一个常数。

**定义（不定积分）**：$f(x)$ 在区间 $I$ 上的原函数的全体称为 $f(x)$ 的**不定积分**，记作

$$\int f(x)\,dx = F(x) + C,$$

其中 $\int$ 称为积分号，$f(x)$ 称为被积函数，$x$ 称为积分变量，$f(x)\,dx$ 称为被积表达式，$C$ 称为积分常数（任意常数）。

**通俗讲解**：求导好比"从路程读瞬时速度"，而求不定积分好比"凭速度表还原走过的路程"。但"还原"并不唯一：同样的速度，起点不同（相差一个常数 $C$），位置就不同——这就是为什么不定积分的结果总带一个任意常数 $C$。从几何上看，$y = F(x) + C$ 是一族"平行"曲线（各点切线斜率都等于 $f(x)$），称为**积分曲线族**。

**注意**：

- 原函数的概念必须针对**区间**而言，讨论都在区间内部进行；
- 连续函数必有原函数，但有原函数的函数未必连续（例如 $F(x) = x^2\sin\frac{1}{x}$ 的导数 $f(x)$ 在 $x=0$ 处不连续，却存在原函数 $F$）——记住"连续 ⇒ 存在原函数"，反向不成立；
- "求不定积分"的结果是一个**函数族**，不是单个数；验证结果是否正确，只需对它求导，看是否回到被积函数。

### 4.2 不定积分的性质

**性质 1（求导与积分互逆）**：

$$\left(\int f(x)\,dx\right)' = f(x), \qquad \mathrm{d}\left(\int f(x)\,dx\right) = f(x)\,dx.$$

**性质 2（积分与微分互逆）**：

$$\int F'(x)\,dx = F(x) + C, \qquad \int \mathrm{d}F(x) = F(x) + C.$$

**性质 3（线性性——常数因子）**：设 $k$ 为非零常数，则

$$\int k f(x)\,dx = k\int f(x)\,dx.$$

**性质 4（线性性——加减）**：

$$\int [f(x) \pm g(x)]\,dx = \int f(x)\,dx \pm \int g(x)\,dx.$$

**通俗讲解**：性质 1、2 合起来说明"微分与积分互为逆运算"：先积分后求导等于原函数，先求导后积分等于原函数加上常数。性质 3、4 说明不定积分对"加减与数乘"是线性的——因此可以把复杂的被积函数拆成若干简单项分别积分，再把结果相加（各常数合并成一个 $C$）。

**注意**：

- 性质 3 中 $k \neq 0$（$k = 0$ 时左边是 $\int 0\,dx = C$，右边是 $0$，两者不相等）；
- 线性性**不**适用于乘法与除法：$\int f(x)g(x)\,dx \neq \int f(x)\,dx \cdot \int g(x)\,dx$；
- 多项拆分后每个不定积分都带常数，最后必须合并为一个任意常数 $C$。

### 4.3 基本积分表

以下公式中 $C$ 均为任意常数，$a$ 为正常数。

**常数与幂函数**：

$$\int k\,dx = kx + C,$$

$$\int x^{\mu}\,dx = \frac{x^{\mu+1}}{\mu+1} + C \quad (\mu \neq -1),$$

$$\int \frac{1}{x}\,dx = \ln|x| + C.$$

**指数函数**：

$$\int e^x\,dx = e^x + C, \qquad \int a^x\,dx = \frac{a^x}{\ln a} + C \quad (a > 0,\, a \neq 1).$$

**三角函数**：

$$\int \sin x\,dx = -\cos x + C, \qquad \int \cos x\,dx = \sin x + C,$$

$$\int \sec^2 x\,dx = \tan x + C, \qquad \int \csc^2 x\,dx = -\cot x + C,$$

$$\int \sec x \tan x\,dx = \sec x + C, \qquad \int \csc x \cot x\,dx = -\csc x + C,$$

$$\int \tan x\,dx = -\ln|\cos x| + C, \qquad \int \cot x\,dx = \ln|\sin x| + C,$$

$$\int \sec x\,dx = \ln|\sec x + \tan x| + C, \qquad \int \csc x\,dx = \ln|\csc x - \cot x| + C.$$

**反三角型（重要）**：

$$\int \frac{dx}{\sqrt{1-x^2}} = \arcsin x + C, \qquad \int \frac{dx}{1+x^2} = \arctan x + C.$$

**一般化形式（必背）**：

$$\int \frac{dx}{a^2 + x^2} = \frac{1}{a}\arctan\frac{x}{a} + C,$$

$$\int \frac{dx}{a^2 - x^2} = \frac{1}{2a}\ln\left|\frac{a+x}{a-x}\right| + C,$$

$$\int \frac{dx}{\sqrt{a^2 - x^2}} = \arcsin\frac{x}{a} + C,$$

$$\int \frac{dx}{\sqrt{x^2 + a^2}} = \ln\left(x + \sqrt{x^2 + a^2}\right) + C,$$

$$\int \frac{dx}{\sqrt{x^2 - a^2}} = \ln\left|x + \sqrt{x^2 - a^2}\right| + C,$$

$$\int \sqrt{a^2 - x^2}\,dx = \frac{x}{2}\sqrt{a^2 - x^2} + \frac{a^2}{2}\arcsin\frac{x}{a} + C.$$

**常用补充**：

$$\int \sec^3 x\,dx = \frac{1}{2}\sec x \tan x + \frac{1}{2}\ln|\sec x + \tan x| + C,$$

$$\int \frac{dx}{x^2 - a^2} = \frac{1}{2a}\ln\left|\frac{x-a}{x+a}\right| + C.$$

**通俗讲解**：这张表不是死记硬背的清单，而是"求导公式表"的镜像：$\int x^{\mu}dx$ 由 $(x^{\mu+1})' = (\mu+1)x^{\mu}$ 反推；$\int \frac{1}{x}dx = \ln|x| + C$ 由 $(\ln|x|)' = \frac{1}{x}$ 反推。所以背积分表最好的办法是**同时背对应的求导公式**，二者互相验证。

**注意**：

- $\int \frac{1}{x}\,dx = \ln|x| + C$ 中的绝对值不能丢（$x$ 可为负，而 $\ln x$ 只对 $x > 0$ 有意义）；若题目明确给出 $x > 0$ 的区间，才可写成 $\ln x + C$；
- $\int a^x\,dx = \frac{a^x}{\ln a} + C$ 要求 $a > 0$ 且 $a \neq 1$；
- $\int \frac{dx}{\sqrt{x^2+a^2}}$ 的结果可以写成 $\ln\left(x+\sqrt{x^2+a^2}\right) + C$ 而不带绝对值（因为 $x + \sqrt{x^2+a^2} > 0$ 恒成立）；而 $\sqrt{x^2-a^2}$ 的情形必须带绝对值。

### 4.4 第一类换元积分法（凑微分法）

**定理**：设 $\int f(u)\,du = F(u) + C$，且 $u = \varphi(x)$ 可导，则

$$\int f[\varphi(x)]\,\varphi'(x)\,dx = F[\varphi(x)] + C.$$

**通俗讲解**：观察被积表达式，若能把它整理成"$f(\varphi(x)) \cdot \varphi'(x)\,dx$"的形状，就把 $\varphi'(x)\,dx$ 看成 $\mathrm{d}\varphi(x)$（微分），于是

$$\int f[\varphi(x)]\,\varphi'(x)\,dx = \left.\int f(u)\,du\right|_{u = \varphi(x)} = F(\varphi(x)) + C.$$

整个过程没有引入新变量，只是"把某一部分凑成某个函数的微分"，因此叫**凑微分法**。形象地说：被积函数里"含谁的导数，就把谁凑成 $d(\cdot)$"。

**常用凑微分公式**（熟记）：

$$dx = \frac{1}{a}\,d(ax+b), \qquad x\,dx = \frac{1}{2}\,d(x^2), \qquad x^{n-1}\,dx = \frac{1}{n}\,d(x^n),$$

$$\frac{1}{x}\,dx = d(\ln x), \qquad \frac{1}{\sqrt{x}}\,dx = 2\,d(\sqrt{x}), \qquad e^x\,dx = d(e^x),$$

$$\sin x\,dx = -d(\cos x), \qquad \cos x\,dx = d(\sin x), \qquad \sec^2 x\,dx = d(\tan x),$$

$$\frac{1}{1+x^2}\,dx = d(\arctan x), \qquad \frac{1}{\sqrt{1-x^2}}\,dx = d(\arcsin x).$$

**典型模式**：

- 线性式：$\int f(ax+b)\,dx = \frac{1}{a}\int f(ax+b)\,d(ax+b)$；
- 幂型：$\int x^{n-1}f(x^n)\,dx = \frac{1}{n}\int f(x^n)\,d(x^n)$；
- 三角型：$\int \sin^n x \cos x\,dx$（凑 $d(\sin x)$）、$\int \cos^n x \sin x\,dx$（凑 $d(\cos x)$）、$\int \tan^n x \sec^2 x\,dx$（凑 $d(\tan x)$）；
- 对数型：$\int \frac{f'(x)}{f(x)}\,dx = \ln|f(x)| + C$（分子恰为分母的导数时）。

**注意**：

- 凑微分**必须验证**：$\varphi'(x)\,dx$ 是否真的等于被积表达式里剩下的那一部分（差一个常数倍没关系，差的倍数用 $\frac{1}{k}$ 补上）；
- 第一类换元的结果不要写回 $u$，直接把 $u = \varphi(x)$ 代回；
- 凑微分与"直接积分"常常混用：先凑微分，再套基本积分表。

### 4.5 第二类换元积分法

**定理**：设 $x = \psi(t)$ 单调、可导，且 $\psi'(t) \neq 0$。若

$$\int f[\psi(t)]\,\psi'(t)\,dt = G(t) + C,$$

则

$$\int f(x)\,dx = G[\psi^{-1}(x)] + C.$$

**通俗讲解**：第一类换元是"把内层函数凑出来"；第二类换元则是**主动引入新变量**：当 $\sqrt{a^2-x^2}$、$\sqrt{x^2 \pm a^2}$、$\sqrt[n]{ax+b}$ 等根式直接出现在被积函数中而难以处理时，通过恰当的代换 $x = \psi(t)$ 把根式"脱掉"，化为 $t$ 的三角函数或有理函数积分。做完积分后**必须把 $t$ 用 $x$ 表示回去**（回代）。

#### 4.5.1 三角代换

| 被积函数含 | 令 | 脱根式 |
|---|---|---|
| $\sqrt{a^2 - x^2}$ | $x = a\sin t$，$t \in \left[-\frac{\pi}{2},\,\frac{\pi}{2}\right]$ | $\sqrt{a^2-x^2} = a\cos t$ |
| $\sqrt{a^2 + x^2}$ | $x = a\tan t$，$t \in \left(-\frac{\pi}{2},\,\frac{\pi}{2}\right)$ | $\sqrt{a^2+x^2} = a\sec t$ |
| $\sqrt{x^2 - a^2}$ | $x = a\sec t$，取 $t \in \left[0,\,\frac{\pi}{2}\right)$ | $\sqrt{x^2-a^2} = a\tan t$ |

**通俗讲解**：这三个代换的几何来源是勾股定理：设直角三角形的斜边为 $a$、一直角边为 $x$，则另一直角边分别是 $\sqrt{a^2-x^2}$、$\sqrt{x^2+a^2}$、$\sqrt{x^2-a^2}$；而三角函数的平方关系（$\sin^2 t + \cos^2 t = 1$、$1 + \tan^2 t = \sec^2 t$）正好把根号"开"出来。回代时借助辅助直角三角形，可以快速写出 $\sin t$、$\cos t$、$\tan t$ 关于 $x$ 的表达式。

#### 4.5.2 根式代换

当被积函数含 $\sqrt[n]{ax+b}$ 时，令

$$t = \sqrt[n]{ax+b}, \quad \text{即} \quad x = \frac{t^n - b}{a}, \qquad dx = \frac{n}{a}t^{n-1}\,dt,$$

化为 $t$ 的有理函数再积分。若同时含 $\sqrt[n]{ax+b}$ 与 $\sqrt[m]{ax+b}$，令 $t = \sqrt[k]{ax+b}$，其中 $k$ 为 $m$ 与 $n$ 的最小公倍数。含 $\sqrt[n]{\frac{ax+b}{cx+d}}$ 时，令 $t = \sqrt[n]{\frac{ax+b}{cx+d}}$。

#### 4.5.3 倒代换

令

$$x = \frac{1}{t}, \qquad dx = -\frac{1}{t^2}\,dt,$$

适用于**分母次数明显高于分子**的有理函数（如分母含 $x^k\sqrt{...}$ 型），例如 $\int \frac{dx}{x^4(x^2+1)}$、$\int \frac{dx}{x^2\sqrt{x^2+1}}$ 等。倒代换后分子分母的次数关系会"翻转"，从而简化积分。

**注意**：

- 第二类换元后**必须回代**，且回代要写全 $t$ 与 $x$ 的关系式（必要时画辅助直角三角形）；
- 三角代换中 $t$ 的取值范围要保证代换函数单调（如 $x = a\sin t$ 取 $t \in \left[-\frac{\pi}{2},\,\frac{\pi}{2}\right]$），否则回代的 $\arcsin\frac{x}{a}$ 会出问题；
- 根式代换、倒代换与三角代换地位并列，都是"脱根号、化有理"的思想，需根据被积函数结构选择。

### 4.6 分部积分法

**公式**：设 $u = u(x)$，$v = v(x)$ 均可导，则

$$\int u\,dv = uv - \int v\,du.$$

**推导**：由乘积求导法则 $(uv)' = u'v + uv'$，两边积分得 $uv = \int v\,du + \int u\,dv$，移项即得。

**通俗讲解**：分部积分是把一个"不易积分"的乘积拆成"好积的部分先积出来"：把被积表达式分成 $u$ 与 $dv$ 两部分，其中 $dv$ 要**容易积分**（从而得到 $v$），$u$ 要**求导后变简单**（从而 $\int v\,du$ 比 $\int u\,dv$ 更容易）。整个技巧的精髓在于：**$u$ 的选取让求导"降级"，$dv$ 的选取让积分"可行"**。

**u 与 dv 的选取原则——"反对幂指三"**：按照

反三角函数（$\arcsin x$、$\arctan x$ 等）→ 对数函数（$\ln x$）→ 幂函数（$x^n$）→ 指数函数（$e^x$）→ 三角函数（$\sin x$、$\cos x$）

的先后顺序，**排在前面的取作 $u$**，剩下的取作 $dv$。理由：反三角与对数求导后变成有理式（"变简单"），幂函数求导后次数降低，而指数与三角函数的积分本身"不增不减"（怎么积都行），所以让"会变简单的"作 $u$。

**典型类型**：

1. **幂函数 × 指数/三角**（$\int x^n e^{ax}\,dx$、$\int x^n\sin ax\,dx$、$\int x^n\cos ax\,dx$）：令 $u = x^n$，连续用 $n$ 次分部积分把幂函数"降级"到常数；
2. **幂函数 × 对数/反三角**（$\int x^n\ln x\,dx$、$\int x^n\arctan x\,dx$、$\int x^n\arcsin x\,dx$）：令 $u = \ln x$（或 $\arctan x$ 等），$dv = x^n dx$，一次分部后对数/反三角消失；
3. **指数 × 三角**（$\int e^{ax}\sin bx\,dx$、$\int e^{ax}\cos bx\,dx$）：连续两次分部积分后"回到自己"，移项解出；此时 $u$ 取谁都行，但前后两次必须取同一种；
4. **自身循环型**（$\int \sec^3 x\,dx$、$\int \sqrt{x^2 \pm a^2}\,dx$）：分部后出现同类积分，移项求解。

**注意**：

- $u$ 与 $dv$ 选错会导致 $\int v\,du$ 比原积分更复杂（"越积越难"）；
- 循环型积分（指数 × 三角、$\sec^3 x$）必须**两次选取一致**，否则会得到恒等式 $0 = 0$ 而无法求解；
- 分部积分可以与换元法配合使用（先换元化简，再分部）。

### 4.7 有理函数的积分

**定义**：形如 $\frac{P(x)}{Q(x)}$（$P(x)$、$Q(x)$ 为多项式）的函数称为有理函数。若 $\deg P \geq \deg Q$（分子次数不低于分母次数），先做**多项式除法**化为"多项式 + 真分式"；真分式的积分归结为**部分分式分解**。

**部分分式分解**：设 $Q(x)$ 在实数范围内因式分解为一次因式与不可约二次因式（判别式 $< 0$）之积，则真分式 $\frac{P(x)}{Q(x)}$ 可唯一分解为以下形状之和（系数用待定系数法确定）：

| $Q(x)$ 的因式 | 对应的部分分式项 |
|---|---|
| 单重一次因式 $(x-a)$ | $\frac{A}{x-a}$ |
| $k$ 重一次因式 $(x-a)^k$ | $\frac{A_1}{x-a} + \frac{A_2}{(x-a)^2} + \cdots + \frac{A_k}{(x-a)^k}$ |
| 单重二次因式 $x^2+px+q$ | $\frac{Ax+B}{x^2+px+q}$ |
| $k$ 重二次因式 $(x^2+px+q)^k$ | $\frac{A_1x+B_1}{x^2+px+q} + \cdots + \frac{A_kx+B_k}{(x^2+px+q)^k}$ |

**求系数的方法**：通分后比较分子对应项系数（待定系数法），或代入特殊值（赋值法，如代入 $x = a$），常把"赋值法 + 比较系数法"结合使用。

**逐项积分**：分解后每一部分都能积分：

- $\int \frac{A}{x-a}\,dx = A\ln|x-a| + C$；
- $\int \frac{A}{(x-a)^k}\,dx = \frac{A}{(1-k)(x-a)^{k-1}} + C$（$k \geq 2$）；
- $\int \frac{Ax+B}{x^2+px+q}\,dx$：先将分母**配方** $x^2+px+q = \left(x+\frac{p}{2}\right)^2 + \left(q-\frac{p^2}{4}\right)$，分子拆成"分母导数的倍数 + 常数"两项：

$$\int \frac{Ax+B}{(x+\alpha)^2+\beta^2}\,dx = \frac{A}{2}\int \frac{2(x+\alpha)}{(x+\alpha)^2+\beta^2}\,dx + (B-A\alpha)\int \frac{dx}{(x+\alpha)^2+\beta^2},$$

第一项得对数，第二项用 $\arctan$ 公式（其中 $\alpha = \frac{p}{2}$，$\beta^2 = q - \frac{p^2}{4} > 0$）。

**通俗讲解**：有理函数的积分是一个"万能程序"：① 化成真分式 → ② 因式分解分母 → ③ 拆成部分分式 → ④ 逐项积分。任何有理函数都能用这个流程（理论上）积出来，只是分解的运算量可能很大。

**注意**：

- 分解前必须确保是真分式（分子次数 < 分母次数），否则先做多项式除法；
- 二次因式 $x^2+px+q$ 必须**判别式小于 0** 才是不可约的，对应分子应设成 $Ax+B$ 而非常数 $A$；
- 若被积函数分母含 $x(x^2+1)$ 型，有时可先用"加减项"技巧（如 $\frac{1}{x(x^2+1)} = \frac{1}{x} - \frac{x}{x^2+1}$）拆分，比部分分式更快。

### 4.8 三角函数有理式与简单无理函数的积分（了解）

**定义**：由 $\sin x$、$\cos x$ 及常数经有限次四则运算组成的函数 $R(\sin x, \cos x)$ 称为三角有理式。

**万能代换**：令

$$t = \tan\frac{x}{2},$$

则

$$\sin x = \frac{2t}{1+t^2}, \qquad \cos x = \frac{1-t^2}{1+t^2}, \qquad dx = \frac{2}{1+t^2}\,dt,$$

于是 $\int R(\sin x, \cos x)\,dx$ 化为 $t$ 的有理函数积分。这是三角有理式积分的"保底方法"，但往往计算量大，考试中应优先用下面的特殊技巧：

- 若 $R(-\sin x, \cos x) = -R(\sin x, \cos x)$（关于 $\sin x$ 为奇函数），令 $t = \cos x$；
- 若 $R(\sin x, -\cos x) = -R(\sin x, \cos x)$（关于 $\cos x$ 为奇函数），令 $t = \sin x$；
- 若 $R(-\sin x, -\cos x) = R(\sin x, \cos x)$（关于 $\sin x$、$\cos x$ 均为偶函数），令 $t = \tan x$。

**简单无理函数的积分**：被积函数含 $\sqrt[n]{ax+b}$ 或 $\sqrt[n]{\frac{ax+b}{cx+d}}$ 时，用根式代换化为有理函数积分（见 4.5.2）。例如 $\int \frac{dx}{1+\sqrt{x}}$：令 $t = \sqrt{x}$，则 $x = t^2$，$dx = 2t\,dt$，化为 $\int \frac{2t}{1+t}\,dt$，再拆项即可积分。

**注意**：

- 万能代换是"最后手段"，先判断是否能用特殊三角技巧或恒等变形化简；
- 简单无理函数题（含 $\sqrt{ax+b}$ 型）在考研中属于基础送分题，必须熟练；
- 三角有理式积分的结果中可能同时出现 $\arctan$ 与 $\ln$，回代后可以合并化简。

## 典型例题

### 例 1（凑微分法）求 $\int \frac{x}{\sqrt{1-x^4}}\,dx$。

**解**：注意到 $x\,dx = \frac{1}{2}\,d(x^2)$，而 $1-x^4 = 1 - (x^2)^2$，于是

$$\int \frac{x}{\sqrt{1-x^4}}\,dx = \frac{1}{2}\int \frac{d(x^2)}{\sqrt{1-(x^2)^2}}.$$

令 $u = x^2$，套用公式 $\int \frac{du}{\sqrt{1-u^2}} = \arcsin u + C$，得

$$\int \frac{x}{\sqrt{1-x^4}}\,dx = \frac{1}{2}\arcsin(x^2) + C.$$

**思路点拨**：见到 $x\,dx$ 与 $x^4 = (x^2)^2$ 的组合，第一反应是凑 $d(x^2)$，把 $x^2$ 看成一个整体套反三角积分公式。检验：$\left(\frac{1}{2}\arcsin x^2\right)' = \frac{1}{2}\cdot\frac{2x}{\sqrt{1-x^4}} = \frac{x}{\sqrt{1-x^4}}$ ✓。

### 例 2（三角代换）求 $\int \sqrt{a^2 - x^2}\,dx$（$a > 0$）。

**解**：被积函数含 $\sqrt{a^2-x^2}$，令

$$x = a\sin t, \quad t \in \left[-\frac{\pi}{2},\,\frac{\pi}{2}\right],$$

则 $dx = a\cos t\,dt$，$\sqrt{a^2-x^2} = a\cos t$。于是

$$\int \sqrt{a^2-x^2}\,dx = \int a\cos t \cdot a\cos t\,dt = a^2\int \cos^2 t\,dt = \frac{a^2}{2}\int (1+\cos 2t)\,dt,$$

$$= \frac{a^2}{2}t + \frac{a^2}{4}\sin 2t + C = \frac{a^2}{2}t + \frac{a^2}{2}\sin t\cos t + C.$$

回代：由 $x = a\sin t$ 得 $\sin t = \frac{x}{a}$，$t = \arcsin\frac{x}{a}$，且 $\cos t = \sqrt{1-\sin^2 t} = \frac{\sqrt{a^2-x^2}}{a}$，故

$$\int \sqrt{a^2-x^2}\,dx = \frac{a^2}{2}\arcsin\frac{x}{a} + \frac{x}{2}\sqrt{a^2-x^2} + C.$$

**思路点拨**：这是公式 $\int \sqrt{a^2-x^2}\,dx = \frac{x}{2}\sqrt{a^2-x^2} + \frac{a^2}{2}\arcsin\frac{x}{a} + C$ 的完整推导，也是三角代换的标准流程：代换 → 脱根式 → 三角积分（用降幂公式）→ 回代。回代时画辅助直角三角形（斜边 $a$、对边 $x$）可快速写出 $\cos t$。

### 例 3（分部积分法）求 $\int x^2 e^x\,dx$。

**解**：属于"幂函数 × 指数函数"型，按"反对幂指三"，$x^2$ 排在前面，令

$$u = x^2, \qquad dv = e^x\,dx \quad \Rightarrow \quad du = 2x\,dx, \quad v = e^x.$$

由分部积分公式：

$$\int x^2 e^x\,dx = x^2 e^x - \int e^x \cdot 2x\,dx = x^2 e^x - 2\int x e^x\,dx.$$

对 $\int x e^x\,dx$ 再用一次分部积分（令 $u = x$，$dv = e^x dx$）：

$$\int x e^x\,dx = x e^x - \int e^x\,dx = x e^x - e^x + C_1.$$

代入得

$$\int x^2 e^x\,dx = x^2 e^x - 2(x e^x - e^x) + C = e^x(x^2 - 2x + 2) + C.$$

**思路点拨**：幂函数乘指数（或 $\sin$、$\cos$）时，反复令"幂函数"为 $u$，每分部一次幂的次数降 1，直到降为常数。这类"降级"思想要熟练。检验：$\left(e^x(x^2-2x+2)\right)' = e^x(x^2-2x+2) + e^x(2x-2) = x^2 e^x$ ✓。

### 例 4（有理函数积分）求 $\int \frac{x+3}{x^2-5x+6}\,dx$。

**解**：分子次数低于分母，是真分式。分母因式分解：

$$x^2 - 5x + 6 = (x-2)(x-3).$$

设

$$\frac{x+3}{(x-2)(x-3)} = \frac{A}{x-2} + \frac{B}{x-3},$$

通分并比较分子：$x + 3 = A(x-3) + B(x-2)$。

赋值法：令 $x = 2$ 得 $5 = -A$，故 $A = -5$；令 $x = 3$ 得 $6 = B$，故 $B = 6$。于是

$$\int \frac{x+3}{x^2-5x+6}\,dx = \int \left(\frac{6}{x-3} - \frac{5}{x-2}\right)dx = 6\ln|x-3| - 5\ln|x-2| + C.$$

**思路点拨**：有理函数积分四步走：判真分 → 因式分解 → 部分分式（待定系数）→ 逐项积分。本题分母为两个单重一次因式，用"赋值法"求系数最省事；若分母含二次不可约因式，分子要设成 $Ax+B$，并配合配方与 $\arctan$ 公式。

## 常见错误与易混淆点

1. **忘记加任意常数 $C$**：不定积分的结果是一个函数族，任何一步都不能丢掉 $C$。检验标准：对结果求导应恰好得到被积函数。
2. **第二类换元忘记回代**：先令 $x = \psi(t)$ 积分出关于 $t$ 的表达式后，必须由 $t = \psi^{-1}(x)$ 代回 $x$；三角代换回代时建议画辅助直角三角形。
3. **$\int \frac{1}{x}\,dx = \ln|x| + C$ 漏绝对值**：积分区间未说明时，$\ln|x|$ 才是正确的原函数；只有明确 $x > 0$ 时才可去掉绝对值。
4. **凑微分"差常数倍"算错**：如 $x\,dx = \frac{1}{2}\,d(x^2)$ 前的 $\frac{1}{2}$、$dx = \frac{1}{a}\,d(ax+b)$ 前的 $\frac{1}{a}$，遗漏系数是高频失分点。
5. **两类换元混淆**：第一类换元不引入新变量、不写回代；第二类换元主动代换、必须回代。把"凑微分"误当"换元"来回代，或反过来，都会出错。
6. **分部积分 $u$ 选错**：$u$ 应让求导后"变简单"（反三角、对数、幂函数），$dv$ 应"好积分"（指数、三角）。若把 $\sin x$、$e^x$ 这类取作 $u$，往往越积越复杂。
7. **循环型积分两次选取不一致**：$\int e^{ax}\sin bx\,dx$ 两次分部必须取同类的 $u$，否则会得到 $0 = 0$ 的恒等式，解不出结果。
8. **部分分式设错形式**：二次不可约因式 $x^2+px+q$ 的分子应设 $Ax+B$；$k$ 重因式要写 $k$ 项。另外真分式要求分子次数低于分母，否则先做多项式除法。
9. **一般化公式漏系数**：如 $\int \frac{dx}{a^2+x^2} = \frac{1}{a}\arctan\frac{x}{a} + C$、$\int \frac{dx}{\sqrt{a^2-x^2}} = \arcsin\frac{x}{a} + C$，$a$ 的系数与位置是常见错误点。
10. **分段函数的原函数不连续**：原函数必须可导（从而连续）。分段函数求不定积分时，各段常数 $C$ 要由分段点处的连续性衔接确定。

## 复习与考研提示

- **地位**：不定积分是第 5 章定积分（牛顿—莱布尼茨公式 $\int_a^b f(x)\,dx = F(b) - F(a)$）与第 7 章微分方程（解方程 = 找原函数）的直接基础，务必学扎实。
- **必背清单**：基本积分表（尤其 $\frac{1}{x}$、$\frac{1}{1+x^2}$、$\frac{1}{\sqrt{1-x^2}}$、$\frac{1}{a^2 \pm x^2}$、$\frac{1}{\sqrt{x^2 \pm a^2}}$ 五类）与常用凑微分公式，要做到"见到就能写出"。
- **方法优先级**：先看能否直接积分 → 再想凑微分 → 换元（三角/根式/倒代换）→ 分部积分 → 有理函数（部分分式）→ 万能代换（保底）。考试中先挑"最简单可行"的方法。
- **考研高频**：凑微分与分部积分是每年必考的计算工具；$\int \frac{dx}{\sqrt{x^2 \pm a^2}}$、$\int \sec x\,dx$、$\int \sec^3 x\,dx$ 等"标准结论"在定积分、二重积分中反复出现，建议直接背结论。
- **技巧速记**：
  - 含 $\sin^2 x$、$\cos^2 x$ 用倍角公式降幂；$\sin x$（或 $\cos x$）的奇次幂凑微分；
  - 含 $\frac{1}{x\sqrt{x^2 \pm a^2}}$ 或分母次数高，优先考虑倒代换；
  - 含 $\sqrt[n]{ax+b}$ 用根式代换；
  - 分子是分母的导数时，结果为 $\ln|分母| + C$，这一模式要能一眼认出。
- **自我检验**：每做完一题都对结果求导验证，形成"求导—积分互逆"的肌肉记忆；这也是检查计算错误最有效的手段。
