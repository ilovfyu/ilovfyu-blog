::: abstract 系列定位
本系列按考研线性代数的稳定知识主线组织，吸收“线性代数九讲”常见的一级推进顺序，但不逐字复刻任何教材，也不绑定具体版本或页码。目标是把定义、定理条件、手算流程和综合题入口连成一张可反复调用的应试网络。
:::

## 1. 使用范围

### 1.1 数一、数二、数三

线性代数通常是数学一、数学二、数学三的共同考试模块，三者在线性代数上的主体内容高度重合，均应系统复习：

- 行列式；
- 矩阵及其运算；
- 向量与向量组；
- 线性方程组；
- 特征值、特征向量与相似对角化；
- 二次型。

::: important 以当年考纲为准
三类试卷的线性代数主体框架高度重合，但不能简单视为范围完全相同。数学一明确要求 $n$ 维向量空间、子空间、基、维数与坐标；数学二、数学三是否要求这些抽象内容，应按报考年度考试大纲复核。本系列完整保留这些内容，并在第 5 讲单独标注。
:::

### 1.2 应试目标

考研线性代数不只考“会不会算”，还考三种切换能力：

1. **数值到结构**：从具体矩阵计算出行列式、秩、特征值和解。
2. **结构到结论**：从 $|A|=0$、$r(A)=n-1$、$A^2=A$ 等条件推出性质。
3. **章节联动**：把行列式、秩、方程组、特征值和二次型放在同一条推理链上。

典型链条为

$$
|A|\neq 0
\iff A\text{ 可逆}
\iff r(A)=n
\iff Ax=0\text{ 只有零解}
\iff 0\text{ 不是 }A\text{ 的特征值}.
$$

## 3. 章节依赖

### 3.1 主干依赖图

$$
\text{行列式}
\longrightarrow
\text{矩阵运算与逆}
\longrightarrow
\text{秩}
\longrightarrow
\begin{cases}
\text{向量组}\\
\text{线性方程组}
\end{cases}
\longrightarrow
\text{特征值}
\longrightarrow
\text{相似对角化}
\longrightarrow
\text{二次型}.
$$

### 3.2 必须打通的横向联系

| 条件 | 可立即转译为 |
|---|---|
| $|A|\neq 0$ | $A^{-1}$ 存在、$r(A)=n$、$Ax=b$ 对任意 $b$ 唯一可解 |
| $|A|=0$ | $A$ 不可逆、$r(A)<n$、$Ax=0$ 有非零解 |
| $A\alpha=0$ 且 $\alpha\neq0$ | $A$ 不满秩，$0$ 是特征值 |
| $A\alpha=\lambda\alpha$ | $(\lambda E-A)\alpha=0$，故 $|\lambda E-A|=0$ |
| $A=P^{-1}\Lambda P$ | 可快速求 $A^k$，且特征值、行列式、迹易读出 |
| $x^TAx$ 且 $A=A^T$ | 可用正交变换化标准形，以特征值判断正定性 |

### 3.3 卡点处理

- 行列式不会算：先停在第 1、2 讲，不急于做特征值。
- 初等变换频繁出错：先专项训练阶梯形，再进入秩与方程组。
- 抽象题无入口：把题设逐条翻译成“列关系、核、秩、特征值”语言。
- 二次型配方混乱：先掌握实对称矩阵正交对角化，再练合同变换。

## 4. 三轮复习法

### 4.1 第一轮：体系与基本手算

目标：能准确复述定义和定理条件，独立完成基础计算。

- 按 01 至 09 顺序学习，不跳过推导。
- 每节建立“定义卡、性质卡、流程卡”。
- 例题必须落笔计算，尤其是符号、初等变换和参数分类。
- 每章结束完成自测；正确率低于 $80\%$ 时，不直接进入综合题。

### 4.2 第二轮：题型与章节联动

目标：看到条件后在 30 秒内确定主工具。

- 按题型重组：行列式计算、秩与方程组、特征值与矩阵幂、二次型正定性。
- 每道错题记录“识别信号”和“第一步”，而非只抄完整答案。
- 同一题至少尝试两种入口，例如参数矩阵既可看行列式，也可看秩。
- 每周安排一次 60 至 90 分钟的线性代数限时套题。

### 4.3 第三轮：限时与稳定性

目标：减少无效展开、符号错误和结论缺条件。

- 只保留高频错题、公式清单和综合母题。
- 选择题优先用性质、秩和反例排除，不做冗长通算。
- 大题书写固定为“依据、变换、结论”三层。
- 对参数题强制检查临界值，对逆矩阵和特征向量强制回代。

## 5. 题型优先级

### A 级：必须稳定得分

- 三阶、四阶行列式的展开与化三角；
- 矩阵乘法、转置、逆、伴随矩阵；
- 初等变换求秩、逆和方程组解；
- 向量组相关性与极大无关组；
- 特征值、特征向量和可对角化判定；
- 二次型化标准形、正定判定。

### B 级：综合题核心

- 参数行列式与参数方程组分类；
- 抽象矩阵的秩、可逆性、伴随矩阵；
- 公共解、同解和解空间包含；
- 由矩阵多项式或秩条件反推特征值；
- 相似对角化求高次幂；
- 二次型与特征值、合同的联动。

### C 级：冲刺辨析

- 递推行列式、加边升阶与结构变形；
- 多个秩不等式联合取等；
- 抽象向量空间证明；
- 相似、合同、等价三个关系的反例辨析。

::: tip 时间分配原则
先保证 A 级题“步骤短、符号稳、结果可检验”，再投入 B 级综合题。C 级方法用于拓宽入口，不应挤占基础题复盘时间。
:::

## 6. 标准审题流程

1. **标对象**：方阵、矩形矩阵、列向量还是二次型。
2. **标条件**：可逆、对称、正交、秩、特征值、参数临界值。
3. **找出口**：题目最终要求数值、秩、解、谱还是正定性。
4. **选桥梁**：用行列式、初等变换、齐次方程或相似变换连接条件与结论。
5. **做检查**：维数、顺序、符号、特殊参数、回代。

## 7. 复盘方法

### 7.1 一题一行复盘表

| 字段 | 应记录内容 |
|---|---|
| 题型 | 如“参数行列式”“抽象矩阵秩” |
| 识别信号 | 如“每行元素和相同”“出现 $A^*$” |
| 第一动作 | 如“各列加到第一列”“先判断 $|A|$ 是否为零” |
| 错误层级 | 概念、入口、运算、书写、时间 |
| 可迁移结论 | 一条能用于下一题的规则 |
| 重做日期 | 当天、3 天后、14 天后 |

### 7.2 错误分级

- **概念错**：重读定义并补一个反例。
- **条件漏**：把定理改写成“若……则……”，圈出前提。
- **入口错**：只记录正确解法的第一步，并找题面识别信号。
- **运算错**：保留中间矩阵，定位第一次错误，不笼统写“粗心”。
- **策略慢**：比较展开、消元、性质法的计算量，形成优先级。

### 7.3 闭环标准

一道错题只有满足以下条件才算关闭：

1. 不看答案可独立重做；
2. 能口述为什么选择该方法；
3. 能指出至少一个常见错误入口；
4. 改动数据或参数后仍能完成同类题。

## 8. 周期安排示例

| 周期 | 主任务 | 检验方式 |
|---|---|---|
| 第 1 周 | 01 至 03，建立行列式与矩阵手算基础 | 每日 8 至 12 题基础计算 |
| 第 2 周 | 04 至 06，打通秩、向量组和方程组 | 参数分类与证明题混练 |
| 第 3 周 | 07 至 09，完成谱与二次型 | 特征值、对角化、正定综合题 |
| 第 4 周 | 九讲串联与第一次限时训练 | 套题加错题回炉 |

该安排只表示相对节奏。基础薄弱时应延长第一轮，不以“看完页数”代替“独立算出”。

## 9. 阶段自测

1. 若 $A,B$ 为同阶方阵且 $AB=E$，能否断言 $BA=E$？
2. 若 $r(A)=n-1$，齐次方程 $Ax=0$ 的基础解系含几个向量？
3. 若实对称矩阵 $A$ 的全部特征值为正，可推出什么？
4. 参数题为什么必须单独检查使主元或分母为零的值？
5. 复盘时为什么不能只记录答案？

::: answer 简明答案
1. 能。有限阶方阵中 $AB=E$ 可推出 $A,B$ 均可逆，故 $BA=E$。
2. 当 $A$ 有 $n$ 列时，基础解系含 $n-r(A)=1$ 个向量。
3. $A$ 正定，且可正交对角化。
4. 通常推导中进行了除法或默认主元非零，临界值可能改变秩与解的个数。
5. 只记答案不能修复“识别信号到第一步”的决策链，同类题仍会重复出错。
:::

## 10. 开始学习

从 [行列式的基本概念与计算](/specials/math/notes/exam-linear-algebra/01/) 开始。第一轮学习时，任何行列式都先判断结构，再决定展开还是化三角，避免上来就作全排列展开。
