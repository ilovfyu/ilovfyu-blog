前面的参数都来自路径、查询或 JSON 请求体。真实接口还会接收请求头、Cookie、HTML 表单和文件。FastAPI 用同一套类型标注处理这些来源，但每类数据的安全边界不同。

## 用一个模型收拢查询参数

查询参数多起来以后，函数签名会变得很长。可以定义一个 Pydantic 模型，再整体标记为 ​`Query`：

```python
from typing import Annotated

from fastapi import FastAPI, Query
from pydantic import BaseModel, Field


class TaskFilter(BaseModel):
    q: str | None = Field(default=None, max_length=100, description="标题包含的关键词")
    done: bool | None = Field(default=None, description="按完成状态过滤")
    limit: int = Field(default=20, ge=1, le=100)
    offset: int = Field(default=0, ge=0)


app = FastAPI()


@app.get("/tasks")
def list_tasks(filters: Annotated[TaskFilter, Query()]) -> dict:
    return filters.model_dump()
```

请求：

```bash
curl 'http://127.0.0.1:8000/tasks?q=docs&done=false&limit=5&offset=10'
```

`Query()`​ 会把模型的每个字段映射为查询参数，校验规则和默认值都来自 ​`Field`。不要把这个技巧用到请求体模型上：查询参数出现在 URL、日志和浏览器历史中，不适合放密码、令牌或大段文本。

## 路径、请求头与 Cookie

```python
from typing import Annotated

from fastapi import Cookie, Header, Path


@app.get("/tasks/{task_id}/audit")
def audit_task(
    task_id: Annotated[int, Path(ge=1)],
    x_request_id: Annotated[str | None, Header(alias="X-Request-ID")] = None,
    session_id: Annotated[str | None, Cookie()] = None,
) -> dict:
    return {
        "task_id": task_id,
        "request_id": x_request_id,
        "session": session_id,
    }
```

`Header`​ 默认会把下划线转成连字符，​`alias`​ 可以显式指定原始名称。浏览器会自动携带同站 Cookie；跨站请求是否携带取决于 ​`SameSite`​、​`Secure` 和 CORS 配置，不能只靠后端读取。

请求头和 Cookie 都属于客户端可控输入。日志里不要记录 ​`Authorization`、Cookie 明文或完整的请求体，除非已经做过脱敏。

## 表单

HTML 表单和 OAuth2 密码流使用 ​`application/x-www-form-urlencoded`​ 或 ​`multipart/form-data`，不是 JSON：

```python
from typing import Annotated

from fastapi import Form


@app.post("/login")
def login(
    username: Annotated[str, Form(min_length=1, max_length=255)],
    password: Annotated[str, Form(min_length=8, max_length=128)],
) -> dict:
    return {"username": username}
```

提交：

```bash
curl -X POST http://127.0.0.1:8000/login \
  -d 'username=alice@example.com' \
  -d 'password=strong-password'
```

`Form`​ 需要安装 ​`python-multipart`​。​`fastapi[standard]`​ 已经包含；如果只安装了 ​`fastapi`​，要单独执行 ​`python -m pip install python-multipart`，否则启动时会报错。

## 文件上传

```python
from typing import Annotated

from fastapi import File, HTTPException, UploadFile

MAX_SIZE = 1024 * 1024


@app.post("/attachments")
async def upload_attachment(
    file: Annotated[UploadFile, File(description="不超过 1 MB 的文本文件")],
) -> dict:
    data = await file.read(MAX_SIZE + 1)
    if len(data) > MAX_SIZE:
        raise HTTPException(status_code=413, detail="文件不能超过 1 MB")
    if file.content_type not in {"text/plain", "text/markdown"}:
        raise HTTPException(status_code=415, detail="仅支持 text/plain 或 text/markdown")
    return {
        "filename": file.filename,
        "content_type": file.content_type,
        "size": len(data),
    }
```

`UploadFile`​ 底层是 ​`SpooledTemporaryFile`​：小文件留在内存，大文件落到临时目录。​`await file.read(n)` 可以分批读，避免一次性把大文件读进内存。生产环境还应设置反向代理的请求体上限，不能只依赖应用内的检查。

文件处理的几个原则：

- `filename`​ 和 ​`content_type` 都由客户端提供，不能直接信任。
- 不要用原始文件名拼接服务器路径，使用随机 ID 或内容哈希。
- 上传目录不要放在可执行代码或静态资源的根目录。
- 图片、PDF 等文件要做类型检测和病毒扫描，不能只看扩展名。
- 下载时使用 ​`FileResponse` 或受控的静态文件服务，不要暴露任意路径。

## 同时接收文件和表单字段

```python
@app.post("/tasks/{task_id}/attachments")
async def attach(
    task_id: int,
    file: Annotated[UploadFile, File()],
    note: Annotated[str, Form(max_length=200)] = "",
) -> dict:
    return {"task_id": task_id, "filename": file.filename, "note": note}
```

```bash
curl -X POST http://127.0.0.1:8000/tasks/1/attachments \
  -F 'file=@note.txt;type=text/plain' \
  -F 'note=设计说明'
```

当表单里同时有文件和普通字段时，整个请求会以 ​`multipart/form-data` 发送。此时不能再要求客户端提交 JSON 请求体。
