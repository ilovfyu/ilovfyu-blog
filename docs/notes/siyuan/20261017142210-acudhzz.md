内存字典在重启后消失，也无法在多个进程之间共享。这一章把任务和用户放进 SQLAlchemy 2.1，先使用同步会话，把模型、会话生命周期和查询写清楚；下一章再讨论异步。

## 安装与模型

```bash
python -m pip install "sqlalchemy==2.1.5"
```

```python
from datetime import datetime

from sqlalchemy import DateTime, ForeignKey, String, func
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column, relationship


class Base(DeclarativeBase):
    pass


class User(Base):
    __tablename__ = "users"

    id: Mapped[int] = mapped_column(primary_key=True)
    email: Mapped[str] = mapped_column(String(255), unique=True, index=True)
    hashed_password: Mapped[str] = mapped_column(String(255))
    is_active: Mapped[bool] = mapped_column(default=True)
    is_admin: Mapped[bool] = mapped_column(default=False)
    created_at: Mapped[datetime] = mapped_column(DateTime(timezone=True), server_default=func.now())

    tasks: Mapped[list["Task"]] = relationship(back_populates="owner", cascade="all, delete-orphan")


class Task(Base):
    __tablename__ = "tasks"

    id: Mapped[int] = mapped_column(primary_key=True)
    title: Mapped[str] = mapped_column(String(200), index=True)
    description: Mapped[str | None] = mapped_column(String(2000), default=None)
    done: Mapped[bool] = mapped_column(default=False)
    owner_id: Mapped[int] = mapped_column(ForeignKey("users.id", ondelete="CASCADE"))
    created_at: Mapped[datetime] = mapped_column(DateTime(timezone=True), server_default=func.now())
    updated_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True), server_default=func.now(), onupdate=func.now()
    )

    owner: Mapped[User] = relationship(back_populates="tasks")
```

`Mapped[...]`​ 与 ​`mapped_column`​ 是 SQLAlchemy 2.x 的声明式写法。类型标注不仅给 IDE 看，也参与列类型推断；复杂类型仍应显式写 ​`String(200)`​、​`DateTime(timezone=True)`。

## 引擎与会话

```python
from sqlalchemy import create_engine
from sqlalchemy.orm import Session, sessionmaker


def make_engine(url: str):
    connect_args = {"check_same_thread": False} if url.startswith("sqlite") else {}
    return create_engine(url, connect_args=connect_args, pool_pre_ping=True)


engine = make_engine("sqlite:///./tasks.db")
SessionLocal = sessionmaker(bind=engine, autoflush=False, expire_on_commit=False)
```

- `check_same_thread=False` 只用于 SQLite，因为 FastAPI 的同步路由会在不同线程执行。
- `pool_pre_ping=True` 在取连接前做一次轻量探测，避免使用已经断开的连接。
- `expire_on_commit=False` 让提交后仍可读取对象属性，适合在响应序列化前提交的场景。
- 生产环境不要在每个请求里新建引擎；引擎和连接池应在应用生命周期内复用。

## 会话依赖

```python
from collections.abc import Generator

from fastapi import Depends, Request
from sqlalchemy.orm import Session


def get_db(request: Request) -> Generator[Session, None, None]:
    factory = request.app.state.session_factory
    with factory() as session:
        try:
            yield session
        except Exception:
            session.rollback()
            raise


DbSession = Annotated[Session, Depends(get_db)]
```

路由里显式提交：

```python
@router.post("", response_model=TaskPublic, status_code=201)
def create_task(payload: TaskCreate, db: DbSession, user: CurrentUser) -> Task:
    task = Task(**payload.model_dump(), owner_id=user.id)
    db.add(task)
    db.commit()
    db.refresh(task)
    return task
```

`commit`​ 之后 ​`refresh`​，是为了拿到数据库生成的 ​`id`​、​`created_at`​ 和 ​`updated_at`​。如果 ​`expire_on_commit=False`，已加载的字段不会过期，但服务器默认值仍需要刷新才能看到。

## 常用查询

```python
from sqlalchemy import func, select


def list_for_owner(db: Session, owner_id: int, limit: int, offset: int) -> tuple[list[Task], int]:
    filters = [Task.owner_id == owner_id]
    total = db.scalar(select(func.count()).select_from(Task).where(*filters)) or 0
    items = list(
        db.scalars(
            select(Task)
            .where(*filters)
            .order_by(Task.id.desc())
            .limit(limit)
            .offset(offset)
        )
    )
    return items, total


def get_owned(db: Session, task_id: int, owner_id: int) -> Task | None:
    return db.scalar(select(Task).where(Task.id == task_id, Task.owner_id == owner_id))
```

`scalar()`​ 取第一行第一列或单个实体；​`scalars().all()`​ 取实体列表。不要用 ​`db.query()`​ 的旧式 API 写新代码，SQLAlchemy 2.x 推荐 ​`select()`。

## 事务与所有权

- 一个请求内的多次写入应放在同一事务中；失败时整体回滚。
- 查询他人任务时，把 ​`owner_id`​ 放进 ​`WHERE`，而不是先查出来再在 Python 里比较。
- 删除用户时如果希望任务一起删除，数据库外键和 ORM 关系要同时配置，并确认数据库真的启用了外键约束。
- SQLite 默认不启用外键；需要时在连接事件里执行 ​`PRAGMA foreign_keys=ON`。

## SQLite 与生产数据库

SQLite 适合本地开发和测试，不适合多进程高并发写入。生产通常使用 PostgreSQL：

```text
postgresql+psycopg://user:password@host:5432/taskdb
```

需要安装 ​`psycopg[binary]`。连接池大小、超时和语句日志要按部署环境配置，不要把本地 SQLite 参数直接带到生产。
