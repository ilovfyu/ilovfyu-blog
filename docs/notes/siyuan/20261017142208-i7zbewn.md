这个系列从一个可以运行的最小应用开始，先把 2026 年的版本、环境和验证方式确定下来。后面的每一章都会围绕同一个任务管理 API 逐步扩展，最终形成一个可测试、可迁移、可部署的 FastAPI 项目。

## 版本基线

本文按当前最新稳定版编写，并在 Python 3.13 上实际运行验证：

|组件|版本|说明|
| -----------| ---------| -----------------------------------|
|FastAPI|0.143.3|2026-10-16 发布|
|Starlette|1.8.0|FastAPI 的 ASGI 基础|
|Pydantic|2.14.1|请求与响应模型|
|Uvicorn|0.54.0|ASGI 服务器|
|Python|3.11+|Starlette 1.8 要求；本文使用 3.13|

FastAPI 自身仍支持 Python 3.10+，但安装最新依赖时会解析到 Starlette 1.8，因此新项目建议直接从 Python 3.11 或更高版本开始。少于 3.11 的环境需要固定旧版 Starlette，不在本文的推荐路径内。

## 创建环境

```bash
mkdir task-api
cd task-api
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install "fastapi[standard]==0.143.3"
```

Windows 下激活命令是 ​`.venv\Scripts\activate`​。​`fastapi[standard]`​ 会一并安装 FastAPI CLI、Uvicorn、​`pydantic-settings`​、​`python-multipart`​、​`email-validator` 和 OpenTelemetry SDK/Exporter，足够走完后面的主要章节。

测试相关的依赖要单独装。Starlette 1.8 的 ​`TestClient`​ 使用 ​`httpx2`​，而 FastAPI 的 ​`standard`​ 额外项仍然声明的是 ​`httpx<1.0`，两者不是同一个包：

```bash
python -m pip install pytest httpx2
```

确认版本：

```bash
python -c "import fastapi, starlette, pydantic; print(fastapi.__version__, starlette.__version__, pydantic.VERSION)"
```

## 第一条路由

新建 ​`main.py`：

```python
from fastapi import FastAPI

app = FastAPI(
    title="Task API",
    version="0.1.0",
    description="贯穿本教程的任务管理 API。",
)


@app.get("/health", tags=["system"], summary="健康检查")
def health() -> dict[str, str]:
    return {"status": "ok"}
```

`app`​ 是应用对象。​`@app.get("/health")`​ 把 HTTP 方法和路径绑定到函数，函数返回值会被序列化为 JSON。类型标注 ​`dict[str, str]` 会进入 OpenAPI，让文档表达响应结构。

## 启动与验证

开发时使用：

```bash
fastapi dev main.py
```

默认监听 ​`127.0.0.1:8000`，带热重载。另开终端：

```bash
curl http://127.0.0.1:8000/health
# {"status":"ok"}
```

打开 ​`http://127.0.0.1:8000/docs`​ 可以直接调用接口；​`/redoc`​ 是另一种文档视图；​`/openapi.json` 是文档的机器可读来源。当前 FastAPI 生成的是 OpenAPI 3.1 文档。

生产启动不再使用热重载：

```bash
fastapi run main.py --host 0.0.0.0 --port 8000
```

`fastapi dev`​ 适合本地开发；​`fastapi run` 适合容器或服务器。两者都来自 FastAPI CLI，不需要自己拼 Uvicorn 命令。

## def 还是 async def

同步函数用 ​`def`​，FastAPI 会把它放到线程池执行，适合 SQLAlchemy 同步会话、文件读写这类阻塞操作。真正的异步 I/O 用 ​`async def`，例如异步数据库、HTTP 客户端或消息队列。

不要为了看起来“现代”把阻塞调用直接写进 ​`async def`​：那会卡住事件循环，拖慢同一进程里的所有请求。判断标准不是函数长短，而是函数内部是否 ​`await` 真正的异步操作。

## 最终项目结构

本教程不会一开始就把目录铺满。前几章先用单个 ​`main.py` 把概念跑通，第 7 章再拆成下面的结构，第 8 章接入数据库，第 10 章加入迁移，第 18 章补齐部署文件：

```text
task-api/
├── app/
│   ├── main.py
│   ├── core/config.py
│   ├── db.py
│   ├── models.py
│   ├── schemas.py
│   ├── security.py
│   ├── deps.py
│   ├── errors.py
│   └── api/v1/
│       ├── router.py
```

每一章只增加当时需要的文件。先理解请求如何进入应用，再考虑如何拆分模块。
