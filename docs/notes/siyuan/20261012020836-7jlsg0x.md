这篇知识库演示记录当前博客已经验证过的发布步骤，可直接作为日常操作手册。

## 先预览

保持思源打开，在博客项目目录双击「同步思源文章.command」。本地预览运行时会更新目录与正文；如果未运行预览，在终端启动：

```bash
npm run blog:preview
```

本地预览地址为 ​`http://127.0.0.1:8092/` 。

## 再发布

双击「发布博客.command」，或者执行：

```bash
npm run blog:publish
```

脚本依次同步文章、复制附件、构建静态网站、提交生成文件并推送 master。GitHub Actions 随后构建并部署到 Pages。

## 确认网站更新

1. 打开[GitHub Actions](https://github.com/ilovfyu/ilovfyu-blog/actions)。
2. 确认最新一次工作流的 build 和 deploy 成功。
3. 刷新[博客网站](https://ilovfyu.github.io/ilovfyu-blog/)。

推送代码和完成部署是两个阶段，在线页面要等部署完成后才会更新。

## 常见情况

|情况|处理|
| ----------------| ------------------------------------------------|
|思源没有打开|打开思源后重试|
|修改了博客代码|先单独提交代码，再发布文章|
|构建失败|修复终端提示的问题后重试，不会自动推送失败构建|
|推送失败|检查 SSH 和网络，本地提交会保留|
|删除了文章|再发布一次，网站才会撤下|
