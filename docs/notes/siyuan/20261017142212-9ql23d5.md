认证回答“你是谁”，授权回答“你能做什么”。这一章先完成认证：注册、密码哈希、OAuth2 密码流、JWT 签发与校验，以及一个受保护的 ​`/me` 接口。

## 依赖

```bash
python -m pip install "pwdlib[argon2]==0.3.1" "pyjwt==2.15.1" "python-multipart"
```

`pwdlib`​ 提供密码哈希，​`argon2`​ 是推荐算法；​`PyJWT`​ 负责 JWT 编解码；​`OAuth2PasswordRequestForm`​ 需要 ​`python-multipart`​。​`fastapi[standard]`​ 已包含 ​`python-multipart`。

## 密码哈希

```python
from pwdlib import PasswordHash

password_hash = PasswordHash.recommended()


def hash_password(password: str) -> str:
    return password_hash.hash(password)


def verify_password(password: str, hashed: str) -> bool:
    return password_hash.verify(password, hashed)


def verify_and_rehash(password: str, hashed: str) -> tuple[bool, str | None]:
    return password_hash.verify_and_update(password, hashed)
```

`verify_and_update` 会在算法参数升级时返回新的哈希，登录成功后可以把新哈希写回数据库。不要自己实现盐、迭代次数或 Base64 拼接；使用经过审计的库。

密码策略建议：最少 8 位只适用于低风险场景；更重要的是长度上限、弱密码检查和泄露密码库比对。永远不要明文存储或记录密码。

## JWT 签发与校验

```python
from datetime import datetime, timedelta, timezone

import jwt

ALGORITHM = "HS256"


def create_access_token(subject: int | str, settings, *, admin: bool = False) -> str:
    now = datetime.now(timezone.utc)
    expires = now + timedelta(minutes=settings.access_token_expire_minutes)
    payload = {
        "sub": str(subject),
        "iat": int(now.timestamp()),
        "exp": int(expires.timestamp()),
        "admin": admin,
    }
    return jwt.encode(payload, settings.secret_key.get_secret_value(), algorithm=ALGORITHM)


def decode_token(token: str, settings) -> dict:
    return jwt.decode(
        token,
        settings.secret_key.get_secret_value(),
        algorithms=[ALGORITHM],
    )
```

要点：

- `sub`​ 使用字符串。PyJWT 新版本会校验 ​`sub` 类型，整数可能触发警告或错误。
- `exp`​ 是过期时间，必须设置；​`iat` 便于排查和撤销策略。
- 解码时显式传 ​`algorithms`​，不要信任令牌头部的 ​`alg`。
- HMAC 密钥至少 32 字节。示例用 ​`secrets.token_urlsafe(32)` 生成。
- JWT 是签名而非加密，任何人都能读取 payload；不要放密码、密钥或敏感个人信息。
- JWT 无法立即撤销。需要强制下线时，使用短有效期、令牌版本号或服务端黑名单。

## OAuth2 密码流

```python
from typing import Annotated

from fastapi import APIRouter, Depends, HTTPException, status
from fastapi.security import OAuth2PasswordBearer, OAuth2PasswordRequestForm
from sqlalchemy import select

oauth2_scheme = OAuth2PasswordBearer(tokenUrl="/api/v1/auth/token")
router = APIRouter(prefix="/auth", tags=["auth"])


@router.post("/token")
def login(
    form: Annotated[OAuth2PasswordRequestForm, Depends()],
    db: DbSession,
    settings: SettingsDep,
) -> Token:
    user = db.scalar(select(User).where(User.email == form.username))
    if user is None or not verify_password(form.password, user.hashed_password):
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="邮箱或密码错误",
            headers={"WWW-Authenticate": "Bearer"},
        )
    token = create_access_token(user.id, settings, admin=user.is_admin)
    return Token(access_token=token, expires_in=settings.access_token_expire_minutes * 60)
```

`OAuth2PasswordRequestForm`​ 接收 ​`username`​ 和 ​`password`​ 两个表单字段。这里把 ​`username` 当作邮箱使用；字段名是 OAuth2 规范固定的，不能随意改。

响应：

```json
{
  "access_token": "eyJ...",
  "token_type": "bearer",
  "expires_in": 3600
}
```

## 用依赖读取当前用户

```python
from jwt import InvalidTokenError


def get_current_user(
    token: Annotated[str, Depends(oauth2_scheme)],
    db: DbSession,
    settings: SettingsDep,
) -> User:
    credentials_error = HTTPException(
        status_code=status.HTTP_401_UNAUTHORIZED,
        detail="无效或过期的身份凭证",
        headers={"WWW-Authenticate": "Bearer"},
    )
    try:
        payload = decode_token(token, settings)
        user_id = int(payload["sub"])
    except (InvalidTokenError, KeyError, TypeError, ValueError):
        raise credentials_error from None
    user = db.get(User, user_id)
    if user is None or not user.is_active:
        raise credentials_error
    return user


CurrentUser = Annotated[User, Depends(get_current_user)]
```

`OAuth2PasswordBearer`​ 会从 ​`Authorization: Bearer <token>`​ 读取令牌。依赖失败返回 401 并带 ​`WWW-Authenticate`，客户端才知道如何重新认证。

## 注册与重复邮箱

```python
@router.post("/register", response_model=UserPublic, status_code=201)
def register(payload: UserCreate, db: DbSession) -> User:
    user = User(email=payload.email, hashed_password=hash_password(payload.password))
    db.add(user)
    try:
        db.commit()
    except IntegrityError:
        db.rollback()
        raise HTTPException(status_code=409, detail="邮箱已被注册") from None
    db.refresh(user)
    return user
```

不要先查询再插入来判断唯一性：两个并发请求可能同时通过检查。让数据库唯一约束做最终裁决，再捕获 ​`IntegrityError`。

## 令牌放在哪里

- 纯 API 客户端：​`Authorization: Bearer`，由客户端安全存储。
- 浏览器应用：优先 HttpOnly、Secure、SameSite Cookie，并配合 CSRF 防护；不要把长期令牌放在 ​`localStorage`。
- 移动端：系统钥匙串或安全存储。
- 日志、URL、错误响应中不要出现令牌。
