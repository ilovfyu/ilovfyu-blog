从一个健康检查接口开始，理解 FastAPI 的应用、路由和交互文档，搭建后续练习需要的最小环境。

## 这条学习路径

本专题用一个任务接口串起四个阶段：启动应用 → 接收并校验数据 → 组织依赖与模块 → 验证接口并准备运行。示例采用 Python 3.10+ 的类型标注和 Pydantic 2 的写法。

## 1. 准备项目

在一个新目录中执行：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install "fastapi[standard]"
```

Windows 激活命令为 ​`.venv\Scripts\activate`。下面的示例默认在项目目录中运行，每章会明确给出需要保存的文件名。

## 2. 写下第一条路由

创建 ​`main.py`：

```python
from fastapi import FastAPI

app = FastAPI(title="FastAPI 入门")

@app.get("/health")
def health():
    return {"status": "ok"}
```

`app` 是应用对象；装饰器把 HTTP 方法、网址和处理函数关联起来。函数返回的字典会作为 JSON 响应。

## 3. 启动并验证

```bash
fastapi dev main.py
curl http://127.0.0.1:8000/health
```

预期响应为 ​`{"status":"ok"}`​。浏览器打开 ​`http://127.0.0.1:8000/docs`​，展开 ​`GET /health`​ 后使用 Try it out 执行请求；​`/redoc`​ 提供另一种文档展示，​`/openapi.json` 是接口描述数据。

## 4. 先建立几个概念

|概念|这里的例子|
| ----------| ------------------------|
|路径操作|`GET /health`|
|请求|客户端调用接口|
|响应|返回状态码与 JSON 数据|
|OpenAPI|用结构化信息描述接口|

示例使用普通 ​`def`​；后续需要等待异步客户端时再使用 ​`async def`。不要为了形式上的“异步”把阻塞操作直接放进事件循环。

## 动手练习

再添加 ​`GET /version`​，返回项目版本；在交互文档中调用它，观察文档如何跟随路由变化。下一章会把 ​`main.py` 替换成可创建、查询任务的版本。
